# OE204 工單達交率（準時開工）

- 選單為「工單管理 → 工單 → 工單達交率（準時開工）」，FunctionNo `MO QUERY2`，FunctionKey `OE204`。Vue 入口為 `/YMES/OE/ManufacturingOrderStartRate`。
- 依 `STD/MESWin/OE/OE_MOQuery2/frmMOQuery2.vb` 及內嵌 Designer、`wsOE.LoadMOBasis` 和 `clsOEBasis.LoadMOBasis`。

## 查詢與計算

- 共用 [OE203 工單查詢](工單查詢.md) 條件，另加 PlanStartDate 含端點範圍與產品類別多選。Oracle 以工單 ProductNo、ProductVersion 對版本化 `TBLPRDPRODUCTBASIS` 做存在檢查。屬性查詢沿用 MONo。
- Oracle Core 回傳 `MODiffDay1=ActualStartDate−PlanStartDate`。差異負值為提前、零為準時、正值為延遲，缺日期沒有分類。Form 的三種百分比皆以整個結果集為分母，包含缺日期的列，顯示一位小數。總數為零時顯示 0%。
- 查詢主表與四個日期欄位已納入 [OE201](工單基本資料.md) DDL。家用端可在同一個資料快照中回查詢結果及整個篩選結果的統計。若清單分頁，統計用全體結果。Oracle DATE 可包含時間，參數使用型別化時間，並保留 NULL 與時間差的處理。產品類別依版本關聯。

## 公司端 DEV

- 沿用 OE201 本機工單與 OE203 查詢，提供計畫開工起迄日、假產品類別及工單屬性查看。範圍以日含端點，顯示開工、完工計畫及實際日期和差異。實際開工日期來自假資料；可新增只有計畫日期的工單檢查缺值計入分母的情境。
