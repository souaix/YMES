# OE206 工單用料清單

- 選單為「工單管理 → 工單 → 工單用料清單」，FunctionNo `MO MATERIAL LIST`、FunctionKey `OE206`。Vue 入口為 `/YMES/OE/ManufacturingOrderMaterials`，亦可從 OE201 開啟所選工單用料。
- 依 `STD/MESWin/OE/OE_MOMaterialList` 的 `frmMOMaterialList`、`frmMOMaterialListDef`、`frmMaterialSubstitute` 及內嵌 Designer、`STD/MESws_STD/wsSTD/wsOE/wsOE.cs` 和 `STD/MESkc/kcOE/clsOEBasis.cs`。

## 原 MES 行為

- 透過 `LoadMOBasis` 挑選工單，候選查詢排除已結案，MOState 為 0、1、2、3、6。載入用料用 `LoadMOMaterialListJoinMOBasis`，再讀 `LoadMOMaterialState` 得到現有量。MaterialLevel 0 是原物料、1 是半成品，切換時篩選清單。
- 新增及修改呼叫 `AddMOMaterialListSubstitute`／`EditMOMaterialListSubstitute`。資料鍵為工單、物料、作業站、替代料。Form 選取後對指定料或目前存料量非零擋修改。刪除多選依序呼叫 `DELMOMaterialListSubstitute`，略過或拒絕符合守門條件的列，正式行為需保留各分支回應。
- 替代料要求工單 MOState >= 2，且為未指定、無存料的原物料。原表單讀 `wsMTL.LoadMaterialSubstitute` 和 `wsPRD.LoadBOMMaterialGroup`。原料／半成品發料也要求 MOState >= 2，分別開啟 `OE_INVMaterialOut.frmINVMaterialOut` 或 `OE_INVSEMIOut.frmINVSEMIOut`。
- Core 新增用料可從 BOM、物料／產品主檔及工單取得計量欄位。所讀標準分支 `RequireQty=MOQty × StdQty × (1 + DecreaseRate)`。正式替代料需求、QPA 分子／分母、指定料與投料點規則仍需依來源分支驗證。舊 Form 把存料列的數量依 MO 查回，再以存料 MaterialNo 與用料 SubstituteMaterialNo 聚合到 CurQty。

## DEV 與家用端 API 交接

- DEV 支援選工單、兩種用料層級、增修、批次刪除、替代料與模擬發料。模擬發料從批號累計本機存料，N/A 替代料使用原料號。DEV 對有存料的列也擋刪除，替代料用手動輸入，未接原庫房配額、查找或扣庫存。工單與用料分開存放，OE202 的守門仍以其自己的 DEV 標記示範。
- 家用端沿用 `/api/oe/manufacturing-orders/{moNo}/materials`，使用四欄鍵與 nullable DataStamp。查詢帶用料層級和存料彙總。新增／修改／替代料用十進位驗證精度與元件身分，交易內重查工單、指定料及存料。發料沿用庫房服務的原料／半成品分流，入帳與扣料必須原子化。OE201／OE202 發放、刪除及 OE207 現況查詢共用工單鎖與正式存料資料。
