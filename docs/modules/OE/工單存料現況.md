# OE207 工單存料現況

- 選單為「工單管理 → 工單 → 工單存料現況」，FunctionNo `MO MATERIAL STATUS`、FunctionKey `OE207`。Vue 入口為 `/YMES/OE/ManufacturingOrderMaterialStock`。
- 已核對 `STD/MESWin/OE/OE_MOMaterialState/frmMOMaterialState.vb` Form 與內嵌 Designer、`wsOE.LoadMOMaterialState`、`wsOE.LoadOEMOMTLState_Component` 及 `kcOE.clsOEBasis`。
- 選工單後以 MONo 查 `TBLOEMOMATERIALSTATE`，顯示料號、批號、單位、量、物料層級／類型、開封日及有效日期。下方元件表以 MONo，以及啟用列的物料與批號查 `TBLOEMOMTLSTATE_COMPONENT`。元件顯示批號、雷刻、載具、槽位、良品量與報廢量。畫面用途為唯讀查詢。

## Oracle 結構與家用端接續

- 存料主表結構見 [OE206](工單用料清單.md)。PowerShell 5.1 + ODP.NET 唯讀取得元件表 DBMS_METADATA 與索引，元件主鍵是 (MONO, MATERIALNO, MATERIALLOTNO, COMPONENTNO)。UseFlag 預設 0、不可空，GoodQty／ScrapQty 為 NUMBER(12,4)。
- [Oracle 元件表 DDL](../../../database/reference/mestest_oe_mo_material_state_component_source_ddl.sql)
- [家用端 PostgreSQL CREATE-only 參考](../../../database/reference/mestest_oe_mo_material_state_component_create.sql)
- 家用端可採 `GET /api/oe/manufacturing-orders/{moNo}/material-stock` 及 `/material-stock/components?materialNo=&materialLotNo=`。選取時以正式料號與批號查元件，清除選取時可讀同工單所有元件。篩選需驗證登入權限、工單身分，存料列保留替代料複合鍵。
