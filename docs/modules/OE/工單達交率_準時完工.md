# OE205 工單達交率（準時完工）

- 選單為「工單管理 → 工單 → 工單達交率（準時完工）」，FunctionNo `MO QUERY3`，FunctionKey `OE205`。Vue 入口為 `/YMES/OE/ManufacturingOrderFinishRate`。
- 依 `STD/MESWin/OE/OE_MOQuery3/frmMOQuery3.vb` 及內嵌 Designer、`wsOE.LoadMOBasis` 與 `clsOEBasis.LoadMOBasis`。

## 查詢與計算

- 沿用 [OE203](工單查詢.md) 查詢與屬性檢視。新增 PlanFinishDate 含端點區間與版本化產品類別。Oracle 用 `ActualFinishDate−PlanFinishDate` 作 `MODiffDay2`；負值為提前、零為準時、正值為延遲。
- 比率分母是篩選後總工單數。缺計畫完工或實際完工日期的筆數留在分母，各分類數不包含該筆。比率顯示一位小數，總工單數為零時顯示 0%。
- `MOLeadTime=ActualFinishDate−ActualStartDate+1`，同日開工完工為 1 天。平均生產天數只除以 LeadTime 非 NULL 的筆數，無有效值時顯示 0，結果最多兩位小數。平均值與完工率使用不同分母。
- 主檔及日期欄位 DDL 共用 [OE201](工單基本資料.md)。家用端可延伸同一個 GET 查詢與 OE204 統計契約。日期篩選、分類及 LeadTime 在同一資料快照計算。保留 Oracle DATE 的時間差與 NULL 行為。

## 公司端 DEV

- 共用 OE201 的假工單。完工報表加上計畫完工起迄日、產品類別、完工差異、單筆與平均生產天數。示範記錄包含提前、準時、延遲及缺實際日期。DEV 日期條件以日含端點，正式資料由家用端接入。
