# OEB01 工單挑片資料查詢

- 選單為「工單管理 → 行業包 → 工單挑片資料查詢」，FunctionNo `B_MO CHOOSE WAFER`。Vue 入口為 `/YMES/OE/ManufacturingOrderWaferQuery`。
- 依 `Industry_Base/MESWin_Industry_Base/OE/OE_B_MOChooseWafer/frmMOChooseWafer.vb` 的 Form／Designer、`Industry_Base.wsOE.LoadChooseWafer`、`tcOE.clsOE_Industry_Base.LoadChooseWafer`。

## 查詢及欄位

- 使用工單編號前綴、訂單／項次、產品／版本與客戶篩選。上表讀 `wsOE.LoadMOBasis`，啟用列時清空舊結果，以 MONo 呼叫挑片查詢。
- Core 讀 `TBLOEMOPROCESS.PSNO` 與 `TBLOEMOBASIS.S_WAFERSOURCE`。0 回未挑片，1 讀來料挑片，2／3 走廠內及自製挑片分支。由 `TBLOEMOCOMPONENT` 讀元件、庫房、料號、批號、供應商、載具、槽位及雷刻。
- `TBLSYSMOCHOOSEWAFERTABLE` 按 PSNo 指定摘要表，名稱清單以逗號分隔。Core 讀實體欄位及已核准 `TBLSYSTESTRECIPEBASIS`，以 ComponentNo 左連接，測項欄有 RecipeType 與 ConversionField／RecipeNo 組成的別名。

## Oracle 與家用端交接

- 工單、流程、元件表 DDL 見 [OE201](工單基本資料.md)。挑片設定表已存在於 [PDB01 結構](../../../database/reference/mestest_prd_choose_wafer_source_ddl.sql)。本輪重新讀其 DBMS_METADATA，確認 FunctionNo 主鍵，另看到 MustSameCassette 預設 1、DataStamp 預設 0。
- `TBLSYSTESTRECIPEBASIS` DDL 確認鍵為 (TESTRECIPETYPE, TESTRECIPENO)，ConversionField 預設 N/A。補查索引時 Oracle 回 ORA-03135，獨立索引字典尚未核實。動態摘要表名及配置值屬站點資料，本輪依公司端範圍查資料字典。
- [Oracle 測試項目表 DDL](../../../database/reference/mestest_oe_wafer_test_recipe_source_ddl.sql)
- [家用端 PostgreSQL CREATE-only 參考](../../../database/reference/mestest_oe_wafer_test_recipe_create.sql)
- 以 `GET /api/oe/manufacturing-orders/{moNo}/wafer-selection` 讀挑片狀態、固定欄、動態欄描述與值。動態來源需從受控配置與已知欄位註冊表解析，按版本及站點授權查詢。需明訂多筆流程／摘要列、重複欄名及未挑片行為。
