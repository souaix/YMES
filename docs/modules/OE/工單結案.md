# OE208 工單結案

- 選單為「工單管理 → 工單 → 工單結案」，FunctionNo `MO CLOSE`、FunctionKey `OE208`。Vue 入口為 `/YMES/OE/ManufacturingOrderClose`。
- 已核對 `STD/MESWin/OE/OE_MOClose/frmMOClose.vb` Form／內嵌 Designer，`wsOE.CloseMO`、`clsOEBasis.chkMOState_Close`、`clsBasis_UPD.SetMOBasisState`。

## 舊流程及正式接續

- Form 拉 IssueState=2、MOState=3 的工單，已結案的列不顯示。多選確認後逐筆呼叫。Service 拒絕不符 IssueState、已結案和 ERP 工單，Core 另重查真實 FromERP。
- `chkMOState_Close` 檢查工單名下持有正數的生產批（LotBasis.LotState<>0、LotState.Status 0–5、CurQty>0），半成品入庫尚有存量、在製報廢正量、不良品等級記錄或元件報廢正量，有任一項即不允許。正式端需重核 WIP 與庫房依賴及廠別設定。
- 通過後將 MOState 置 99，原值保存到 OrgMOState，版本和修改稽核沿用工單主表。資料字典見 [OE201](工單基本資料.md)。
- 家用端可沿用 `GET /api/oe/manufacturing-orders?issueState=2&moState=3`，新增 `POST /api/oe/manufacturing-orders/{moNo}/close`。需根據已鎖定的工單和正式 WIP／庫房條件決定能否關閉，使用 nullable DataStamp 保護競態。工單與能增減依賴記錄的寫入端採一致交易鎖次序，對 ERP 操作套獨立權限及來源驗證。

## 公司端 DEV

- 共用 OE201 的工單。可搜尋、多選，確認後將符合的工單轉 99 並從清單移除，仍能從 OE203 查到。用示範旗標呈現 ERP 與 WIP 擋案，第一筆失敗即停止並顯示已結案筆數。正式生產批、庫房及 ERP 條件待家用端接入。
