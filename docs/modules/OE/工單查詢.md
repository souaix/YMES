# OE203 工單查詢

- 選單為「工單管理 → 工單 → 工單查詢」，FunctionNo `MO QUERY`，FunctionKey `OE203`。Vue 入口為 `/YMES/OE/ManufacturingOrderQuery`。
- 依 `STD/MESWin/OE/OE_MOQuery/frmMOQuery.vb` 的 Form 與內嵌 Designer、`STD/MESws_STD/wsSTD/wsOE/wsOE.cs` 的 `LoadMOBasis` 及 `STD/MESkc/kcOE/clsOEBasis.cs`。

## 查詢規則

- Form 傳訂單／項次、客戶、產品／版本、工單編號前綴、工程／版本、工單類型、工單來源與工單狀態。簽核狀態傳全部。MOState 可多選 0 未確認、1 待簽核、2 確認、3 發放、6 在製品退回、99 結案。未選時省略 MOState。
- Grid 含工單、狀態、數量、未開批量、單位、訂單及項次、產品／工程版本、來源、父工單、計畫完工、客戶批號和 ERP 行號。屬性按鈕以 MONo 動態呼叫 `OE_MOProperty.frmMOProperty`。
- 主檔與屬性 DDL 共用 [OE201](工單基本資料.md)。家用端沿用 `GET /api/oe/manufacturing-orders`，以參數化條件套用 MONo 的前綴與其他篩選。應對照 Oracle 實際文字/數值版本與空值行為，資料與權限由已登入 API 決定。

## 公司端 DEV

- 與 OE201／OE202 共用假工單。查詢視窗使用填值啟用條件、支援來源與工單狀態多選，選定工單後可唯讀查看屬性。公司端以手動欄位輸入替代舊 WIP、PRD、ENT、SYS 查找視窗。未開批量顯示已知 DEV 值，缺值時以該筆工單量示範，待正式 WIP 資料接入。
