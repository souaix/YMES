# OE 工單管理模組總覽

此文件對應 MES 選單的 **OE「工單管理」**。清冊內 13 個功能入口皆已有 WinForms／Service／Core 覆核、Vue DEV 畫面及獨立模組規格；本文件補上跨畫面的入口、流程關係與家用端接手界線。這代表公司端 DEV 與規格交接完成，不代表正式 API／schema 或跨模組交易已上線。

> PM301–PM303 是另一組「保養工單」功能，規格位於 `docs/modules/PM/`；其家用端 schema 前置目前等待三張原生 Oracle 結構資料，不屬於本 OE 選單群組。

## 跨畫面業務脈絡

1. **訂單**：OE101 維護訂單主檔、明細與接收屬性；核准及複製依原 Service/Core。OE102 對已核准且符合狀態的訂單結案。工單可以引用訂單及其未開單量，刪改時須保留這項關聯守門。
2. **工單生命週期**：OE201 建立／修改／複製工單，並涵蓋核准、簽核與發放；OE203 查詢狀態及屬性；OE202 依工單狀態、ERP 來源、生產批及存料情況分流停用或硬刪；OE208 只處理符合來源條件的待結案工單。
3. **物料與元件**：OE206 維護工單用料及替代料，並展示 DEV 模擬發料；OE207 讀取工單存料及元件現況；OE209 維護工單元件。正式寫入需由伺服器重新核對工單狀態、庫存／預約與複合鍵，不能採信前端狀態或稽核欄位。
4. **交期分析**：OE204 以計畫／實際開工差異統計提前、準時與延遲；OE205 依計畫／實際完工計算準時率與生產天數。兩者沿用 OE201 工單資料及各規格所列的日期、NULL、分母口徑。
5. **晶片測試行業包**：OEB01 查詢工單挑片資料與動態測項；OEP01 按晶片測試來源規則開立工單並處理挑片、元件及半成品關聯。動態欄位設定及站點資料來源不可由前端固定值冒充正式設定。

## 家用端 API／schema 接手

- 正式 PostgreSQL schema、migration、登入保護 API、跨表交易及驗收由家用電腦依各單項規格和 `todolist_homepc.md` 接續；公司端不連 YMES PostgreSQL。
- OE101／OE102 共用訂單主檔及屬性 references；OE201 工單主檔及流程／元件／屬性 references 是多項工單功能的結構基礎。各項另有用料、存料、異動紀錄、晶片半成品關聯表等 references，請從對應規格追溯，不重建共用表。
- 對新增、修改、刪除、核准、發放、發料及結案使用伺服器端交易與狀態／DataStamp 檢查；跨訂單、工單、WIP、庫存、ERP、挑片或簽核服務的未完成契約與舊 Core 風險，逐項見規格，不由 Vue DEV 規則推導正式行為。
- Oracle MESTEST DDL／metadata 與 CREATE-only references 只用於結構交接；不匯出業務資料，不執行 Oracle 寫入。
