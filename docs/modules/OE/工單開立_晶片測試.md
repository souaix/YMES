# OEP01 工單開立_晶片測試

- 選單為「工單管理 → 行業包 → 工單開立_晶片測試」，FunctionNo `P_MO BASIS PKG`。Vue 入口為 `/YMES/OE/ChipTestManufacturingOrders`。
- 依 `IC_CP_PKG/MESWin_IC_CP_PKG/OE/OE_P_MOBasis` 的 `frmMOBasis_IC_CP_PKG`、`frmMOBasisDef_PKG`、元件挑選及用料編輯子窗，及 `Industry_Base/MESws_Industry_Base/wsOE/wsOE_Base.cs`、`tcOE.clsOE_Industry_Base`、`kcOE.clsOEBasis`。

## 原 MES 來源

- 主清單用工單／父工單查詢，MOState 只取 0、1、2，MOClass=PKG 或 NULL。新增及修改使用 `Industry_Base.wsOE.AddMOBasis_PSS`／`EditMOBasis_PSS`，刪除及發放走 `DelMOBasis_PSS`／`ReleaseMOBasis_PSS`。核准沿用 `wsOE.ApproveMOBasis`。
- 定義窗有四種訂單來源、工程／廠別／產品／流程、工單及發放單位、半成品來源、挑片、元件與屬性。產品流程可另取 ECN 對應。挑片設定由 FunctionNo 的 `LoadMOChooseWaferTable` 提供 MustChooseWafer、MOClass 等值。表單在非強制挑片時設 WaferSource=2。
- 流程需元件且有強制挑片，或需元件且產品非 Wafer 時，表單要求元件筆數等於工單量、元件單位有效、編號唯一且良品量大於 0。修改若未重新挑片，舊表單傳 `WaferMO=false`。ERP 行號不可手改。
- PSS 新增組工單、用料、流程、元件、屬性、庫房批次與替代料。發放仍核對用料和流程，傳 WaferSource、MustChooseWafer、IsWafer、MOState=3 與舊 DataStamp。部分情境要生成元件、依工單自動發料及更新庫位。這些跨表步驟應納入正式交易與稽核。
