## 畫面與欄位

- 主清單預設 IssueState 0「未凍結」，另有 1「簽核中」、2「已生效」、-1「未使用」狀態頁籤；載入全部狀態後由 Form 篩選。搜尋欄位只有 ToolNo。
- Grid 顯示 ToolNo、ToolName、Description、Creator/CreateDate、Reviser/ReviseDate；IssueState、DataStamp 隱藏。舊 Form 與 Core 沒有明確 ORDER BY／DefaultView.Sort；DEV 依 ToolNo 排序以保持穩定。
- ToolNo 必填、MaxLength 20；ToolName 必填、MaxLength 50；Description 可空、MaxLength 255。ToolNo 與 ToolName 離開輸入欄位時均轉大寫，沒有 Trim。編輯時 ToolNo 鎖定。
- 舊 Form 將 ToolName XML 參數標成 `Integer`，但 `wsEQP.Add/EditToolBasis` 把值讀成字串並交由 Core 寫 ToolName；DEV 以字串處理。
- `clsBasis_UPD.EditToolBasis` 將空 Description 當成未提供，所以修改無法用空白清除原 Description。

## 狀態與操作

- 新增與複製建立 IssueState 0。Copy 可從任一狀態列操作，只預填 ToolNo／ToolName／Description，使用者輸入新 ToolNo 後新增一筆；此功能沒有附屬資料 Copy。
- 修改僅限 IssueState 0，以 ToolNo + DataStamp 更新 ToolName／Description、Reviser／ReviseDate，並增加 DataStamp。
- 多選刪除逐筆處理：0／-1 呼叫 Core 硬刪；2 以版本化狀態更新設為 -1；1 及其他狀態拒絕。多選遇首筆失敗會停止，前面成功列保留。
- 核准只接受 IssueState 0。IssueNo 為 `TOOL BASIS`；無 JobMap 或沒有流程明細時直接 Active=2；有流程時啟動簽核並設 Pending=1，核准 SQL 設 2、退回 SQL 設 0。流程完成用原始 SQL 直接更新 IssueState，該 SQL 沒更新 DataStamp／audit。DEV checkbox 模擬是否有流程。
- 舊 Core 硬刪只刪 `tblEQPToolBasis`，沒有檢查 PM108 Tool Used 引用；PM108 的工具 lookup 不依 IssueState 限制。正式刪除需依 live FK／引用查詢決定拒絕或受控處理。

## 家用端 API／schema handoff

- `database/reference/mestest_first_phase_create_tables.sql` 已有 `tbleqptoolbasis` CREATE 草稿，欄位註解明標為推測：ToolNo varchar(20)、ToolName varchar(50)、Description varchar(255)、Creator／Reviser varchar(10)、IssueState numeric(1)、DataStamp numeric(11)、timestamp 欄位與 ToolNo PK。這份草稿不是已核實 Oracle DDL／metadata，不能據此認定 live PG schema 相同。
- 公司桌機受保護 Oracle MESTEST profile 不存在，本項未連 Oracle；未新增或修改 CREATE SQL。家用端先比對 PostgreSQL live schema／migration 並安全取得 Oracle source DDL／metadata（若其環境允許），核實欄位實型、nullable/default、PK/FK、索引、IssueState 與 DataStamp，再修正或保留既有 CREATE-only reference。
- 正式 API 建議提供有權限且 bounded 的 IssueState／ToolNo 搜尋、穩定排序／分頁；新增主檔、以 ToolNo + DataStamp 修改、狀態命令、按狀態刪除。SQL 一律參數化並記錄 audit。
- 建立與修改需交易內確認唯一 ToolNo。硬刪前核實並處理 `tblPMToolUsedDetail` 等引用，避免孤兒明細；若外鍵限制刪除，回明確業務錯誤。Active→Unused 更新需以版本條件原子執行。
- 正式 Issue workflow 需使用 YMES Issue service 管理。不可照搬舊 Service 的最終直接狀態 SQL而略過 DataStamp／audit；公司端未連 PostgreSQL、未建 schema/API、未部署。
