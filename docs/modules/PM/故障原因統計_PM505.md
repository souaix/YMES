## WinForms 行為

- Form Load 讀 `ChamberManage`、載入 Chamber 設備清單及依名稱排序的 Equipment Type；選取類型時呼叫 `wsEQP.LoadEquipmentBasis` 重載設備清單並清空兩側選取。未啟用 Chamber 管理時設備選項另加 `ChamberFlag=0`，並排除 Chamber 子設備。
- 篩選有 Equipment Type、Equipment No 雙清單、Break Down Time From／To、Repair Time From／To。四個時間控制初始皆勾選，From 預設兩個月前 `00:00:00`，To 預設今天 `23:59:59`。Equipment Type 只提供設備選項；只有把設備移到右側才會成為查詢條件。未選任何設備且未啟用 Chamber 管理時，Query 透過 Additional XML 排除 Chamber；已選設備時直接送 EquipmentNo 清單。
- `LoadSumOfEQPBreakDown` 回傳彙總列：`BreakDownNo`、`BreakDownCause`、`Count`，Grid 依 BreakDownNo 升冪顯示。Query 清除舊結果，取得新摘要後以 ColumnChart 顯示。圖表類型由系統 ValueList `BREAKDOWNQUERY.ChartType` 提供；Form 程式列出 Column、Bar、Line、Pie、Area 五類。Print 呼叫 UltraChart 的 PrintChart；安裝印表機才會啟用。
- Core SQL 將 `tblPMEQPBreakDownLog A`、`tblPMEQPBreakDownLogDetail B`、`tblPMEQPRepairLog C`、`tblPMBreakDownBasis D` 以 BreakdownSerialNo／BreakDownNo 內連，按 `B.BreakDownNo,D.BreakDownCause` 分組並 `Count(*)`。因此只有有對應 RepairLog 的事件會計入；沒有狀態條件。
- Break Down Time 套用 `A.BreakDownStartTime`。畫面標籤 Repair Time 的 From／To 實際由 Service 傳入 RepairStartTime／End，再由 Core 套用到 `C.RepairEndTime`（不是 RepairStartTime）。這個舊欄位映射照實記錄；正式 API 應使用清楚欄位名稱並由家用端決定是否相容舊行為。
- 設備、日期與 Additional XML 由舊 Core 直接拼進 SQL。正式端必須參數化；統計需防止因重複 RepairLog 關聯放大 Count，並確認與舊結果的一致性。
- UltraChart 對折線／面積等圖表會把 BreakDownCause 作為 series 名稱；若同一原因跨多個 BreakDownNo 重複，舊建表邏輯可能遇到重複欄名。資料字典 ValueList 的實際標籤與排序未由桌機 Oracle profile 核實。

## 家用端 API／schema handoff

- 建議唯讀端點 `GET /api/pm/breakdown-statistics`，支援 `equipmentNos`、`breakdownStartFrom`、`breakdownStartTo`、`repairEndFrom`、`repairEndTo` 及安全的分頁／結果上限，回傳 `breakdownNo`、`breakdownCause`、`count`。Repair Time 條件名稱需明確表達查 `RepairEndTime`；設備類型查找不能被誤當為直接統計篩選。
- 統計來源涉及 `tblPMEQPBreakDownLog`、`tblPMEQPBreakDownLogDetail`、`tblPMEQPRepairLog`、`tblPMBreakDownBasis`。需核實 BreakdownSerialNo／BreakDownNo 關聯、RepairLog 一對多規則、原因主檔狀態、欄位型別／長度、PK／FK／索引，確保 Count 不重複放大。
- 公司桌機目前沒有可用的受保護 Oracle MESTEST profile，無法以 PowerShell 5.1 + Oracle.ManagedDataAccess 讀取四表 DDL／metadata。可信 PostgreSQL CREATE-only SQL 及鍵／索引待家用端核 live schema 與同版 MESTEST 後提供；未猜測或新增 CREATE SQL。公司端不連 PostgreSQL、不實作正式 API/schema。
