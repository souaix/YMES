# PM507 故障維修登錄查詢

## 功能與來源

- FunctionNo：`BREAKDOWN_REPAIRQUERY`
- FunctionKey：`PM507`
- WinForms：`D:\iMES\CSiMES\STD\MESWin\PM\PM_BreakDown_RepairQuery\frmBreakDown_RepairQuery.vb`（畫面與 Designer 初始化同檔）
- Service：`D:\iMES\CSiMES\STD\MESws_STD\wsSTD\wsPM\wsPM.cs` 的 `LoadBreakDown_RepairQuery`
- Core：`D:\iMES\CSiMES\STD\MESkc\kcPM\clsPMMaintanceLog.cs` 的 `LoadBreakDown_RepairQuery`

此頁唯讀列出設備故障登錄與關聯維修記錄。直接資料表 DDL／metadata 尚未核實；公司桌機沒有可用的受保護 Oracle profile，故不提供猜測的 CREATE SQL。

## WinForms 條件與操作

- EquipmentNo checkbox 啟用設備條件；`...` 開啟 `frmCOMSearch_Multi` 多選設備，取消 checkbox 會清空設備文字。沒有選設備時不限制設備。
- 三組日期時間區間各有一個 checkbox：`BreakDownStartTime`、`RepairStartTime`、`RepairEndDateTime`。視窗載入時各 From 預設 Now−3 months、To 預設 Now，但 checkbox 預設未勾選，故日期初值不會直接套用。
- 每組日期區間啟用時必須有 From 與 To，且 From 必須嚴格早於 To。Core 以 `>= From` 及 `<= To` 比較完整時間。
- 狀態 checkbox 為 UnConfirm=0、Waiting=1、CLOSED=2。三者全部未勾選時代表全部狀態；勾選一個或多個時才限制狀態。
- Query 執行條件檢查並載入唯讀 Grid；Close 關閉視窗。沒有新增、修改、結案或刪除操作。

設備條件由 `wsEQP.LoadEquipmentBasis(IssueState=defInteger)` 提供；當 `ChamberManage` 不等於 `1` 時，Service 呼叫附加 `ChamberFlag=0`，不列子設備。查詢結果載回後，WinForms 再依設備 lookup 清單過濾結果。

## Service／Core 查詢邏輯

Service `wsPM.LoadBreakDown_RepairQuery` 解析設備逗號清單、狀態 pipe 清單、三組日期端點及 AdditionalXml，再呼叫 `clsPMMaintanceLog.LoadBreakDown_RepairQuery`。

Core 建立兩個同欄位結果集並 UNION：

1. 未結案／處理中的故障列來自 `tblPMEqpBreakDownState`，直接帶 State、BreakDownStartTime、故障描述／建立者／建立時間，以及目前維修序號、開始時間、維修人；BreakDownEndTime、RepairEndTime、RepairDescription 以空值輸出。
2. 已結案列來自 `tblPMEQPRepairLog A` 內連 `tblPMEQPBreakDownLog B`，關聯條件為 `A.BreakDownSerialNo = B.BreakDownSerialNo`，State 固定為 2。維修序號、時間、人員及描述取 A，故障結束時間、故障描述與故障建立者／時間取 B。同一故障若有多筆 RepairLog，Core 會輸出多列。

設備與三組日期條件會同時套到兩個分支。State 空值時不加狀態條件、直接 UNION 全部；只選 CLOSED 時只查第二分支；選到 CLOSED 加其他狀態時，第一分支按所選狀態過濾，再 UNION 第二分支；未選 CLOSED 時只查第一分支的所選狀態。

Grid 顯示 13 欄：BreakDownSerialNo、EquipmentNo、State、BreakDownStartTime、BreakDownEndTime、BreakDownDescription、BreakDownCreator、BreakDownCreateDate、RepairSerialNo、RepairStartTime、RepairEndTime、RepairUserNo、RepairDescription。狀態 ValueList 顯示 UnConfirm／Waiting／CLOSED。

## 舊程式問題與 Vue DEV 行為

Form 的 `funLoadData` 在 RepairStartTime 區間啟用時，From 使用 `dteRepairStartStartDateTime`，但 To 參數 `RepairStartDTTo` 誤取 `dteRepairEndEndTimeTo`；應使用 Repair Start 的結束控制項 `dteRepairStartEndDateTime`。另 Repair Start 結束控制項的 Click handler 綁到開始控制項事件。Vue DEV 依欄位名稱使用自己的 RepairStart From／To，將兩個來源問題留在 handoff，不模仿錯誤值。

Vue 頁在 `web/src/components/PmBreakdownRepairQuery.vue` 與 `PmBreakdownRepairQueryDevPreview.vue`。以假資料完成設備 checkbox／多選、三組完整日期時間範圍、狀態多選、起訖檢查、Query 與 13 欄結果。未選狀態模擬全部；設備清單及結果排除 ChamberManage 關閉時的子設備。結果為唯讀。
