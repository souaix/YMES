# WP204 生產批執行_設備

## 功能識別

- 三層選單：在製品管理 → 在製品 → 生產報工 → 生產批執行_設備。
- FunctionNo：EXECUTE LOT_EQP；FunctionKey：WP204；Form：frmEquipmentLotState；ExecutionFile：WP_EquipmentLotState.dll。
- DEV 路徑：/YMES/WIP/EquipmentLotState。頁面只用本機假資料及 localStorage。
- WinForms 為最大化設備看板，Designer ClientSize 1008×591。收藏設備按 PageNo 分頁，每頁最多 15 台。

| 層次 | 來源 | 職責 |

初始化以 ComputerName 最後一段形成 HostName，從 TBLEQPFAVORITE 載入 PageNo 與 EquipmentNo。設備狀態由 wsEMS.LoadEquipmentStateJoinColor 取得；再讀取設備上的暫存批次與 LoadPort。Load Available Lots 勾選時才呼叫 wsWIP.LoadAvailableLotOnEQP。卡片呈現 EquipmentNo、狀態及顏色、可用批次數、占用／總 LoadPort、各埠批次占用及 AutoFlag。點擊選取、雙擊開 LoadPort 明細、右鍵開 LoadPort State／Available Lot／Equipment State Log。

## 畫面與按鈕

- 左側：Host 收藏設備 PageNo。每頁 15 台，不是設備狀態篩選。
- 上方：Availd Lot、LoadPort State、Lot Info、Lot Log、EQP Log、Recommand、Load Available Lots、Hold Lot by EQP、說明、Refresh、頁碼。
- Recommand 啟用時，Availd Lot 按鈕改開 LOTRESERVATION；否則開可用批次清單。Load Available Lots 關閉時卡片數量顯示 N/A。
- 主區：5 欄×3 列設備卡；設備狀態色由狀態設定決定，AutoFlag 顯示自動／人工／未設定邊框；紅色 LoadPort 表示有在機批次。
- 底部：Check In、Check Out、Hold Lots、Eqp Change State、Carrier Check In、Carrier Check Out、QC List、General Check In/Out、Close。

## 交易與家用端 API handoff

- Check In／Out 不是設備或 Lot 的簡單 CRUD。WinForms 子視窗會走共用 wsWIP.ExecuteLot，視狀態執行 TriggerOP、Business Rule、TransferLot 等交易分支；家用端須依 WP201 規格重用同一套執行流程。
- 看板 API 依登入者及受授權工作站查設備收藏、狀態、LoadPort 與在機批次；支援分頁。候選 Lot API 必須由後端重算 Recommand、產品流程、SMD Area、設備群組、設備狀態與 LoadPort，不可相信前端提供的資格結果。
- Check In/Out、Carrier、Hold、狀態變更用受權限保護的 POST command。後端重讀 Lot、Equipment、LoadPort、狀態及 LotStamp，採交易鎖或 CAS，保留 WP201 的 TriggerOP／BR／TransferLot、QTime/LMS、ERF、SPC/QC、設備及 operation log 語意。
- QC List、Lot Log、EQP Log 為依授權的唯讀 API；以登入者識別、參數化查詢、分頁及明確錯誤碼保護。
- 四表 CREATE-only 是來源結構參考，不代表都須新增；先核對 YMES PostgreSQL live schema/migrations。不得因此複製 WP101/WP201 已有資料表。

## DEV 簡化與驗收界線

- 使用固定 30 台設備、兩個 PageNo、固定推薦批次及點檢資料；不讀取真實 HostName 收藏。
- DEV Check In/Out 只配置／釋放假 LoadPort；未模擬掃碼、LotStamp、Business Rule DLL、TriggerOP、TransferLot、Future Hold/Wait/OS、Carrier protocol、QTime/LMS、SPC/QC 或 ERP side effects。設備 Hold／狀態也只改 localStorage。
- 推薦畫面沒有重建 Core 的資格過濾、排序、預約及副作用；Lot Info、歷程、QC 子視窗只呈現示範欄位。
- DEV key：ymes.dev.wp204-equipment-lot-state.v1。不得呼叫 Oracle、YMES PostgreSQL 或正式 API。
- 公司端未建 API／migration，未連 PostgreSQL，未執行 build、test 或 browser。
