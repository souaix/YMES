# WP915 生產批產品變更作業

- `CHANGELOTPRODUCT` 對應 `STD/MESWin/WIP/WP_ChangeLotProductOperation/frmChangeLotProduct.vb` 和 Designer。工單、批、區段、產品條件查 `LoadLotBasisJoinState`；LotBasis.LotState 1／2／3／4／11，ProductChangeUpdDetail 啟用時畫面另限 LotState.Status=0。
- 聯產品來源由參數決定，可從產品主檔取，也可依 ERP 聯產品資料（TIPTOP／T100／E10ICD 分支）取。ERP 分支以勾選資料驗證相同來源產品，並核 ERP 回傳與 MES 產品版本及使用狀態。確認前檢查目標產品、版本、單位，整批包裝預檢通過後逐批呼叫 `wsWIP.ChangeLotProduction`。遇錯停止後續，前面成功保留。
- STD Service 送 `kcWIP.clsLot.ChgProductOperation`（操作 6、產品變更類型 1、啟用 ReleaseLog）。來源與目標產品號相同直接返回。Core 重讀狀態，簡單模式更新 LotBasis 的料號／版本／投入單位，依條件同步半成品庫；明細模式按排隊／執行／完成／入庫狀態分支核對產品流程、站點、ECN、LotStamp，並重建相應流程與版本、記回復及稽核。不得用單表更新代替這些分支。
- 主直接表與既有依賴見 [WP101 LotBasis／State](../../../database/reference/mestest_wip_wp101_create.sql)、[WP201 ECN](../../../database/reference/mestest_wip_wp201_create.sql)、[WP902 存回復資料表](../../../database/reference/mestest_wip_wp902_create.sql) 及 PRD、PRS、半成品庫、Lot ReleaseLog 既有參考。此交接未新增直接核心表定義；正式分支的欄位與外部合約仍逐項核證。
