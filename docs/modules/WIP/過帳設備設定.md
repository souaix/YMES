| 項目 | 來源 |

## 主畫面

- WinForms 視窗 `frmEquipmentFavorite` 初始最大化，Designer 基準尺寸 784×561。左 Grid 列出目前 HostId 的收藏 PageNo，右 Grid 顯示所選頁面的 EquipmentNo；右側按鈕為 ADD、EDIT、DEL、COPY、Close。
- HostId 由 `gComputerName` 去掉最後一段 `/` 與其後文字產生。此資料是工作站範圍收藏，不是使用者收藏。主畫面載入時呼叫 `LoadEQPFavoritePage(HostId)` 與 `LoadEQPFavorite(HostId)`，點選左 Grid 後用 PageNo 篩出右 Grid 的設備並依 EquipmentNo 排序。
- Add 開空白維護窗；Edit 只對目前作用中的 PageNo 開窗且 PageNo 唯讀；Copy 以作用中的頁面和設備作為初始內容，PageNo 可修改。
- Delete 先將作用中列納入選取，再確認刪除所有選取列；之後逐一呼叫 `DelEQPFavorite(HostId, PageNo)`。來源逐列刪除，若中間失敗，前面成功刪除不會回復；完成迴圈後重新載入兩個 Grid。

## 新增／編輯／複製視窗

- `frmEquipmentFavoriteDef` Designer 尺寸 804×566。左側為已核准 EquipmentType Grid 及 PageNo；右側上方為該類別可選設備，下方為已選設備，中間有向下加入與向上移除按鈕。HostId 欄位不可見。底部有 Confirm、Close、Apply。
- 載入全部 `IssueState=2` 的 EquipmentType 與 EquipmentBasis。選取類別後以該 EquipmentType 篩選設備，只顯示 `ChamberFlag=0`，依 EquipmentNo 排序。設備資料列的 EquipmentNo 可見，其餘資料欄隱藏。
- 編輯與複製先從 HostId/PageNo 載入收藏設備並勾選。編輯的 PageNo 唯讀；新增／複製可輸入 PageNo。
- 向下加入按鈕取全部已勾選設備；必須至少一台，最多 15 台。選取結果以 EquipmentNo 排序。向上按鈕移除已選 Grid 中勾選的列；若未勾選列，來源程式會以目前作用列作移除目標。
- Confirm 與 Apply 均需 PageNo 非空及至少一台設備。Add/Copy 才檢查 HostId+PageNo 是否存在；若存在詢問是否取代。Edit 不詢問重複。取代時 Service/Core 先刪除此 HostId/PageNo 的舊明細，再逐設備新增；Confirm 儲存後關閉，Apply 儲存後保留視窗。
- ADD/COPY 的「取代」確認與儲存不是同一個 WinForms request，但 Web API 應以同一資料庫交易完成該頁的刪除與重建，並在交易內重驗頁面狀態。

## 資料表與原始限制

| Oracle 表 | 本功能用途 | 結構依據 |
|---|---|---|
| `TBLEQPFAVORITE` | HostId、PageNo、EquipmentNo 收藏關聯；WP203 寫入與 WP204 設備生產批載入共用 | `database/reference/mestest_wip_wp204_source_ddl.sql`、`mestest_wip_wp204_create.sql` |
| `TBLEQPEQUIPMENTTYPE` | 已核准設備類別清單 | `database/reference/mestest_equipment_type_*` |
| `TBLEQPEQUIPMENTBASIS` | 已核准設備及 EquipmentType/ChamberFlag | `database/reference/mestest_equipment_basis_*` |

WP203 沒有新增 Oracle table。`TBLEQPFAVORITE` Oracle source DDL 為 HostId、PageNo NOT NULL，EquipmentNo nullable；沒有 PK、unique index、一般 index、FK 或 trigger。PostgreSQL 空表 CREATE-only 已由 WP204 建立；不可因 API 查重方便而自行補 Oracle 不存在的資料庫唯一鍵。Equipment Type/Basis 使用已存在的 DDL reference，不重複查詢或產生 SQL。

## Vue DEV 假資料頁

- 路徑 `/YMES/WIP/EquipmentFavorites`，三層選單 FunctionNo `EQP FAVORITE SETUP`。
- Development Preview 使用隔離 localStorage：`ymes-dev-mock:wip-eqp-favorite:pages:v1`、`ymes-dev-mock:wip-eqp-favorite:equipment:v1`，只代表一個虛構工作站的假資料；HostId 維持隱藏，與 WinForms 表單一致。假資料不能代表 Production 的工作站授權或身份。
- UI 保留左右收藏頁／設備 Grid、右側 ADD/EDIT/DEL/COPY/Close、雙 Grid 編輯窗、類別切換、Check、▽/△、15 台限制、頁面重名取代確認、Confirm/Apply 差別及多選逐列刪除。Production 不讀寫 localStorage。

## 家用端 Production API handoff

| 方法 | 路徑 | 規則 |
|---|---|---|
| GET | `/api/wip/equipment-favorites` | 回傳已解析 Host 範圍的收藏 PageNo。不可接受任意 HostId query 作授權範圍。 |
| GET | `/api/wip/equipment-favorites/{pageNo}` | 回傳該 HostId/PageNo 的設備清單。參數化查詢並驗證此 Host 頁面可見。 |
| GET | `/api/wip/equipment-favorites/options?issueState=2` | 一次回傳 `equipmentTypes`（對應已核准 EquipmentType）及 `equipment`（已核准 EquipmentBasis，至少含 EquipmentNo、EquipmentType、EquipmentName、ChamberFlag、IssueState）。候選設備只允許 IssueState=2 且 ChamberFlag=0。 |
| POST | `/api/wip/equipment-favorites` | body `{ pageNo, equipmentNos, replaceExisting }`。新增／複製需要非空 PageNo、1–15 個不重複且核准的主設備。若同 HostId/PageNo 已存在且 `replaceExisting=false` 回 409；使用者確認取代後才送 true。交易內再查核後刪舊明細及重建。 |
| PUT | `/api/wip/equipment-favorites/{pageNo}` | body `{ equipmentNos }`。PageNo 固定不可改；重驗 1–15 個設備後原子替換該頁設備。 |
| DELETE | `/api/wip/equipment-favorites/{pageNo}` | 刪除單一頁面的收藏明細。WinForms 多選刪除是逐頁呼叫，故部分成功時回報成功／失敗清單或讓客戶端逐頁呼叫並明確呈現已完成項。 |

### HostId 的 Web 身份邊界

WinForms 的 HostId 來自客戶端 `gComputerName`，不等同登入者。Web API 不得接受瀏覽器任意傳入 HostId 後直接讀寫其他工作站的收藏。家用端需由可信登入 session/伺服器端登記的 client workstation context 解析 HostId；若現有登入架構沒有可靠的工作站識別，先提出可追溯的 workstation binding 設計，不能退化為使用者可改的 query/body，也不能把 HostId 改成 UserNo 而不記錄產品語意變更。

由於來源表無唯一鍵，多台 Web API instance 同時新增／取代同一 HostId/PageNo 時，須以 PostgreSQL transaction-scoped advisory lock（依 HostId/PageNo 固定雜湊鍵）或同等跨 instance 序列化機制避免重複；不要新增 source 未有的 unique constraint。清單與寫入需登入保護、WP203 功能授權、Equipment IssueState/ChamberFlag server-side 重驗、參數化 SQL 及適當審計。
