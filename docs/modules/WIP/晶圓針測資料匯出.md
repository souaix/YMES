# WPP02 晶圓針測資料匯出

## 來源與入口

- FunctionKey WPP02，清冊功能 P_WAFERMAP EXPORT，Form `frmWIPWaferExport`，分類「芯片測試生產管理」。主 Form 和 Designer 同在 `D:\TP-iMes\iMES_THEIL_TP\IC_CP_PKG\MESWin_IC_CP_PKG\WIP\WP_P_WaferExport\frmWIPWaferExport.vb`；沒有獨立 Designer 檔。
- Service：`IC_CP_PKG\wsIC_CP_PKG\wsWIP\wsWIP.cs` 的 `ChkLotNoForWaferMAP`、`LoadWaferMAPDataByLotNo`、Wafer Bin Summary extension 查詢；`wsSYS\wsSYS.cs` 的 `LoadSYSWaferExportBasis`、`LoadSYSWaferExportDetailAndHeader`。
- Core：`MEStc_IC_CP_PKG\tcWIP\clsLot.cs` 的 `ShowJoinWaferExportBasisByLotNo`、`LoadWaferMAPDataByLotNo`；`tcSYS\clsSYSEng.cs` 的匯出 Basis／Detail／Header 查詢。檔案格式產生器為 `iMES_Service\iMESWaferMAPHandler\clsWaferExportHanlder.vb`，使用 NPOI 產生文字 MAP 與 Excel 類輸出。
- Vue DEV fallback：`/YMES/WIP/WaferMapExport`。只用固定 Lot／Wafer／匯出設定 fixtures 和本機 DEV 操作紀錄；不呼叫 MES Service/API，不讀寫本機檔案、不執行 FTP／File Service、不連 Oracle 或 PostgreSQL。

## 查詢與選擇

- LotNo 必填；Query 先檢查 Lot 是否存在，再載入 Lot／Customer／Product 關聯、Wafer MAP、Bin Summary、Bin Define、產品／工單屬性、Component、Contact Attribute／Equipment 與匯出設定。沒有 Wafer MAP 時清空輸出明細並停止。
- `ChkLotNoForWaferMAP` 另外確認 Lot Basis／Component State、匯出 Basis、MAP／Bin Summary 資料；Ship MAP 有 Combo MAP 設定時檢查其中各 OP 站是否有 MAP 或 Bin Summary。
- MAP 查詢會傳 `LotNo`、`LoadMAPCoordData=Y`、`CurVersion=1`。有 Combo MAP 指定 OP 時傳 OP 清單；否則傳 `ShipMap=Y`。WinForms Designer 的 OPNo 搜尋欄與 Current MAP 按鈕均為隱藏控制，不在 DEV 顯示。
- Wafer 清單可逐列勾選、全選或全取消。可見欄位為 Sel、MONo、CustomerLOTNo、WaferSlotNo、OPNo、WaferFlat、TotalTestQTY、TotalPassQTY、StartTestTime、UploadTime；Current Version 欄位與 WaferId 欄位被隱藏。選取組合若 `SlotNo + OPNo` 重複，Export 會拒絕；至少選一片且須有對應 Bin Define。

## 匯出設定與產生

- Basis 設定表為 `tblSYSWaferExportBasis`。載入時優先匹配 CustomerLotNo + ProductNo，再依序退到產品精確／CustomerLotNo `*`、ProductNo `*`／Customer Lot 精確、兩者 `*`。`FunctionFlag=1` 為 Automatic、`0` 為 Manual；模式切換後按 Lot／Product／FunctionFlag 讀取 Detail 與 Header。
- 來源有兩個設定選取風險：載入 Basis 後固定勾 Automatic 的 CheckedChanged handler 會把 `FunctionFlag` 設為 1，即使剛匹配的 Basis 記錄原值為 0；Export 又只以 ProductNo + FunctionFlag 選 Basis、未帶 CustomerLotNo，若相同產品有多組 customer lot 設定可能取到不確定的第一列。DEV 依已解析的 Lot／Product／FunctionFlag 顯示設定；正式 API 應把 resolved CustomerLotNo、ProductNo、FunctionFlag 作為完整 key，並決定沿用或修正舊畫面行為。
- Basis 顯示 TargetFolder、FilePatten、CompressAllFile、FTPFlag 等欄位。Detail Grid 可見 ProductNo、ItemNo、ExportFormat、TargetFolder、FilePatten；Set Folder 對目前明細列選擇輸出目錄。Header 依 CustomerLotNo／ProductNo／FunctionFlag／ItemNo 關聯明細，控制輸出欄位與值映射。
- Export 複製所選 Wafer、對應 Bin Summary／Bin Define、MO Component、Bin Summary extension、Product／MO Property、Contact Attribute／Equipment 與額外資訊，按 Detail 的 `ExportFormat` 產生 MAP／文字／Excel 輸出。支援多種 CP 客戶格式；格式專用 Bin symbol mapping、Header mapping、檔名 token、壓縮與 FTP 目的地會影響內容及路徑。
- DEV 頁模擬 Lot 精確查詢、設定 wildcard 選擇、Automatic／Manual、Wafer 多選、明細模式切換、Set Folder、duplicate SlotNo+OPNo 守門、缺 Bin Define 對帳與檔名 manifest。只產生虛構輸出清單；不生成檔案、Excel、ZIP，不存取使用者路徑，不上傳 FTP。

## 資料表與交接限制

- 匯出設定直接讀取 `tblSYSWaferExportBasis`、`tblSYSWaferExportDetail`、`tblSYSWaferExportHeader`。Wafer 查詢直接使用 `TBL_CPWIPWAFERMAP`、`TBL_CPWIPWAFERBINSUMMARY`、`TBL_CPWIPWAFERBINDEFINE`，並連接 Lot／MO／Customer／Product、Lot State、Scrap component、MO Material／Property／Component、Product Property、Contact Attribute／Equipment 等共用資料。BumpCode 與 Bin Summary extension 亦有額外來源查詢。
- 桌機兩個既知 Oracle attachment 路徑均不存在，沒有可安全使用的本機 MESTEST profile；本輪未查 Oracle DDL／metadata、未查業務資料、未連 YMES PostgreSQL，也未猜欄位型別、PK、constraint、index、default 或 CREATE-only SQL。上述設定三表與 CP Wafer MAP／Bin tables 的同版 DDL／metadata 是明確缺項；家用端先核 PostgreSQL live schema／migration，再決定任何 schema 變更。
- 正式 API 應以登入身分及權限限制 Lot，參數化查詢；保留配置匹配順序、FunctionFlag、Combo MAP OP／ShipMap、目前 MAP、Bin Define／Summary、產品／工單屬性與檔名格式語意。檔案生成應在 server 端採格式 allowlist 與安全輸出位置；FTP credential、遠端 host／path 只從 server 受保護設定解析，不能接受 browser 任意路徑。回傳逐檔生成結果與可下載 manifest，處理 ZIP／Excel／MAP format、同名覆寫及失敗結果。
- 原始 FunctionOrder 尚未由可讀清冊保存；桌機受保護 Oracle profile 不存在，無法核實 WPP02／WPP04／WPP08 的精確先後。此次依未完成 FunctionKey 數值先交付 WPP02；後續有安全 Oracle profile 時再補核順序，不以猜測的次序覆蓋既有交接。
