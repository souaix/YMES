## WinForms 畫面

原視窗最大化，設計尺寸 804×578。最上方是 LotNo、Position 輸入框；右側是 Put In、Takes Out、Clear Carrier。中間上方 `CarrierState` Grid 顯示載具主現況，下方 `CarrierState Detail` Grid 顯示所選載具內容；底部有 StatusBar 與 Close。LotNo 與 Position 是黃色可輸入欄位。兩個 UltraGrid 都隱藏 GroupByBox。

| WinForms 控制項／欄位 | 行為 |
| --- | --- |
| LotNo、Position | 手動輸入批號與起始位置。Put In 檢查 LotNo 非空、Position 是大於 0 的正整數。`...` 選批按鈕在 Designer 預設隱藏。 |
| Put In | 必須先選載具。批號若在 Stocker 中即禁止；批號還必須存在，`LotState=1` 且 `Status` 為 0–5。沒有元件時在指定位置放一列 `ComponentNo=N/A`；有元件時逐元件放入，位置依序遞增。 |
| Takes Out | 必須選取一列 Detail，確認後依 CarrierNo + ContentID 移除該批號內容；同一批號的所有元件列會一起取出。批號不在可管理的 lot state 時，要求先執行 Carrier Management Comp。 |
| Clear Carrier | 必須選取載具並確認；逐筆確認其 ContentID 仍有 lot state，再清除該載具全部 Detail。無法核對的批號會要求先做 Carrier Management Comp。 |
| CarrierState Grid | 顯示 CarrierNo、CarrierCategory、CarrierType、CarrierState、Description；選列後載入該載具 Detail。狀態值由 `TBLWIPCARRIERSTATE.CARRIERSTATE` ValueList 顯示。 |
| Detail Grid | 實際可見欄位為 CarrierPosition（Position）、ContentID（LotNo）、BCIP（UserNo）、ComponentNo。`Flag`、CarrierNo 等欄位不顯示。 |
| Carrier Change、Lot Change | Designer 預設隱藏，且由 `ExeGroupControlPriv(Me, PrivFunNo)` 管理權限。前者切換 CarrierState 0/1；後者切換所選 Detail 的 Flag 0/1。Vue DEV 將兩項放在預設收合的權限操作區。 |
| Close | 關閉功能視窗。 |

## 查詢與業務規則

1. Form Load 先載入 CarrierState ValueList，再呼叫 `wsEQP.LoadCarrierState` 取全部載具現況。選取載具後呼叫 `wsEQP.LoadCarrierStateDetail(CarrierNo)`。
2. 放入批號先呼叫 `wsINV.LoadStockerState(LotNo)`；有 StockerNo/LocatorNo 時禁止上載具。接著 `wsWIP.LoadLotBasisJoinState` 以 `Status=0|1|2|3|4|5`、`B.LotState=1` 查批次，並另呼叫 `wsWIP.LoadComponentState(LotNo)` 取得元件列。
3. 每個 Unit 逐一呼叫 `wsEQP.CheckPutsOnUnitID`。Core 檢查 LotNo 存在、同一 ContentID/ComponentNo 不在其他載具、CarrierNo 存在、以 `TBLEQPCARRIERTYPE.CarrierLayer × CarrierCapacity` 計算容量、載具總量未滿、目標 Position 空白且沒有超出總容量。來源有「同一作業站」註解，但此方法目前沒有相應查詢。
4. `wsEQP.AddCarrierStateDetail` 新增 CarrierNo、CarrierPosition、BCIP（登入者）、ContentID、Flag=0、LotNo、ComponentNo；同批次 `TBLWIPLOTSTATE.CarrierNo` 設為 CarrierNo，載具 `CarrierState` 設為 1。元件批次逐列檢查與新增，若後一列檢查失敗，之前成功的列不回滾；需保留部分成功的回覆語意。
5. 取出與清空呼叫 `wsEQP.DelCarrierStateDetail`。Core 先按範圍寫 `TBLWIPCARRIERSTATEDETAILLOG`，再刪 Detail、清除 lot state 的 CarrierNo。單筆取出只傳 ContentID，故一批多元件時會整批移除，不是只移除選到的一個 ComponentNo。
6. `Carrier Change` 呼叫 `EditCarrierState`；`Lot Change` 呼叫 `EditCarrierStateDetail` 更新 Flag。兩者在 WinForms 預設隱藏，後端必須保留 Function/控制項授權。
7. **來源相容性注意：** `DelCarrierStateDetail` 在刪除 SQL 尚未執行前先查舊 Detail 數量，只有舊數量小於等於 1 才排入 `CarrierState=0` 更新。若一次刪多列，載具清空後可能仍顯示狀態 1。WP302 DEV 依來源重現此行為；若正式 API 改為依刪除後內容數校正，應把它記為明確的行為修正。
8. Core 寫入內容歷程時取得 LotSerial/LogGroupSerial 及原 Detail 欄位，但此呼叫未指定 PutInTime/TakeOutTime；三張表 metadata 也沒有此功能的 Trigger。不要在重製時臆測歷程時間由此流程自動寫入。

## 資料表與 Oracle DDL

本機 Windows PowerShell 5.1 + Oracle.ManagedDataAccess 使用受保護 Oracle profile 直連 MESTEST，只查 `ALL_TABLES`、DBMS_METADATA DDL 與欄位／約束／索引／Trigger metadata，未讀業務資料列，未執行 Oracle DDL/DML。

| Oracle 表 | 功能用途 | MESTEST 結構結果 | YMES reference |
| --- | --- | --- | --- |
| `TBLWIPCARRIERSTATE` | 載具現況主表 | 已有既存 reference | `mestest_carrier_basis_dependencies_*` |
| `TBLWIPCARRIERSTATEDETAIL` | 載具位置與 Lot／Component 關聯 | 11 欄、7 個 NOT NULL constraint；無 PK；`I_TBLWIPCARRIERSTATEDETAIL_01` 是 ComponentNo 非唯一索引；無 Trigger | 本模組 source DDL／metadata／CREATE-only |
| `TBLWIPCARRIERSTATEDETAILLOG` | 載具內容移除歷程 | 18 欄、9 個 NOT NULL constraint；沒有 PK／Index／Trigger | 本模組 source DDL／metadata／CREATE-only |
| `TBLINVSTOCKERSTATE` | 禁止把 Stocker 內批次放入載具 | 8 欄；PK `(STOCKERNO, LOCATORNO, CONTENTNO)`；無 FK／Trigger | 本模組 source DDL／metadata／CREATE-only |
| `TBLEQPCARRIERTYPE` | 提供 CarrierLayer、CarrierCapacity | 已有既存 reference | `mestest_carrier_type_*` |
| `TBLWIPLOTBASIS`、`TBLWIPLOTSTATE`、`TBLWIPCOMPONENTSTATE` | Lot 查詢、CarrierNo 關聯、Component 清單 | 已有既存 reference | `mestest_wip_wp101_*` 等 |

新查證表的 DDL 與欄位 metadata：

- [Oracle source DDL](../../../database/reference/mestest_wip_wp302_source_ddl.sql)
- [MESTEST metadata](../../../database/reference/mestest_wip_wp302_metadata.txt)
- [PostgreSQL CREATE-only 參考](../../../database/reference/mestest_wip_wp302_create.sql)

載具 Detail 與 DetailLog 在 Oracle 本身沒有主鍵；CREATE-only 未新增主鍵、外鍵或唯一索引。家用端需先比對 PostgreSQL live schema／migration history，再為確實缺少的表新增 forward migration。

## DEV 頁面範圍

Vue 頁依 WinForms 佈局提供批號／位置輸入、載具現況 Grid、選取載具內容 Grid、放入、取出、清空、確認對話框及關閉。DEV 假資料涵蓋空載具、一般 Lot、有多個 Component 的 Lot、Stocker 中 Lot、不可用狀態 Lot、容量與 Position 驗證。假資料存在 `ymes.dev.wp302-carrier-state.v1` localStorage；正式 API 未接線，非 DEV 模式停用資料異動。畫面沒有載具查詢條件，進入時載入整張現況表。
