# WP903 批次刪除已下線生產批

- FunctionNo 為 `DELETE BATCH LOT`。依 `STD/MESWin/WIP/WP_DelBatchLot/frmDELBatchLot.vb` 及內嵌 Designer，查 `wsWIP.LoadLotBasisJoinState` 固定 LotState=1、Status=0／1／4。來源批、工單、產品依對應勾選框增列過濾；取工單、產品分別走 `wsWIP.LoadMOBasis` 和 `wsPRD.LoadProduct`。Grid 提供全選、取消全選、單項勾選與反白列／儲存格轉為勾選。
- 刪除確認後，先將所有勾選批送 `wsWIP.CheckLotPackage`，任一已包裝即整批停止。通過預檢後依 Grid 順序逐批呼叫 `LoadReverseHistory` 與 `DelReleasedLot`。有歷程傳 ReverseId=1。單筆刪除失敗會報批號、原因並繼續，最後重查列表。
- 正式刪除委派相同 STD Service、`udReverse.clsReverse.DeleteReleasedLot` 與相關表，沿用 [WP902 API、Oracle metadata 及 CREATE-only](刪除已下線生產批.md)。工單與產品查找沿用既有 master，WP903 無新直接表。

## DEV 與家用端

- `/YMES/WIP/ReleasedLotBatchDelete` 用勾選式過濾、候選輸入、表格逐項選取、全選、清除選取與確認演示流程。DEV-BD003 可演示整批包裝阻擋，DEV-BD001/002 同選可演示一筆成功及一筆失敗。欄位縮為選批所需，不模擬反白儲存格轉勾選、實際逆向交易，離開頁面重置。
- 建議登入及 WP903 ACL 保護的 `POST /api/wip/released-lots/batch-delete`，傳每批 lotNo、預覽版本及冪等鍵；重用 WP902 的有權限查詢與單筆交易。開始前先對所有目標做統一包裝與可見範圍預檢，執行時逐批重驗版本和狀態。回傳已刪除、失敗、未執行清單及原因，使部分成功可稽核和安全重試。
