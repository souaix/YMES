# WP909 換廠作業

- `TRANSFER FACTORY` 對應 `STD/MESWin/WIP/WP_TransferFactory/frmTransferFactory.vb` 與內嵌 Designer。區域、作業站和廠別取自 SMD／OP lookup。查詢 `LoadLotBasisJoinState` 固定 Status=0，可帶原廠、區域、OPNo。Grid 勾選一批或多批後，設定目的廠。
- Form 呼叫 `LoadElectrostaticDetail` 查靜電箱，箱內有任何未勾選批時整組不能換廠。OPReference=0 傳產品／版本，其他使用 ModuleNo／ModuleVersion。舊表單依行迴圈呼叫 Convert 與重查，並在換廠回應後另呼叫 `UpdateElectrostaticFactoryNo` 更新載具。該呼叫失敗時可能已成功換批，且原 dtTransfer 會被迴圈覆蓋，正式端須預防。
- STD `wsWIP.ExeTransferFactory_Lot` 委派 `STD/MESkc/kcWIP/clsWIP.cs::ExeTransferFactory_Lot`。它以產品或模組、版本、站查 PRDOPArea 與 AreaBasis 的廠別，沒有區域時拒絕；按批號和 OPNo 更新 LotState.FactoryNo、AreaNo。 `clsLot.LoadElectrostaticDetail` 連 CarrierStateDetail、LotState、CarrierBasis，`UpdateElectrostaticFactoryNo` 更新 CarrierBasis。
- 直接表沿用 [LotState](../../../database/reference/mestest_wip_wp101_create.sql)、[PRDOPArea](../../../database/reference/mestest_prd_parameter_setup_create.sql)、[AreaBasis](../../../database/reference/mestest_smd_area_basis_create.sql) 和 [CarrierBasis／FactoryBasis](../../../database/reference/mestest_carrier_basis_create.sql) 及既有 WP305 CarrierStateDetail。本項無新表。
