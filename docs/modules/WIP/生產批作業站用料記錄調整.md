# WP911 生產批作業站用料記錄調整

- FunctionNo `LOT OP CONT MATERIAL ADJUST`。核對 `STD/MESWin/WIP/WP_Cont_Material_Adjust/frmCont_Material_Adjust.vb` 與内嵌 Designer。以工單或批號查 `LoadLotLog_ReportJoinLotBasis`（Status=1），明細以 LogGroupSerial 查 `LoadCont_Data` 的 Material 分支。
- 新增在材料與產品分流，材料以工單站別用料、替代料及批控取值；產品要產品號及批號。數量須大於零。新增可套用後繼續；修改固定識別列，只調用量／說明。刪除以選取列逐筆呼叫，可能部分成功。
- STD `wsWIP.AddCont_Material_Adjust`、`EditCont_Material_Adjust`、`DelCont_Material_Adjust` 委派 `STD/MESkc/kcWIP/clsWIP.cs` 同名方法。有料批新增／調整／刪除維護 Cont_MaterialLot 和 Cont_Material.UseQty，調整量以差額計，刪除最後量後刪除用料頭。無料批直接操作用料頭。修改／刪除比對舊量，料批再比對 CreateDate。這些方法直接操作用料記錄。
- 直接表已有 [WP201](../../../database/reference/mestest_wip_wp201_create.sql) 的 Cont_Material 與報工歷程、[WP112](../../../database/reference/mestest_wip_wp112_create.sql) 的 Cont_MaterialLot、[工單用料](../../../database/reference/mestest_oe_mo_material_create.sql)。本項無新直接表。
