# WP912 生產批作業站製程特性值調整

- `LOT OP CONT ATTRIB ADJUST` 對應 `STD/MESWin/WIP/WP_Cont_Attrib_Adjust` 的主 Form、批／元件調整 Form 及 Designers。以批號查 `LoadLotLog_ReportJoinLotBasis`，按 LogGroupSerial 分查 `LoadCont_Attrib_PRDOP` 和 `LoadCont_ComponentAttrib_PRDOP`。
- 只允許產品設定中屬於 AttribSource=0 的記錄。批排除 GOODQTY／SCRAPQTY，元件排除 CGOODQTY／CSCRAPQTY／CPASS。批單選一個特性，元件依相同 AttribNo 展開多個元件並可查找；可清空值，只送有異動的值與說明。
- STD `wsWIP.UpdCont_Attrib_Adjust` 依 UpdateType 0／1 委派 `STD/MESkc/kcWIP/clsWIP.cs::UpdCont_Attrib_Adjust`。依 LogGroupSerial、AttribNo（元件另帶 ComponentNo）更新實績並插入 Cont_AttribAdjustLog，記錄舊／新值、說明、Revisor、ReviseDate。源碼將舊值放在稽核資料，正式交易應鎖定重查它。
- [WP201](../../../database/reference/mestest_wip_wp201_create.sql) 已含 Cont_Attrib 與 Cont_ComponentAttrib。本項唯讀補 [調整歷程 metadata](../../../database/reference/mestest_wip_wp912_metadata.txt) 及 [CREATE-only](../../../database/reference/mestest_wip_wp912_create.sql)。該表未見 PK／UK／FK，ComponentNo 可空，LogGroupSerial 有非唯一索引。家用端比對 BYTE 長度和 defaults。
