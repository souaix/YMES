## 欄位與互動

- 主查詢固定 Status=0（未確認）與 OSType=2（臨時外包）。選填外包站、外包商、單號、建立人員、建立日期區間。文字條件為等值，迄日包含當天。選定主檔後呼叫 `LoadWIPOSDetail`。主檔含單號、外包站、項目、外包商、承辦人、需求日、外包量、狀態、建立人員／日期與說明。
- 定義窗必填 OSNo、OPNo、OSItemNo、SubContractorNo、參考批；PrepareName 若有值必須是有效使用者。OSItem 的 ReturnType=1 時，以參考批的流程節點選 ReturnOPNo／ReturnNodeId。修改時 OSNo 唯讀。單號正式依 `GetNewOSNo → udWIP.InitOSNo` 按企業設定生成。
- 參考批候選至少有 ProductNo、MONo、LotNo、ComponentNo 之一，Form 固定 LotState.Status 0–5。選參考批後可按同流程刷入其他批。參考批是第一個明細且無法取消，全選／取消全選只切其他列。外包量為選取批的 CurQty 合計，明細保存 LotNo、InputQty、InputUnitNo。
- Add / Edit 經 `UpdAddOS`／`UpdEditOS`。Edit 重查 Status=0 並以 DataStamp 更新和重建明細／預定外包。Delete 刪除三表關聯；Abort 刪除 FutureOS 預定並將主檔轉 -1，保留明細。兩者只有未確認可執行。舊 Form 批次逐筆呼叫並在錯誤時停止。

## Oracle、家用端 API 與交易

- `TBLWIPOSBASIS`（OSNO）與 `TBLWIPOSDETAIL`（OSNO, LOTNO）已有 [WP207 Oracle DDL](../../../database/reference/mestest_wip_wp207_source_ddl.sql) 和 [CREATE-only](../../../database/reference/mestest_wip_wp207_create.sql)。
- `TBLWIPFUTUREOS` 已有 [WP201 Oracle DDL](../../../database/reference/mestest_wip_wp201_dependency_source_ddl.sql) 和 [CREATE-only](../../../database/reference/mestest_wip_wp201_create.sql)。LotBasis／LotState、OP、產品、廠商、外包項目、流程節點與共用取號表沿用現有 references。本次無缺少 DDL 的直接表。
- 建議 `GET/POST /api/wip/outsource-orders`、`GET/PATCH/DELETE /api/wip/outsource-orders/{osNo}`、`POST /api/wip/outsource-orders/{osNo}/abort` 及獨立候選查詢。套登入與 WP401 權限、伺服器限量及型別化參數。頁面清單固定狀態 0、類型 2，API DTO 保留主檔與明細稽核、DataStamp。
- 保存整筆主檔、明細與 FutureOS 必須同一交易。伺服器依有序批號重讀 LotState、流程、計量單位、數量和現有預約，從首筆取得參考批及合法回貨節點，並以資料庫量重算總量。工單／批與預約採一致鎖順序，更新使用 nullable DataStamp + 狀態 CAS。查詢依穩定排序返回可辨識的參考批，避免靠無排序資料列位置。單號生成依企業規則集中分派，並以主鍵防重。

## 公司端 DEV 範圍

- 使用本機 mock 外包單、批號與查詢來源，支援新增、修改、套用、確認、刪除及作廢。未確認資料可見，已作廢離開主清單。本機同一外包站的待處理預約限制另開同批。數量與回貨節點依固定 DEV 流程核對。
- 以有填值啟用查詢條件，日期用日精度。候選使用固定下拉及選批按鈕，刷入使用本機批號。產生 DEV 單號只比對本機資料。切換參考批時重設明細和回貨站。刪除／作廢以一次本機寫入模擬多選，正式逐筆結果由 API 回報。正式庫存、供應商、取號、批狀態與其他 WIP 模組的預定外包由家用端整合。
