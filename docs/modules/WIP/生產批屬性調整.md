# WP913 生產批屬性調整

- `LOT PROPERTY ADJUST` 對應 `STD/MESWin/WIP/WP_LotPropertyAdjust/frmLotPropertyAdjust.vb`、`frmLotPropertyAdjustValue.vb` 和各自的 Designer。輸入批號轉為大寫，`LoadLotBasis` 以 BaseLotNo 查批，`LoadLotProperty`、`LoadComponentState` 與 `LoadComponentProperty` 取兩種屬性。
- 新增、修改和刪除兩種屬性都要調整原因。新增用 `wsSYS.LoadLotProperty`／`LoadComponentProperty` 的 TableType=0 選定義，屬性與值必填。修改固定屬性鍵並傳舊／新值，刪除傳原鍵及調整原因。
- STD `wsWIP.Add/Edit/DelLotProperty` 和 `Add/Edit/DelComponentProperty` 委派 `STD/MESkc/kcWIP/clsLot.cs` 同型方法，寫 `TBLWIPLOTPROPERTY`／`TBLWIPCOMPONENTPROPERTY`。服務用 EventLog 記原因，修改送舊值供比對和稽核。直接表與 SYS 定義沿用 [WP101](../../../database/reference/mestest_wip_wp101_create.sql)、[WP102](../../../database/reference/mestest_wip_wp102_create.sql)、[WP201](../../../database/reference/mestest_wip_wp201_create.sql)；無新直接表。
