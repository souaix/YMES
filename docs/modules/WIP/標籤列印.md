# WP908 標籤列印

- `LABEL PRINT` 對應 `STD/MESWin/WIP/WP_LabelPrint/frmLabelPrint.vb` 及內嵌 Designer。批號可逗號分隔，來源固定產品，軟體由 `wsSYS.LoadParameter` 取得，印表機列出 Preview 與本機系統印表機；Encoding 和 ComponentNo 在設計器隱藏。
- `wsWIP.LoadLabelDataByLot` 委派 `kcWIP.clsLot.LoadLabelDataByLot`。逐 BaseLotNo 以 LabelSource=1 先配產品專屬規則，再找 ProductNo='*'，未對應輸出 Fail。清單顯示批號、來源、類型、標籤編號、印表機、軟體及結果。啟用列以 `wsPRD.GetLabelValue` 呼叫 `kcPRD.clsProduct.GetLabelValue`，用 LabelDetail Position／Piece 等定義組值。
- 舊 Print 發送給 PD_Kit 的 BarTender／CodeSoft。全數有 ItemName 時用 named item，否則走舊資料檔分支。雖然表單方法名為 funAddLabelRePrintLog，這個入口實際呼叫 `wsWIP.AddLabelPrintLogByProduct`，由 `clsLot` 寫 PrintLog，標籤內容為 XML/CLOB。與另一路 AddLabelRePrintLogByProduct 分開。
- 參考 [LabelMap](../../../database/reference/mestest_prd_product_label_map_create.sql)、[LabelBasis](../../../database/reference/mestest_prd_label_basis_lookup_create.sql)、[LabelDetail](../../../database/reference/mestest_prd_label_detail_create.sql)。新增 [PrintLog metadata](../../../database/reference/mestest_wip_wp908_metadata.txt) 及 [CREATE-only](../../../database/reference/mestest_wip_wp908_create.sql)。Core 可用的 SorterBinData 分支仍查無 MESTEST 欄位，與 WP209 記錄相同。家用端在有實際此類標籤時核對來源，再啟用該分支。

## DEV 與家用端

- `/YMES/WIP/LabelPrint` 以 DEV-LABEL001／002 展示專屬／通用標籤，其他批號展示無對應。支援預覽、欄位表和目標印表機選擇。預覽使用 HTML 文字樣本，模擬列印只顯示已對應筆數。未呼叫印表機、標籤軟體、資料檔或寫 PrintLog。
- 建議 WP908 ACL 的 `POST /api/wip/lot-labels/resolve`、`GET /api/wip/lot-labels/{lotNo}/{labelNo}/values` 和 `POST /api/wip/lot-labels/print-jobs`。核對批次可見範圍，按每筆重取 mapping／values，限用受控範本和目的印表機。回傳逐筆預覽或列印結果，記錄操作人、裝置、軟體及不可變標籤內容；正式送印需有 provider 回執、冪等與重試，避免把預覽或失敗當作已列印。
