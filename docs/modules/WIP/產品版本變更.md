# WP905 產品版本變更

- FunctionNo 為 `PRODUCT VERSION CHANGE`。依 `STD/MESWin/WIP/WP_ProductVersionChange/frmProductVersionChange.vb` 與內嵌 Designer，`wsPRD.LoadProduct` 提供產品版本，目標顯示 CurVersion=1，舊版本可選同產品其他版本。查詢 `wsWIP.LoadLotBasis` 送產品、可選舊版本及 LotState=1。Grid 顯示 CheckFlag、BaseLotNo、ProductNo／Version、RONo、ItemNo、MONo、CustomerNo。
- 確認前把所有選取 BaseLotNo 送 `CheckLotPackage`，任一批已包裝即阻擋。送 ProductNo 和 BaseLotNo 陣列至 STD `wsWIP.Exe_ProductVersionChange`，成功重查。全選、取消全選屬 Grid 互動，Print handler 無實作。
- `STD/MESkc/kcWIP/clsLot.cs::UpdProductVersionChange` 重查 `TBLPRDPRODUCTBASIS.CurVersion=1`，只更新和目前版本不同的 `TBLWIPLOTBASIS`。先呼叫 `STD/MESud/udReverse/clsReverse.cs::Commit_LotBasis`，由 `TBLWIPREVERSEUNCOMMIT.ConditionString='BASELOTNO=<key>'` 找 LotSerial。按設定把對應歷程 CommitState 設為 1、寫 CommitDesc 並移除該序號 UnCommit；與產品版本更新一同送 SQL 批次。

## DEV 與交接

- `/YMES/WIP/ProductVersionChange` 提供選產品、顯示目前版本、舊版本過濾、勾選、確認、結果與重查。DEV-VER002 可觸發整批包裝阻擋，DEV-VER003 維持目前版本。DEV 僅改本頁假 LotBasis，未串 WP901 的歷程或實際批關聯。Print 和桌面 Grid 尋找器未移植。
- 建議 WP905 ACL 的 `GET /api/wip/lot-product-versions` 及 `POST /api/wip/lot-product-versions/upgrade`，提交 productNo、畫面顯示的目標版本、BaseLotNo 陣列、版本憑據與冪等鍵。鎖定重讀產品目前版本及各基礎批、檢查批屬此產品、仍在線與確實未包裝；目標版本已變更時要求重查，以交易更新 LotBasis、回復標記及稽核。
- 沿用 [產品主檔](../../../database/reference/mestest_prd_product_basis_create.sql)、[WP101 LotBasis](../../../database/reference/mestest_wip_wp101_create.sql)、[WP215 ReverseHistory](../../../database/reference/mestest_wip_wp215_create.sql)、[WP901 ReverseUnCommit](../../../database/reference/mestest_wip_wp901_create.sql) 與共用包裝表。本功能無新直接表。
