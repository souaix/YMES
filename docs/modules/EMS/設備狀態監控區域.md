# ES203 設備狀態監控_區域（SHOW EQP STATUS BY AREA）

## 選單與來源

- 選單識別：Module `EMS`、FunctionNo `SHOW EQP STATUS BY AREA`、FunctionKey `ES203`、Form class `frmAreaShowEMS_THEIL_BU1`、執行檔 `ES_AreaShow_THEIL_BU1.dll`，分類為設備_執行。
- 選單所列 Form 名是 class 名；三份來源樹的實際檔名都是 `frmAreaShow_THEIL_BU1.vb`，位於 `Customer\Production\MESWin\EMS\ES_AreaShow_THEIL_BU1`。CSiMES、THEIL 與 DEV_SILVA 三份主 Form SHA-256 相同，Designer 內嵌。
- 主 Form 呼叫 `wsSMD.LoadBaseArea`、`wsSMD.LoadAreaRelationDefine`、`wsEQP.LoadEQPStateBasis`、`wsEMS.LoadEquipmentStateBySMD`；另外讀取 `wsSYS.LoadParameter(SysInfo, MainVersion)`，傳給外部設備狀態監控視窗。
- THEIL Customer Service：`Customer\Production\MESws_STD\wsSTD\wsSMD\wsSMD.cs` 的 `LoadBaseArea`／`LoadAreaRelationDefine`，及 `...\wsEMS\wsEMS.cs` 的 `LoadEquipmentStateBySMD`。Core：`STD\MESkc\kcSMD\clsSMDBasis.cs` 的 `ShowAreaBasis`／`LoadAreaRelationDefine`；`STD\MESkc\kcEMS\clsEMSEquipment.cs` 的 `LoadEquipmentStateBySMD`。

## 主畫面與互動

- 視窗 1008×591。Base Area 下拉列出已核准、AreaClass=1 的基底區域；初始沒有選取區域。選取後清除舊圖及底圖，載入該區域關聯，並依目前顏色模式取現況資料。
- 圖形位置及大小來自 `TBLSMDAREARELATION` 的 ObjectX、ObjectY、ObjectWidth、ObjectLength；ObjectText 為節點文字，ObjectNo 為節點識別。ObjectType 0 區域畫矩形、1 庫房畫六角形、2 設備畫橢圓、3 設備類別及 4 設備群組畫圓角矩形。BorderColor、BorderStyle、TextColor 為選用外觀欄位；基底區域 BackgroundImage 有資料時會顯示背景。
- 預設 `Show Area Color`，節點使用關聯設定 ObjectColor。切換 `Show EQP State Color` 時呼叫 `LoadEquipmentStateBySMD`，以 `TBLEMSEQUIPMENTSTATE.EquipmentState` 對應 `TBLEQPSTATEBASIS.StateColor`，只替 ObjectType=2 的設備節點著色；找不到現況或狀態色時為白色。其他節點在無底圖時白色，有底圖時透明。工具列提供 Zoom 100%、150%、75%、50%、Grid 設定、Refresh、Close；Refresh 只有狀態色模式可用。
- `LoadEquipmentStateBySMD` 在一般主畫面收到相同的 BaseAreaNo／AreaNo，Core 取該 BaseArea 直接配置的設備及 EquipmentGroup 展開設備現況；EquipmentType 展開分支在 Core 已註解，主 Form 也不傳該條件。EquipmentGroup 本身不是狀態色節點，雖然 Core 會查其成員設備。
- 單擊選取節點，狀態列顯示所選文字；重疊區域的 AddFlow 群集選取與 ZOrder 會把內含節點送到前景。雙擊區域／設備／設備類別／群組會以對應 BaseArea、Area、EquipmentNo、EquipmentType 或 EquipmentGroup 參數開啟外部 `ES_EquipmentStateMonitor`；雙擊庫房開啟 `frmINVWipInventory`。畫布空白區雙擊會開啟基底區域整體監控。
- 右鍵選單只在 `gEnterpriseNo = IMESTECH` 顯示。區域節點提供設備監控、設備狀態紀錄、作業人員 State／History；設備節點提供設備監控與狀態紀錄；庫房節點只提供 Inventory。作業人員 State／History 會開啟 WP 區域作業人員功能。區域節點的 Show Equipment State Log handler 將 AreaNo 當成 `strEquipmentNo` 傳給 ES402，疑似來源參數錯置；正式端不應照搬。
- 隱藏 `txtTimer` 初始值是 `0`，所以沒有預設自動刷新。`btnRefresh_KeyDown` 有 F12 程式碼，但方法沒有 Handles，Form 內也沒有找到 AddHandler；F12 自動刷新入口看起來未連線。
- DEV 使用固定虛構 Base Area、關聯節點、目前狀態、狀態色與人員／設備資訊；可切區域、兩種著色、縮放、Grid、選取、DEV IMESTECH 右鍵選單、雙擊預覽與 Refresh 狀態快照。SVG 取代 AddFlow；碰撞／群集 ZOrder 只做簡化點選，Grid 只切換顯示。沒有載入 BackgroundImage BLOB，也不呼叫外部視窗、API、Service、Oracle 或 YMES PostgreSQL。右鍵資料視窗是本頁假資料預覽，不執行正式 WP、Inventory 或 ES402 功能。

## Service／Core 與 SQL handoff

- `wsSMD.LoadBaseArea` 呼叫 `clsSMDBasis.ShowAreaBasis(AreaClass=1, IssueState=2)`。`LoadAreaRelationDefine` 回傳指定 BaseArea 的 `TBLSMDAREARELATION`，並預載有效子區域、Inventory、Equipment、EquipmentGroup lookup；主監控 Form 的繪圖只讀關聯資料與已選 BaseArea 的 BackgroundImage，其他 lookup 結果不使用。
- `wsEMS.LoadEquipmentStateBySMD` 解析 BaseAreaNo、AreaNo 及可選 EquipmentNo／EquipmentType／EquipmentGroup。Core 查 `TBLEMSEQUIPMENTSTATE`，以 `TBLSMDAREARELATION` 找直接設備及群組，再用 `TBLEQPGROUPDETAIL` 展開群組設備。Core SQL 以字串串接，正式端必須參數化並驗證登入者可見 BaseArea／Equipment。
- 可沿用既有 Oracle／PostgreSQL 參考：`TBLSMDAREARELATION` 在 `database/reference/mestest_equipment_group_smd_source_ddl.sql`／`mestest_equipment_group_smd_create.sql`；`TBLSMDAREABASIS` 在 `mestest_smd_area_basis_source_ddl.sql`／`mestest_smd_area_basis_create.sql`；`TBLEMSEQUIPMENTSTATE` 在 `mestest_equipment_state_references_source_ddl.sql`／`mestest_equipment_state_references_create.sql`；`TBLEQPSTATEBASIS` 在 `mestest_equipment_state_create.sql`。`TBLEQPGROUPDETAIL` 有 `mestest_equipment_group_create.sql` CREATE-only，但 repo 沒有同版 Oracle source DDL；桌機受保護 Oracle profile 不可用，本次無法唯讀補查該表 metadata。其他預載的 Equipment／Group／Inventory lookup 只供 layout 配置視窗，本主畫面不消費其資料；正式監控 GET 可只回傳 rendering 所需欄位。
- 建議家用端先比對上述現有 live schema／migration，再提供登入授權的唯讀區域配置及設備現況 API，例如 `GET /api/smd/areas?areaClass=1&issueState=2`、`GET /api/smd/areas/{baseAreaNo}/layout`、`GET /api/ems/equipment-state-by-smd?baseAreaNo=&areaNo=`。以伺服器核定 BaseArea 與設備範圍，對巢狀 Area 依其布局矩形及 EquipmentGroup 成員取現況；使用單一狀態色 DTO、參數化查詢、結果數與快取／更新政策。已有 SMD SD108 layout handoff 可共用，不新增另一份區域表 schema。`BackgroundImage` 尚需 SD104 layout API 回傳安全的資料 URL；不要把資料庫 BLOB直接放到 DEV。
