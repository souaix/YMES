## WinForms 查詢與圖表行為

- 主 Form ClientSize 1004×587，欄位為 Equipment Type、Equipment State、Equipment No、User No 及狀態時間。前三項各有勾選／文字輸入／`...` 單筆查找；文字非空時自動勾選，取消勾選會清空。狀態名稱下拉選單以平行的隱藏代碼欄位送出。
- 時間模式預設 `Status Start Time`。StartTime From／To 初始為七天前同一日的 00:00:00／23:59:59；EndTime From／To 初始為今日 00:00:00／23:59:59。每一端可各自取消。切到 End 模式會停用並取消 StartTime 兩端，啟用並勾選 EndTime 兩端；切回 Start 則相反。Core 使用 `>=`／`<=`，包含邊界。
- `Query` 開啟 Top Ten 狀態表；`Pie Chart`、`Bar Chart`、`Bar Chart(Label)` 分別開啟獨立圖表子窗，四個入口都重新送出同一組篩選條件，各自呼叫 `LoadEquipmentStateLogTopTen`。來源查詢沒有必填條件、日期跨度上限或分頁；清除所有日期勾選後可查完整歷史。
- DEV 提供相同條件、假資料 lookup、Start／End 日期模式、排行表、比例圓餅圖、長條圖及長條數值標籤。為配合 Web shell，圖表模式在同一頁切換，沒有另開 WinForms 子窗；結果與互動只存在頁面記憶體。所有代碼、名稱、顏色、設備、人員和時間都是示意資料。

## Service／Core 聚合

- Service 可解析 EQPSerialNo、EquipmentNo、EquipmentState、EquipmentType、UserNo 及兩組時間端點；主 Form 沒有 EQPSerialNo 欄位，不傳此條件。時間字串由 Service `Convert.ToDateTime` 解析。
- Core 直接查 `TBLEMSEQUIPMENTSTATELOG` 中 EQPSerialNo 非空的記錄，依可選篩選條件分組 `EquipmentState` 並計算狀態總時數，按 TotalTime 由大到小排序。再查 `TBLEQPSTATEBASIS` 取得 StateName／StateColor。
- 最多保留前 9 個狀態；剩餘狀態時數合計大於 0 才新增第 10 列 `EquipmentState=-999`、`StateName=Others`、黑色。表格欄位為 Order、EquipmentState、TotalTime、StateName、StateColor；Top Ten Form 的 Print／Find 按鈕在來源中隱藏。
- Oracle 以 `SUM((EndTime - StartTime) * 24)` 算小時；非 Oracle 分支先用 `DATEDIFF(mi, StartTime, EndTime)` 轉整數分鐘再除以 60，精度與負值行為可能不同。兩分支均使用 Core 字串串接 SQL，正式 API 應以參數化查詢聚合並使用單一明確的時數／捨入規則。

## SQL 與家用端 handoff

- 兩張直接表已有同版參考：`TBLEMSEQUIPMENTSTATELOG` 的 Oracle source DDL／PG CREATE-only 在 `database/reference/mestest_wip_wp305_source_ddl.sql`／`mestest_wip_wp305_create.sql`；`TBLEQPSTATEBASIS` 在 `database/reference/mestest_equipment_state_create.sql`，Oracle source 沿設備狀態 references。Equipment Type／Basis、User 與 State lookup 使用共用 Service 既有 references。本功能沒有新直接表或新增 SQL。
- 桌機受保護 Oracle profile 未備妥；本次沿用 repo references，沒有連 MESTEST、讀取業務資料或 YMES PostgreSQL，也未補猜測 DDL。
- 建議家用端實作登入者權限保護的唯讀 `GET /api/ems/equipment-state-log-summary`，支援 equipmentType、equipmentNo、userNo、equipmentState、timeField (`start`／`end`)、from／to 與必要分頁／結果限制。伺服器應驗證日期順序與跨度、限制無條件全歷史掃描、參數化所有篩選、套用使用者可查設備範圍。回傳 top 9 與 Others 的 state code/name/color/hours，圖表可共用同一 DTO；正式 SQL 不要照搬 Oracle／非 Oracle 兩套時數表達式。
