## WinForms 主畫面

來源：`D:\iMES\CSiMES\STD\MESWin\EQP\EP_EquipmentBasis\frmEquipmentBasis.vb`。

- 預設主清單狀態為 UNFROZEN（IssueState=0）；可切換 PENDING（1）、ACTIVE（2）、UNUSED（-1）。清單只顯示非 Chamber 設備。
- 查詢欄位固定為 EquipmentNo，支援包含式搜尋；按「查詢」重新讀取資料。
- 主清單欄位包含 EquipmentNo、EquipmentType、EquipmentName、EngineerGroupNo、EquipmentClass、VendorNo、ModelNo、AssetNo、Capacity、LoadPort、MaxTime、CountEqpUnitQty、FixEqpTime、VarEqpTime、QCListNo、AutoFlag、Description。部分欄位需水平捲動。
- 選取設備列會載入附屬 Chamber 清單；Chamber 有獨立的 UNFROZEN/PENDING/ACTIVE/UNUSED 狀態篩選。
- ChamberManage 系統參數為 1 時顯示 Chamber 面板；否則隱藏，且主設備 Grid 擴展填滿版面。

### 主畫面按鈕

| 操作 | WinForms 行為 |
| --- | --- |
| 新增 | 開啟 EP104 空白表單；成功後重載清單並定位新設備 |
| 修改 | 讀取作用列資料開啟 EP104；舊程式會再依 IssueState 套用欄位權限 |
| 刪除 | 可多選；IssueState=0 或 -1 實際刪除，IssueState=2 改成 UNUSED；其餘狀態不允許。逐筆執行，已完成的刪除不會自動復原 |
| 複製 | 複製設備欄位後清空 EquipmentNo，走新增服務 |
| 核准 | 可多選，但逐筆核准；只允許 IssueState=0。Controlled=1 的設備屬性未設定時阻擋；Controlled=2 欄位未設定時警告並允許取消；傳 DataStamp。若 AutoFlag=1 且 MultiOperator=1，顯示多人加工提示 |
| 屬性 | 呼叫 `EP_EQPProperty` |
| 參數 | 開啟 `frmEQPParameterBasis` |
| 點檢表 | 呼叫設備點檢表關聯功能 `EP_EQPQCList` |
| Download / Print | 匯出清單及列印 |
| 設備匯入 | 呼叫 `EP_EquipmentDataImport`；成功後重載設備與 Chamber 清單 |
| 關閉 | 關閉主畫面 |

## EP104 設備編輯表單

來源：`frmEquipmentBasisDef.vb`；新增/修改/複製共用表單。

| 欄位 | 規則 / 來源 |
| --- | --- |
| EquipmentNo | 必填；輸入自動轉大寫；Edit 唯讀 |
| EquipmentType | 必填；應從設備類別主檔挑選 |
| EquipmentName | 必填 |
| EngineerGroupNo | 必填；工程群組主檔 |
| VendorNo | 必填檢查；空值送出前舊程式回填 `N/A` |
| EquipmentClass / EquipmentClassNo | 由 ValueListProvider 提供；SEMI Wafer / 行業包影響選項；排除值 2；值 6 只在有對應行業包時顯示；存入英文字串與分類代碼 |
| ModelNo / AssetNo | 一般文字欄位 |
| Capacity | 必填數字，最小 -1；-1 表示不限制 |
| LoadPort | 必填數字，最小 -1；-1 表示不限制 |
| MaxTime | 0–24 小時 |
| FixEqpTime / VarEqpTime | 非負分鐘數 |
| CountEqpUnitQty | 非負整數 |
| EqpRecipe | ValueList 項目：UnLimited、Single Recipe、Multi Recipe、Batch Recipe；預設索引 0，保存索引值 |
| QCListNo | 從設備點檢表主檔選取 |
| AutoFlag | Y/N 選項，存 1/0；自動設備會顯示訊息佇列欄位 |
| QueueServer | AutoFlag=1 且未使用 Default Server 時必填 |
| Request/Response Message Queue | 欄位依 EAP_FILTERMODE 參數切換；模式 0 或未設定時，使用 REQUESTMSGQUEUE、RESPONSEMSGQUEUE、REQUESTMSGQUEUE_MES、RESPONSEMSGQUEUE_EAP；其他模式使用一般 Request/Response 欄位 |
| EAController | 一般文字欄位 |
| Description | 多行文字 |

Creator/CreateDate 在新增/複製時寫入目前登入者與時間；Edit 保留建立資訊並更新 Reviser/ReviseDate。Edit 帶 DataStamp；Apply 成功後本地版本遞增、視窗保留並停用 Apply，後續欄位變更再啟用；Confirm 儲存並關閉。

### 表單驗證與衍生行為

- EquipmentNo、EquipmentType、EquipmentName、EngineerGroupNo、VendorNo、Capacity、LoadPort 必填。
- Capacity、LoadPort 必須是數值且不得小於 -1。
- 若 EquipmentClass 為 LINE，EquipmentNo 必須已存在區域主檔。
- AutoFlag=1、未勾 Default Server 時，QueueServer 必填。
- 設備分類 ValueList 和設備點檢表選項需由 API options 取得，不可把特定廠區值寫死成正式設定。
- EquipmentType、EngineerGroupNo、VendorNo、QCListNo 的舊表單有查詢/挑選入口；應保留查詢彈窗或等價的即時選擇器。

## Chamber 子設備

- Chamber 與主設備共用 `TBLEQPEQUIPMENTBASIS`，以 ChamberFlag=1 及 BelongEquipmentNo 關聯父設備；父設備為 ChamberFlag=0。
- Chamber 清單另依四種 IssueState 篩選。新增/修改欄位至少含設備編號、所屬設備、設備名稱、說明；編號在 Edit 唯讀。
- Chamber 新增/修改/刪除/核准走既有 `wsEQP` 服務；刪除及核准要帶 IssueState、DataStamp，且需確認父子設備及狀態限制。
- WinForms 的停用條件由 `ChamberManage` 系統參數和父設備狀態決定；Vue 不可一律顯示或允許所有操作。

## 資料表與 CREATE SQL 狀態

Oracle 來源表為 `MESTEST.TBLEQPEQUIPMENTBASIS`。使用者於 2026-11-13 提供原始 Oracle CREATE TABLE 與 PK 唯一索引 DDL；已轉為 [設備主檔 CREATE SQL](../../../../database/reference/mestest_equipment_basis_create.sql)。PostgreSQL 轉換保留欄位、長度、NUMBER precision/scale、DEFAULT、NOT NULL 與 PK；Oracle tablespace/storage 子句省略，PK 由 PostgreSQL 自動建立唯一索引。`database/reference/mestest_first_phase_create_tables.sql` 已同步修正同名表的預設值與 NOT NULL constraint names，並移除先前推測欄位註解。

家用電腦比對 YMES schema 現有 `tbleqpequipmentbasis` 欄位/預設值/constraint，缺表時參照單表 SQL 建 migration；若既有表有差異，另寫向前 migration，不用 `IF NOT EXISTS` 假設自動修正。Oracle 來源 DDL 只存結構，不含 MES 業務資料。連線字串與憑證只留在安全設定，不寫入文件或 Git。

設備屬性、點檢表、設備類別、工程群組、供應商、訊息佇列搜尋等關聯來源，需依 WinForms Service 查詢和 Oracle DDL 逐一確認；不得假設跨表關聯全由外鍵保護。

### Oracle 主表欄位約束摘要

`TBLEQPEQUIPMENTBASIS` 的設備編號為 `VARCHAR2(50) NOT NULL` 主鍵；EquipmentType `VARCHAR2(50) NOT NULL`；VendorNo `VARCHAR2(50) NOT NULL`。資料庫中的 `EquipmentName`、`EngineerGroupNo`、`Capacity`、`LoadPort` 可為 NULL，但 EP104 表單會要求設備名稱、工程群組、容量及 LoadPort。Capacity 預設 -1；IssueState 預設 0 且不可 NULL；LoadPort 預設 0；FixEqpTime/VarEqpTime 預設 0；CountOpUnitQty/CountEqpUnitQty 預設 1；ChamberFlag/DataStamp 預設 0。完整欄位精度與 constraint name 以單表 CREATE SQL 為準。

## 現有 Vue / API 契約

目前 Vue 元件使用下列設備 API；API 詳細規則見既有設備規格與家用電腦 API 專案：

| 方法 | 路徑 | 用途 |

| POST / DELETE | `.../{chamberNo}/approve`、`.../{chamberNo}` | Chamber 核准 / 刪除或停用 |
