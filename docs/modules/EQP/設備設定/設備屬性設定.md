# 設備屬性設定（EP_EQPProperty）

## 識別資訊

| 欄位 | 值 |
| --- | --- |
| 第一層 / 第二層 | 設備資料 / 設備設定 |
| 呼叫來源 | EP104 設備基本資料；設備類別主檔也共用此 Form |
| WinForms Form | `frmEQPProperty`、`frmEQPPropertyDef` |
| Service | `wsEQP.LoadEQPProperty`、`AddEQPProperty`、`EditEQPProperty`、`DelEQPProperty`、`ApproveEQPProperty` |

## 關鍵語意

此 Form 的資料鍵欄位名稱為 `Equipment`。從 EP104 開啟時，Equipment 傳入實際設備編號；從設備類別主檔開啟時，Equipment 傳入 EquipmentType。兩種呼叫共用同一張屬性表與畫面，API 需按呼叫來源保留此值，不能一律替換成設備實體編號或 EquipmentType。

## WinForms 主清單與操作

- 預設顯示 IssueState=0（Unfrozen），搜尋欄位為 PropertyNo；此 Form 隱藏 IssueState 選單。
- 主清單以 Equipment + PropertyNo 識別，顯示屬性編號、預設值、順序、說明及狀態/稽核欄位。
- 新增、修改、複製會開啟 `frmEQPPropertyDef`；修改只允許 IssueState=0。
- 刪除允許 IssueState=0、-1、2，Service 直接刪除資料；傳 Equipment、PropertyNo、IssueState、DataStamp。IssueState=1 不允許。
- 核准只允許 IssueState=0；逐筆呼叫核准服務並傳 Creator、DataStamp。沒有反簽核功能。
- 刪除/核准可多選；逐筆服務若中途失敗，先前成功資料不會自動回復。

## 新增/修改表單

| 欄位 | WinForms 規則 |
| --- | --- |
| Equipment | 必填；由來源設備/設備類別帶入，不可在表單修改 |
| PropertyNo | 必填；新增/複製可透過屬性定義查詢選擇；Edit 唯讀 |
| DefaultValue | 一般文字；依 Element 定義的預設值帶入，也可選 MES Parameter 有效值 |
| PropertySequence | 數值欄位；資料表欄位為 NUMBER(2,0) |
| Description | 多行文字 |
| Creator/CreateDate | Add/Copy 使用目前登入者及時間；Edit 保留原建立資訊 |
| Reviser/ReviseDate | Edit 顯示目前登入者及時間 |

Add/Copy/Edit 共用服務表單。Apply 驗證 Equipment、PropertyNo 必填後保存並停留；Confirm 驗證相同欄位後保存並關閉。Edit 傳舊 IssueState 與 DataStamp。屬性編號選擇來自 `wsSYS.LoadEQPPropertyDefine(PropertyType=1)`；選取後帶回 ElementNo、DefaultValue、ElementSequence。DefaultValue 的第二個選擇入口呼叫 `wsSYS.LoadElementValue(ElementNo)`。

## 資料表 / SQL

`TBLEQPEQUIPMENTPROPERTY` 的 Oracle 原始 DDL 已轉換到 [設備類別參考 SQL](../../../../database/reference/mestest_equipment_type_create.sql)，PK 為 `(Equipment, PropertyNo)`，欄位包含 DefaultValue、PropertySequence、Description、IssueState、DataStamp 與稽核欄位。該單表 SQL 已核實來源；套用前仍由家用電腦比對 YMES 現有結構。

## API 契約待辦

- `GET /api/equipment/{equipmentNo}/properties`：限定實體設備的屬性；設備類別呼叫應提供獨立明確路徑或 resource type，避免 `Equipment` 鍵值語意混淆。
- 新增/修改/刪除/核准需以 `(Equipment, PropertyNo)` 為鍵，Edit/Delete/Approve 傳 IssueState 與 DataStamp，回傳並更新 DataStamp。
- 提供屬性定義與 ElementValue 選項 API；不把系統 Element 資料硬寫入正式 UI。
- 設備主檔核准依 Controlled 屬性檢查時，使用同一套 API 規則及狀態有效性。
