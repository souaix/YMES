## WinForms 清單與使用者配置畫面

來源：STD/MESWin/EQP/EP_EngineerGroupBasis/frmEQPEngineerGroupBasis.vb。

- 上方群組清單顯示 EngineerGroupNo、EngineerGroupName、Description、Creator、CreateDate、Reviser、ReviseDate；DataStamp 隱藏。
- 群組資料依 EngineerGroupNo 排序。查詢欄位為 EngineerGroupNo；Find/Print 按鈕在 Form 中隱藏。
- 右側可見按鈕依序為 ADD、EDIT、DEL、Copy、Close；Find 與 Print 在 WinForms Designer 中隱藏。DEL 可多選，刪除前詢問確認。
- 選取群組列後，下方使用者清單即載入群組成員狀態。
- 使用者清單欄位為勾選框、UserNo、UserName；UserNo/Name 唯讀。
- 「Selected」預設勾選，只顯示目前已加入該群組的使用者。取消後顯示所有系統使用者，以便勾選加入。
- 使用者勾選變更先留在畫面；按下 Confirm 才送出群組與完整 UserNo 集合。按 Confirm 前不寫入。
- 使用者來源為 wsUSR.LoadUserSecurity；勾選狀態依工程群組明細查詢結果計算。
- 工程群組刪除時，Service 先刪除 tblUSRUserGroup 中 GroupType=2 的關聯，再刪除工程群組主表資料。

## 群組定義表單

來源：frmEQPEngineerGroupBasisDef.vb。

| 欄位 | 必填 | 編輯規則 |
| --- | --- | --- |
| EngineerGroupNo | 是 | 最長 20；ADD/COPY 可編輯，EDIT 唯讀 |
| EngineerGroupName | 是 | 最長 50 |
| Description | 否 | 最長 255，多行 |
| Creator / CreateDate | 系統欄位 | 新增/複製寫入目前使用者與時間 |
| Reviser / ReviseDate | 系統欄位 | 修改時更新 |
| DataStamp | 系統欄位 | 修改時送回，成功後版本遞增 |

ADD 表單的編號預設為空；COPY 帶入原群組編號、名稱、說明，編號仍可改。編號離開欄位時轉為大寫。必填檢查只驗證編號及名稱；主表 PK 防止重複編號。表單按鈕依序為「確定」（儲存並關閉）、「關閉」、「套用」（儲存後保留表單）；修改/新增/複製皆支援套用。

## 群組成員規則

來源：frmEQPEngineerGroupBasis.vb、STD/MESkc/kcEQP/clsEQPBasis.cs。

- 關聯表為 tblUSRUserGroup，工程群組使用 GroupType=2。
- AddEQPEngineerGroupDetail 寫入 GroupNo、UserNo、GroupType=2、AgentOf='NA'。
- LoadEQPEngineerGroupDetail 以 GroupType=2 查詢；畫面只把 AgentOf='NA' 的明確使用者關聯標為已選。
- DelEQPEngineerGroupDetail 以 GroupType=2 篩選，刪除時可依 EngineerGroupNo 與 UserNo 限定範圍。
- 主畫面 Confirm 呼叫 wsEQP.UpdEQPEngineerGroupDetail，傳入群組編號和完整的勾選 UserNo 清單。該 WebService 實作未在目前 WinForms/Core 原始碼中找到；API 應以交易方式同步完整集合，並保留 AgentOf='NA' 語意。
- COPY 呼叫 wsEQP.CopyEQPEngineerGroup，提供來源/目標編號、目標名稱、說明與建立者。WebService 實作未在目前原始碼中找到；本機假資料頁按複製群組並複製來源成員處理，需由家用 API 對照正式 Service 行為。

## Oracle DDL 與 CREATE SQL 交接

- MESTEST.TBLEQPENGINEERGROUPBASIS Oracle DDL 已由資料字典確認：EngineerGroupNo varchar2(20) NOT NULL PK；EngineerGroupName varchar2(50) NOT NULL；Description varchar2(255)；Creator varchar2(10)；CreateDate DATE；DataStamp NUMBER(11,0) DEFAULT 0；Reviser varchar2(10)；ReviseDate DATE。
- PostgreSQL tbleqpengineergroupbasis 已包含於 database/reference/mestest_first_phase_create_tables.sql 的 75 表 bootstrap。本功能另附可單獨執行的 database/reference/mestest_equipment_engineer_group_create.sql，以支援家用電腦檢視或單表建立。
- MESTEST.TBLUSRUSERGROUP 原始 DDL 已於 2026-11-16 由 Windows PowerShell 5.1 + Oracle.ManagedDataAccess 唯讀查得。欄位為 UserNo varchar2(10) NOT NULL、GroupNo varchar2(20) NOT NULL、GroupType number(1,0) NOT NULL DEFAULT 0、AgentOf varchar2(10)（由 PK 實際強制 NOT NULL）、AgentDate DATE、AgentCreateDate DATE。PK 為 (UserNo, GroupNo, GroupType, AgentOf)。
- Oracle 資料字典確認該表只有 PK 對應的 unique index，無其他 index 或 FK。來源 DDL：database/reference/mestest_equipment_engineer_group_member_source_ddl.sql；PostgreSQL 空表 CREATE SQL：database/reference/mestest_equipment_engineer_group_member_create.sql。
- 此表不在現有 75 表 bootstrap/migrations；家用電腦需先比對 YMES 實際表與欄位，缺表才新增 migration。來源 Service 已確認工程群組只操作 GroupType=2、AgentOf='NA' 的直接成員；不可刪改其他 GroupType 或代理人資料。
- Web/UI 不直接連 Oracle 或 PostgreSQL。

## YMES API 契約（家用電腦待實作）

| 方法 | 路徑 | 用途 |
| --- | --- | --- |
| GET | /api/equipment/engineer-groups?engineerGroupNo= | 群組清單；編號採包含式查詢 |
| POST | /api/equipment/engineer-groups | 新增群組 |
| GET | /api/equipment/engineer-groups/{engineerGroupNo} | 單筆群組資料（表單/版本核對） |
| PUT | /api/equipment/engineer-groups/{engineerGroupNo} | 修改名稱/說明；使用 DataStamp 併發檢查 |
| DELETE | /api/equipment/engineer-groups/{engineerGroupNo} | 刪除群組與 GroupType=2 關聯，需同一交易 |
| POST | /api/equipment/engineer-groups/{sourceGroupNo}/copy | 複製群組欄位及成員；與舊 CopyEQPEngineerGroup 對照 |
| GET | /api/equipment/engineer-groups/{engineerGroupNo}/users | 回傳全部可配置使用者，含 selected 布林值；只把 AgentOf='NA' 的 GroupType=2 關聯視為已選 |
| PUT | /api/equipment/engineer-groups/{engineerGroupNo}/users | Body { "userNos": ["..."] }；交易式取代該群組的 GroupType=2 成員集合 |

群組清單 DTO 欄位為 EngineerGroupNo、EngineerGroupName、Description、Creator、CreateDate、Reviser、ReviseDate、DataStamp。成員 DTO 欄位為 UserNo、UserName、Selected。API 不回傳代理人資料作為人工選取成員。

## Development UI 與 Production 行為

- Vue 3 頁面僅在本機建置且使用者選取 Development 環境時使用清楚標示的假資料；新增/修改/複製/刪除、查詢、使用者勾選、只看已選及確認儲存都可於瀏覽器本地完成。切換環境或 API 位址時重新載入。
- 開發資料存於 localStorage，使用 ymes-dev-mock: 命名空間，不呼叫假 API，不寫入資料庫。
- Production 不使用假資料；僅呼叫正式 API，API 缺少時明確顯示錯誤。
