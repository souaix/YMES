## 功能目的與範圍

維護設備狀態代碼、顯示名稱、顏色及稼動類型，供設備現況、狀態控制及設備點檢表引用。本頁只維護狀態主檔；不包含狀態控制設定或點檢表設定。

公司電腦 Vue Development 模式使用本地 DEV 假資料與 localStorage。Production 必須走 YMES API，不能使用本地假資料。

### 驗證與寫入差異

- EquipmentState 必填、需為整數且不可小於 0；資料庫欄位為 Oracle NUMBER(2,0)，實際可存代碼範圍受兩位數精度限制。
- StateType 必填。舊程式的註解與 ValueList 註解標示索引 1 為 User Define；該類型不可使用 0–10。StateType 選項文字和值應由相同的 ValueList 對照來源提供，不能硬編為 Production 唯一來源。
- StateName 必填；Oracle 欄位長度為 50。
- Confirm 需選擇 UtilizationType；未選會顯示必填訊息。On 儲存為 1、Off 儲存為 0。
- Apply 的舊程式未檢查 radio 是否已選；尚未選時依 VB 整數預設值送出 0。Vue 保留此 Apply / Confirm 差異。
- Color 由 .NET Color.ToArgb() 寫入 StateColor；Confirm 另寫 StateColor_HEX，值為 RGB 六位十六進位、不含 #。Apply 不帶 StateColor_HEX。
- DataStamp、IssueState、核准流程不適用於此表。

### 按鈕行為

| 按鈕 | 行為 |
| --- | --- |
| 新增 | 開啟空表單；Confirm 呼叫 wsEQP.AddEQPStateBasis；成功後關閉主檔表單並重載清單 |
| 修改 | 以目前作用列載入資料；EquipmentState 唯讀；Confirm 呼叫 wsEQP.EditEQPStateBasis |
| 複製 | 複製目前列的類型、名稱、顏色、說明、稼動類型；清空 EquipmentState，走新增 Service |
| 刪除 | 可多選；先詢問確認，再執行引用檢查；每筆呼叫 wsEQP.DelEQPStateBasis。舊程式逐筆處理，若後續列失敗，先前成功刪除不會自動復原 |
| Apply | 表單維持開啟；儲存成功後停用 Apply，等待使用者再次修改 |
| Confirm | 驗證後儲存並關閉表單 |
| 關閉 / 取消 | 關閉目前視窗，不儲存未提交修改 |

新增、修改、複製成功後，主清單重新載入並定位到該 EquipmentState。主 Grid 雙擊列在 Vue 版開啟修改視窗。

## 刪除引用限制

WinForms 在刪除前呼叫 wsEQP.ChkEQPStateExist，來源位於 D:\iMES\CSiMES\STD\MESkc\kcEQP\clsEQPStateControl.cs。Service 將以下來源的代碼 UNION 後回傳：

1. tblEMSEquipmentState.EQUIPMENTSTATE
2. TBLEQPSTATECONTROL.EQUIPMENTSTATE
3. tblEQPQCListBasis.UNVALIDACTION（以狀態值別名）

清單有任一欲刪代碼，即阻擋該筆並顯示「已被 EP106 / ES102 / EP107 使用」訊息。雖然表單註解另提 EP107，現行查詢的第三個來源是 tblEQPQCListBasis.UNVALIDACTION；API 應忠實覆蓋實際查詢，並確認三個依賴在 YMES 的對應結構/資料來源。Oracle DDL 未宣告外鍵，因此不能只依賴 FK 限制。

目前 Development 假資料以狀態 83 模擬被引用資料，刪除時會提示阻擋；這只用於 UI 流程演示。

| Oracle 來源表 | 用途 | Oracle PK / 唯一索引 | 外鍵 / 額外索引 |

### ValueList 正式值

公司端唯讀查詢 `MESTEST.TBLSYSVALUELIST`，篩選 `TABLENAME='TBLEQPSTATEBASIS'` 與欄位名稱。WinForms 使用 `ValueListProvider.GetValueList(..., True)`；繁中顯示文字由 `Customer/Production/MESClient/mesresource.zh-cht.resources` 的翻譯資源核實。

| 欄位 | 值 | Oracle DisplayText | WinForms 繁中顯示 |
| --- | ---: | --- | --- |
| `STATETYPE` | 0 | `SYSTEM_DEFINE` | 系統 |
| `STATETYPE` | 1 | `USER DEFINE` | 使用者定義 |
| `UTILIZATIONTYPE` | 0 | `EQPOFF` | 非稼動 |

以上是資料字典 ValueList 設定，不是從設備狀態業務資料推算。Vue 表單應顯示核實的繁中翻譯，同時保留原始數值傳給 API。

## API 契約與部署狀態

Vue Production 頁面採用以下契約：

| 方法 | 路徑 | 用途 |
| --- | --- | --- |
| GET | /api/equipment/states | 全量讀取，依 EquipmentState 升冪；回傳列表欄位與可選顯示文字 |
| GET | /api/equipment/states/options | 回傳 { stateTypes, utilizationTypes } ValueList 選項 |
| POST | /api/equipment/states | 新增（Add 與 Copy 共用） |
| PUT | /api/equipment/states/{equipmentState} | 修改；StateColor_HEX 缺省時不得清掉舊值，以對應 Apply |
| DELETE | /api/equipment/states/{equipmentState} | 先檢查三個使用來源；被引用回 409，引用表未完整建立回 503，無引用時刪除並回 204 |

DTO 使用 camelCase；stateColor 為有號 32-bit ARGB 整數，stateColorHex 為不含 # 的 RGB 字串。新增/修改必須參照資料庫長度、整數範圍、StateType ValueList 與 user-defined 0–10 限制。此功能沒有 IssueState / DataStamp / 核准端點。刪除需由伺服器檢查引用，不能只信任 Vue。

API options 回傳的值為 StateType 0/1、UtilizationType 0/1。公司端已核實 MESTEST ValueList 及繁中翻譯，Vue 依數值顯示「系統／使用者定義／非稼動／稼動」，寫入 API 時仍傳原始數值；家用端 API 只需維持這些數值與既有驗證。user-defined 0–10 限制已完整確認。

- `0016_equipment_state_api.sql` 已恢復來源 DEFAULT，並只授予 `ymes_app` 對 `tbleqpstatebasis` 的 CRUD 權限。
- Production GET/options/POST/PUT/DELETE API 已部署至 `/YMES/API`。刪除端點目前採 fail-closed：兩個缺少的 MES 引用表 DDL 尚未交付，所以資料表不完整時回 503，不允許刪除；引用命中時回 409。
- migration 前已建立並驗證備份：`/opt/ymes/backups/ymes_before_0016_equipment_state_20261114_admin.dump`。
