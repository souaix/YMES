## WinForms 主清單

- 開啟時帶入唯讀 EquipmentType、EquipmentNo、EquipmentName，資料依 EquipmentNo 查詢。
- 清單顯示設備關聯的 QCListNo、QCListName、QCType、InspType、InspStartTime 及稽核/版本欄位。
- Add、Edit、Delete、Copy、Close；Add/Edit 使用定義表單。新增/修改後重載並定位關聯列。
- 關聯鍵為 EquipmentNo + QCListNo + InspType + InspStartTime。非 Daily 的起始時間以 N/A 表示。
- 查詢 QCListNo 使用 `TBLEQPQCLISTBASIS` 選擇；輸入編號後依清單主檔 QCType 調整可選檢查類型。

## 關聯編輯表單與規則

- EquipmentNo、EquipmentType、QCListNo 必填；QCListNo 必須存在點檢表主檔。
- 點檢表類型為 CheckIn 時可選 Lot、Shift、Daily；Daily 必須選起始時間，選項為 00:00 至 23:30、每 30 分鐘一個值。
- 點檢表類型為 Manual 時，Lot/Shift/Daily 與時間欄位停用，InspType 設為 None。
- Add 保存 EquipmentNo、QCListNo、InspType；Daily 時另保存 InspStartTime 及 Creator。
- Edit 以舊 QCListNo/InspType/InspStartTime 識別原列，保存新鍵值與 Reviser。Form 傳 DataStamp，但 Service `EditEQPListSetUp` 方法簽章沒有 DataStamp 參數；需向 Oracle 實際定義與上層 Service 確認是否有併發檢查，不能假設有效。
- Service 讀取以 `tblEQPQCListSetup` 左聯 `TBLEQPQCLISTBASIS`；Delete 以完整關聯鍵刪除。

## API 契約待辦

- `GET /api/equipment/{equipmentNo}/qc-lists` 回傳設備關聯及 QCList 主檔名稱/類型。
- 提供可選 QCListNo 清單；新增/修改/刪除使用完整複合鍵，Daily 必須有半小時對齊的時間，其餘 InspType 正規化為 N/A。
- 服務端驗證 QCListNo 存在，Manual 不允許排程類型；DataStamp 僅在確認舊服務實際有此欄位/檢查後納入。
- 關聯 CRUD 與 QCList 主檔 CRUD 分開；不能把本頁映射至 `/api/equipment/qc-lists` 主檔維護端點。

- `GET /api/equipment/{equipmentNo}/qc-lists`
- `GET /api/equipment/{equipmentNo}/qc-list-options`
- `POST /api/equipment/{equipmentNo}/qc-lists`
