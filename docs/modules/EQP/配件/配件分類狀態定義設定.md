## 查詢清單

- 預設 IssueState=0，可切換 0 未簽核、1 簽核中、2 已簽核、-1 不使用。
- 查詢欄位為 AccessoryCategory、AccessoryState、OperationName；EP201 開啟時限制目前分類。
- Grid 隱藏 IssueState、InitialFlag、DataStamp；顯示分類、狀態編號/名稱、作用名稱、介面名稱、說明、建立/修改者及日期、狀態色彩。狀態色彩由 TBLEQPACCSTATEBASIS join 顯示。

## 定義表單

| 欄位 | 行為/限制 |
| --- | --- |
| 配件分類 | 必填；EP201 帶入時鎖定；離開欄位轉大寫 |
| 配件狀態 | 必填，從 LoadEQPACCStateBasis 選既有狀態 |
| 狀態名稱 | 隨狀態選項帶入，唯讀 |
| 初始狀態 | Checkbox 對應 InitialFlag 0/1；同一分類只能有一筆 InitialFlag=1 |
| 作用名稱 OperationName | 必填，最多 50 字；不得等於 ControlType=EMS 的 ControlNo 或翻譯名稱 |
| 介面名稱 | 選填；只列 EXECUTIONMODE=0 且 ACCStateChangeInterface=1 的系統功能 |
| 執行檔 | 隨介面選項帶入；新增預設 ES_ACCStateChangeDescription.dll |
| 說明 | 選填，最多 255 字 |

新增與修改都檢查初始狀態唯一性。來源 CheckAccCategoryInitialState 依分類檢查所有狀態列的 InitialFlag=1，沒有排除其他 IssueState。新增/複製記錄登入者與建立時間；修改只允許 IssueState=0，分類、狀態編號/名稱、作用名稱唯讀，更新初始旗標、介面、說明等欄位並遞增 DataStamp。套用成功留在表單，確定成功後關閉。

## 按鈕及狀態規則

| 按鈕 | 行為 |
| --- | --- |
| 新增(A) | 新增未簽核定義 |
| 修改(E) | 只允許單筆 IssueState=0 |
| 複製(C) | 預帶來源列；分類鎖定，狀態/作用需調整以避免主鍵重複 |
| 刪除(D) | 可多選；0/-1 物理刪除、2 改為 -1、1 拒絕 |
| 核准 | 可多選，只處理 IssueState=0；可直接核准或進簽核 |
| 關閉 | 關閉視窗/頁面 |

DelAccessoryCategoryStateBasis 物理刪除指定三欄 PK；WebService 僅在 IssueState 0 或 -1 呼叫。IssueState=2 則以 DataStamp 設為 -1；IssueState=1 拒絕。核准走 IssueManagement；沒有 Job/Detail 時可直接設為 2，有簽核流程則設為 1，通過為 2、退回為 0。

## Oracle 資料表結構

### TBLEQPACCCATEGORYSTATEBASIS

Oracle DDL 由公司端 PowerShell 5.1 + ODP.NET 直接唯讀呼叫 DBMS_METADATA.GET_DDL 取得：

- database/reference/mestest_accessory_category_state_source_ddl.sql
- database/reference/mestest_accessory_category_state_create.sql

| 欄位 | Oracle 型別 | NULL/default |
| --- | --- | --- |
| ACCESSORYCATEGORY | VARCHAR2(50) | NOT NULL |
| ACCESSORYSTATE | NUMBER(2,0) | NOT NULL |
| ACCESSORYSTATENAME | VARCHAR2(50) | NOT NULL |
| INITIALFLAG | NUMBER(1,0) | DEFAULT 0, NOT NULL |
| ISSUESTATE | NUMBER(1,0) | DEFAULT 0, NOT NULL |
| DESCRIPTION | VARCHAR2(255) | NULL |
| CREATOR | VARCHAR2(10) | NULL |
| CREATEDATE | DATE | NULL |
| OPERATIONNAME | VARCHAR2(50) | PK 隱含 NOT NULL |
| INTERFACENAME | VARCHAR2(50) | NULL |
| EXECUTIONFILE | VARCHAR2(50) | NULL |
| DATASTAMP | NUMBER(11,0) | DEFAULT 0，可 NULL |
| REVISER | VARCHAR2(10) | NULL |
| REVISEDATE | DATE | NULL |

PK 為 ACCESSORYCATEGORY、ACCESSORYSTATE、OPERATIONNAME；只有 PK 唯一索引，沒有 FK/額外索引。DataStamp default 0 不代表 NOT NULL。

### TBLEQPACCSTATEBASIS

狀態名稱與 StateColor lookup。來源 DDL 亦以 PowerShell + ODP.NET 直連取得；初期推測 CREATE SQL 已用此 DDL 修正：

- database/reference/mestest_accessory_state_source_ddl.sql
- database/reference/mestest_accessory_state_create.sql
- database/reference/mestest_first_phase_create_tables.sql 中的 bootstrap block

PK 為 ACCESSORYSTATE，只有 PK 唯一索引。STATETYPE NUMBER(2,0) DEFAULT 1 NOT NULL；DATASTAMP NUMBER(11,0) DEFAULT 0 但可 NULL。無額外 FK/index。

## 建議 API 契約（Production 尚待家用端實作）

| 方法 | 路徑 | 用途 |
| --- | --- | --- |
| GET | /api/equipment/accessory-category-states?accessoryCategory=&issueState= | 清單，join 狀態選項回傳 StateColor |
| POST | /api/equipment/accessory-category-states | 新增 |
