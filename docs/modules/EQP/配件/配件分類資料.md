## 清單與查詢

- 預設 IssueState=0（未簽核），可切換 0 未簽核、1 簽核中、2 已簽核、-1 不使用。
- 查詢欄位為 AccessoryCategory；WinForms 以狀態 Radio 切換資料檢視。
- Grid 隱藏 IssueState 與 DataStamp；顯示配件分類、說明、建立/修改者及日期。隱藏欄位供狀態與並行控制。
- Add/Edit/Copy/Delete/Approve 可操作目前列或多選列。可用狀態必須有目前列，並以該列分類開啟 EP204。
- Vue 使用前端動態狀態更新選取列，不把選取資料放進網址。

## 新增、修改、複製

| 欄位 | 規則 |
| --- | --- |
| 配件分類 AccessoryCategory | 必填，最多 50 字；新增/複製離開欄位時轉大寫；修改時唯讀 |
| 說明 Description | 選填，最多 255 字 |
| IssueState | Service 新增時設為 0 |
| Creator / CreateDate | 新增時帶登入者與系統時間 |
| Reviser / ReviseDate | 修改時帶登入者與系統時間 |
| DataStamp | 修改帶舊值作並行條件並遞增 |

- 複製沿用說明，編號可修改；新資料為未簽核。
- 修改只允許 IssueState=0。套用成功留在表單；確定成功後關閉。
- 主鍵重複由資料庫拒絕；API 應回傳可理解的重複鍵訊息。

## 按鈕與狀態規則

| 按鈕 | 行為 |
| --- | --- |
| 新增(A) | 新增資料，IssueState=0 |
| 修改(E) | 只允許單筆 IssueState=0 |
| 複製(C) | 依選取資料建立新的未簽核列 |
| 核准 | 可多選，但只接受 IssueState=0 |
| 刪除(D) | 可多選，依 IssueState 物理刪除或停用 |
| 可用狀態 | 開啟 EP204 並傳入目前列的分類 |
| 資料匯入 | 開啟匯入視窗 |
| 關閉 | 關閉功能頁 |

刪除取自 wsEQP.DelAccessoryCategory：

- IssueState 0 或 -1：物理刪除 TBLEQPACCESSORYCATEGORY 該列。
- IssueState 2：改成 -1，並更新修改者、日期與 DataStamp。
- IssueState 1：拒絕刪除。
- clsAccBasis.DelAccessoryCategory 只刪主檔列，沒有同步刪除 TBLEQPACCCATEGORYSTATEBASIS 子列；Oracle 定義也沒有 FK。YMES API 應保留來源語意，不可描述為 cascade。
- 核准依舊簽核 Job/Detail 決定直接改為 2，或先設 1 進簽核；簽核通過為 2，退回為 0。Production API 要沿用簽核流程並回傳實際狀態。

## 匯入

- WinForms 使用第一個工作表，欄位為 AccessoryCategory（必要）及 Description（選填），資料由第二列開始。
- 依不同 AccessoryCategory 分組，呼叫 DataImporter.AccessoryCategoryDataImporter.AccessoryCategoryDataChecker，逐組回報結果/訊息；可顯示進度及取消。
- Vue Development 目前只有 CSV 預覽、範本、必填/長度/重複檢查及本機假資料結果。xls/xlsx、舊 DataChecker 和正式匯入端點待 API；Production 不使用 localStorage 假匯入。

## 建議 API 契約（Production 尚待家用端實作）

| 方法 | 路徑 | 用途 |
| --- | --- | --- |
| GET | /api/equipment/accessory-categories | 清單，回傳 IssueState、DataStamp 與稽核欄位 |
| POST | /api/equipment/accessory-categories | 新增 |
| PUT | /api/equipment/accessory-categories/{accessoryCategory} | 修改並檢查 DataStamp |
| POST | /api/equipment/accessory-categories/approve | 核准，必須沿用簽核流程 |
| POST | /api/equipment/accessory-categories/delete | 依來源狀態刪除或停用 |
| POST | /api/equipment/accessory-categories/import | CSV JSON 或 multipart/form-data 的 file 欄位上傳 Excel；回傳逐分類結果 |

刪除/核准請求至少含 accessoryCategory、issueState、dataStamp。匯入回應 results[] 每列含 accessoryCategory、result、message。Vue 批次逐筆呼叫；API 必須重新驗證狀態與 DataStamp。
