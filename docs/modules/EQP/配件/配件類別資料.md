# 配件類別資料（EP202）

## 功能識別

| 項目 | 內容 |
| --- | --- |
| 第一層 | 設備資料（EQP） |
| 第二層 | 配件 |
| 第三層 | 配件類別資料 |
| FunctionNo / FunctionKey | ACC TYPE / EP202 |
| WinForms | frmAccessoryType、frmAccessoryTypeDef、frmAccessoryLife |
| 執行檔 | EP_AccessoryType.dll |
| Vue 路由 | /YMES/Equipment/AccessoryTypes |
| 開發資料 | Development 假資料存於本瀏覽器 localStorage |

依據 STD/MESWin/EQP/EP_AccessoryType、EP_ACCProperty、EP_AccessoryTypeDataImport 的 WinForms 原始碼，以及 STD/MESkc/kcEQP/clsAccBasis.cs、STD/MESws_STD/wsSTD/wsEQP/wsEQP.cs。資料表結構由公司電腦以 PowerShell 5.1 + Oracle.ManagedDataAccess 唯讀查詢 MESTEST；不含 MES 業務資料。

## 主清單

- 初始狀態為「未簽核」(IssueState=0)，可切換未簽核 0、簽核中 1、已簽核 2、不使用 -1。
- 查詢欄位是 AccessoryType；清單依 AccessoryCategory 排序。
- 顯示配件類別、說明、配件分類、建立人/日期、修改人/日期。IssueState 與 DataStamp 是隱藏欄位。
- 支援列選取與多列選取；修改、複製、屬性、壽命管理以單列為目標，刪除與核准可批次處理。

### 主畫面按鈕

| 按鈕 | WinForms 規則 |
| --- | --- |
| 新增 | 開啟新增表單；成功後資料為 IssueState=0。 |
| 修改 | 只允許 IssueState=0；AccessoryType 唯讀。 |
| 複製 | 新代碼必填；預帶來源分類與說明。Service 新增主檔並呼叫 CopyEQPAccessoryLife 複製壽命設定；不複製屬性列。來源可為目前選取資料。 |
| 核准 | 只允許 IssueState=0，透過舊簽核流程處理。流程可能進入簽核中或完成核准，不能把按核准直接等同 IssueState=2。 |
| 刪除 | 可刪 IssueState 0、2、-1；狀態 1 拒絕。Service 先刪 TBLEQPACCESSORYPROPERTY、TBLEQPACCESSORYLIFE，再刪 TBLEQPACCESSORYTYPE。 |
| 屬性 | 開啟 EP_ACCProperty，Accessory 傳入目前 AccessoryType，AccessoryVersion 固定為 -1。 |
| 壽命管理 | 開啟 frmAccessoryLife，AccessoryNO 傳入目前 AccessoryType。 |
| 資料匯入 | 開啟 EP_AccessoryTypeDataImport。 |
| 關閉 | 關閉 WinForms 視窗；Web 頁返回 YMES 主選單。 |

WinForms 刪除/核准可處理多筆，遇到狀態不允許或服務錯誤會停止後續列；Web 目前先在送出前檢查整批狀態，避免假資料出現部分成功。

## 定義表單

- 欄位：AccessoryType 必填、最大 50；AccessoryCategory 必填、最大 50；Description 選填、最大 255。
- Add/Copy 可輸入新 AccessoryType；Edit 時編號唯讀。輸入離開欄位時轉大寫。
- 配件分類是唯讀文字加選擇按鈕。舊服務 LoadAccessoryCategory 取得非空分類；WinForms 傳入狀態參數的呼叫實際未帶出篩選，所以不可自行限縮為已簽核分類。
- 確定儲存後關閉；套用儲存後留在表單。Edit 傳入 IssueState 與 DataStamp；重複主鍵由服務/資料庫拒絕。
- Creator/CreateDate/Reviser/ReviseDate 由表單及服務寫入，不由一般使用者任意修改。

## 屬性子功能（EP_ACCProperty）

- 以 Accessory=AccessoryType、AccessoryVersion=-1 載入 TBLEQPACCESSORYPROPERTY。
- 屬性資料欄位：PropertyNo (20)、DefaultValue (255)、PropertySequence (NUMBER(2,0))、Description (255)、IssueState、DataStamp 與建立/修改稽核欄位。
- Add/Edit/Copy/Delete/Approve 沿用 IssueState 規則：只允許未簽核修改；刪除狀態 0、2、-1；核准狀態 0。主檔刪除會先刪除全部版本的屬性列。
- 原表單的 PropertyNo 由系統元素/值清單選取；目前 Vue Development 子視窗接受手動輸入，選項搜尋器待補。

## 壽命管理子功能（frmAccessoryLife）

- 以 Accessory 為主鍵載入或新增 TBLEQPACCESSORYLIFE；沒有此列時以新增模式開啟。
- 欄位：LifeManage、LifeScript、Repairable、RepairCycle、ScrapType、ScrapLife、LifeTolerance、TimeCycle、AlertTime、AlertCount 與稽核/DataStamp。
- LifeManage 必選。若啟用，批數管制與週期管制至少選一種；批數管制需要公式及數值週期；週期需正整數。AlertCount/AlertTime 若有填，需正整數。Repairable、LifeTolerance 需選擇；可維修時要選 ScrapType。
- 停用壽命管理時，WinForms 會關閉相關欄位並清空控制值。公式編輯器目前以文字輸入簡化，公式語法驗證待補。

## 資料匯入

- 舊表單只讀第一個 Excel 工作表；欄序為 AccessoryType、AccessoryCategory、Description。前兩欄必填、說明可空。
- 預覽/結果欄為 AccessoryType、AccessoryCategory、Message。後端以 AccessoryType + AccessoryCategory 分組呼叫 DataImporter.AccessoryTypeDataImporter.AccessoryTypeDataChecker，各組回報結果。
- Development 本地預覽目前支援 UTF-8 CSV 與 CSV 範本；WinForms .xlsx/.xls 解析、正式 Excel 範本、Checker 驗證及非同步進度/取消尚未複刻。Production 應由 API 接手 Excel 解析與逐組結果，不能用前端假驗證取代舊 Checker。

## YMES API 契約（家用端待實作）

| 方法 | 路徑 | 用途 |
| --- | --- | --- |
| GET | /api/equipment/accessory-types | 取得主檔及狀態、稽核欄位 |
| POST | /api/equipment/accessory-types | 新增 |
| PUT | /api/equipment/accessory-types/{accessoryType} | 修改；驗證未簽核及 DataStamp |
| DELETE | /api/equipment/accessory-types/{accessoryType} | 交易式刪除屬性、壽命、主檔；檢查 IssueState/DataStamp |
| POST | /api/equipment/accessory-types/{accessoryType}/approve | 啟動並回報舊簽核狀態轉換 |
| POST | /api/equipment/accessory-types/{sourceType}/copy | 新增指定代碼；同一交易複製壽命列，不複製屬性列 |
| GET | /api/equipment/accessory-categories | 提供分類選擇；依舊 LoadAccessoryCategory 語意，不任意加狀態篩選 |
| GET | /api/equipment/accessory-types/{accessoryType}/properties?accessoryVersion=-1 | 讀取屬性 |
| POST/PUT/DELETE | /api/equipment/accessory-types/{accessoryType}/properties[/{propertyNo}] | 屬性 CRUD；固定版本 -1、IssueState/DataStamp |
| POST | /api/equipment/accessory-types/{accessoryType}/properties/{propertyNo}/approve | 屬性簽核 |
| GET/PUT | /api/equipment/accessory-types/{accessoryType}/life | 讀寫壽命設定 |
| POST | /api/equipment/accessory-types/import | 上傳/檢核 Excel，回傳逐配件類別結果與訊息 |

Vue Production 僅呼叫上述 API；未完成 API 時顯示未接通，不回退 localStorage。API 需在伺服器端重新驗證欄位、狀態、DataStamp、分類存在性及簽核權限。
