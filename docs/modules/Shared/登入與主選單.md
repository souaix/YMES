# 登入與主選單

## 範圍

本文件涵蓋 YMES 共用登入頁、環境切換、登入狀態還原、Demo 登入、登出與主選單載入。入口由 `web/src/App.vue` 控制；正式 API 位址依環境設定取得，登入狀態使用同源 session cookie。開發模式的頁面預覽由 `developmentPreview` 隔離，不得把假資料結果當成正式交易。

## 登入與還原

- 啟動時先讀取環境設定，再呼叫 `/auth/me` 還原 session；等待期間停用帳密、環境與 Demo 操作。還原失敗時顯示錯誤並允許重新確認，不自動改送到其他環境。
- 登入呼叫 `/auth/login`；初次登入需改密碼時切到改密碼頁。Demo 按鈕使用開發測試帳號，正式環境仍以登入 API 回應為準。
- 登入成功與首次改密碼完成後，等待 `/api/navigation/menu-tree` 載入；等待期間主框架保持忙碌且不可操作，選單載入完成或失敗後才解除鎖定。
- session epoch、環境和 API 位址共同識別登入請求；menu request epoch 隔離重試、登出與環境切換。過期回應不得覆寫目前使用者的選單。
- 登出只有在 `/auth/logout` 成功後才清除本機登入狀態；環境變更會中止舊請求並重置本機 session。

## 主選單與路由

伺服器 menu tree 是正式選單來源。正式載入失敗時不以簡化 DEV 清單取代，提供錯誤與重試；開發模式可顯示 fallback 清單。頁面路由由 `menuRoutes`／`functionRoutes` 對應；`/YMES/` 是首頁，選單初始折疊，收合時保留圖示。登入、登出和重試過程不應留下其他 session 的 menu response。

## 修改與驗證

調整登入／menu 載入狀態後，執行前端 typecheck 與 production build；使用 app-browser 驗證環境選擇、session 還原、Demo 登入、載入中鎖定、載入成功／失敗重試、登出及首頁路由。若 app-browser 無法操作，須在家用端待辦記錄具體阻礙，不將 HTTP health check 當成 GUI 驗收。
