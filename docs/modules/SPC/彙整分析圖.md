# SC207 彙整分析圖

## 功能範圍

- WinForms 功能：LINE CHART ANALYSIS／FunctionKey SC207，Form frmQueryLineBarChart，執行檔 SC_QueryLineBarChart.dll。
- Vue DEV 頁：/YMES/SPC/LineChartAnalysis，fallback menu function LINE CHART ANALYSIS。
- 由 QC Item 與收集要因條件載入變數量測資料，再選擇資料、Line Chart、Histogram、Factor Analysis 或 MaxMinMean 檢視。

## WinForms、Service、Core 對照

- 主 Form：D:\iMES\CSiMES\STD\MESWin\SPC\SC_QueryLineBarChart\frmQueryLineBarChart.vb（含 inline Designer）。Get 使用 LoadQCItemForVariables；搜尋窗篩選 IssueState 2／-1。選定 QC Item 後以 LoadQCItemFactor 建立動態收集要因表。MES ParameterType 0／1 的要因透過查找清單多選；ParameterType 2 可自由輸入。
- 查詢條件：Query by Date 起訖欄位預設不勾選，日期預設約兩個月區間；Show All Data 預設關閉，Data in One Page 與 Show BarChart 預設開啟。Trans to Short-Run Chart 另提供 Relative／Absolute tolerance。Query Data、Query Chart、Histogram 分別將 child 預設檢視設為 0、1、2。
- 分析子畫面：D:\iMES\CSiMES\STD\MESWin\SPC\SC_AnsLineBarChart\frmAnsLineBarChart.vb。主要分頁為 QCItem Test Data、Line Chart Analysis、Histogram、FactorAnalysis、MaxMinMean；支援資料點／批次統計、要因分析、控制界線、刷新、Save Graph 與列印。Short-Run 轉換是彙整分析的 limit 模式，與線上 Short-Run Chart 區別。
- Customer Service：D:\iMES\CSiMES\Customer\Production\MESws_STD\wsSTD\wsSPC\wsSPC.cs 的 LoadVarQCItemChartDataLog 解析 QC Item、Factor 清單、日期、FactorSerial、TransShortrun、LatestLots；依所選條件透過 Core 取得 Factor Log、Statistic Log、Detail Log、chart basis／interval detail／rule、QC Rule、Violation 與 Limit Content。
- 標準 Core：D:\iMES\CSiMES\STD\MESkc\kcQC\clsQCBasis.cs 提供 QC Item／Factor lookup、GetFactorSerial、Chart Basis／Detail／Rule 與 QC Rule；D:\iMES\CSiMES\STD\MESkc\kcSPC\clsSPC.cs 的 ShowVarFactorLog、ShowVarStatisticLog、ShowVarDetailLog、ShowSPCLimit、ShowQCChartSpec、ShowSPCVarViolation、ShowSPCVarLimitContent 供應量測、規格、limit 與違規。動態 Factor 欄名來自 Factor metadata，正式 API 需白名單並參數化值。
- Service 在找不到有效 chart basis 時會取 SPCLimit；沒有 limit 時再以 QC Spec fallback。這些分支不是 DEV 的正式算法。

## Vue DEV 行為

- QC Item picker 模擬 IssueState 2／-1、Data Type、ChartType、Sample Size 與搜尋；選取後依項目載入 Table list／Function list 多選要因及 Free input 要因。
- Query by Date 可限制假資料日期；支援 Show All Data、Data in One Page、Show BarChart、Trans to Short-Run Chart 及 Relative／Absolute tolerance。
- Query Data、Query Chart、Histogram 開啟分析視窗，含 QCItem Test Data、Line Chart Analysis、Histogram、FactorAnalysis、MaxMinMean 五種檢視；可點選圖表點看批次、量測、要因及 ERF。
- 所有量測、chart limit、Cp／Cpk、違規點、Histogram 與 Factor Analysis 統計皆為頁面記憶體假資料和簡化算法。Refresh 只更新本機狀態；Save Graph／Print 僅提示模擬結果，不讀寫檔案、不列印，也不呼叫 Service、Oracle、YMES API 或資料庫。正式環境顯示尚未開放提示。

## 家用端 API handoff

- 提供登入與 SC207 Function 權限保護的 QC Item lookup、Factor metadata lookup 與 analysis data endpoint。查詢條件包含 QC Item、核准的 FactorNo／多值、日期起訖、Show All Data 與 Short-Run limit mode；驗證日期跨度與返回筆數。
- FactorNo 及欄位識別字只接受已核准 QC Item Factor metadata allowlist；FactorValue、QC Item、日期、FactorSerial、LatestLots 等查詢值以 SQL parameters 傳入。不要將瀏覽器提交的 FactorNo 直接拼成 SQL identifier。
- 正式結果需保留來源的 FactorSerial／LatestLots 選擇、Factor／Statistic／Detail Log、chart basis／interval limit、QC Rule、Violation、SPC limit 與 QC Spec fallback 語意；使用來源 Core 規則計算，不採用 DEV 的 Cp／Cpk／界線。
- TBLSPCLIMIT 先核實 live schema 與 migration；缺可靠 DDL 前不新增 migration／CREATE。Save Graph 如要開放，另訂 Function 權限、檔案格式／bytes 上限、檔名與覆寫規則；Print Graph 不需服務端寫入 API。
