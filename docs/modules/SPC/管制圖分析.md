# SC206 管制圖分析

## 功能範圍

- WinForms 功能：`CONTROL CHART ANALYSIS`／FunctionKey `SC206`，Form `frmQueryBarControlChart`，執行檔 `SC_QueryBarControlChart.dll`。
- Vue DEV 頁：`/YMES/SPC/ControlChartAnalysis`，fallback menu function `CONTROL CHART ANALYSIS`。
- 本模組只提供查詢與圖表分析；不建立或修改 SPC 檢測資料。

## WinForms、Service、Core 對照

- 主畫面：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_QueryBarControlChart\frmQueryBarControlChart.vb`（含 inline Designer）。QC Item 透過 Get 選擇，依 QC Data Type、IssueState、ChartControl 與 QC Item Factor 載入一般 `QCChart` 或 `ShortrunChart` 群組；群組依 FactorSerial 顯示要因、KeyNode、起訖時間與筆數。選取群組後可 Query Data、Query Chart 或 Histogram。
- 分析子畫面：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_AnsLineBarChart\frmAnsLineBarChart.vb`。承接選取的 QC Item、FactorSerial／Factor、日期或最近批數與短程旗標；依 ChartType 呈現 X-R、X-S 或 X-Rm。畫面包含 QCChart／Short-run 分頁、資料／圖表／Histogram、點選資料、Show All Data、ERF 標示、單頁模式、BarChart、Collect Hold Rules、Refresh、Save Graph 與 Print Graph。Form_Load 會取消 Query by Date 預設勾選；實際預設值以來源 Form 為準。
- Customer Service：`D:\iMES\CSiMES\Customer\Production\MESws_STD\wsSTD\wsSPC\wsSPC.cs` 與同層 `wsQC\wsQC.cs`。主查詢使用 `LoadQCItemForVariables`、`LoadQCItemFactor`；分析查詢由 `LoadVarQCItemChartDataLog`／`LoadControlChartData`／`ExecuteQCChartRuleCheck` 取回量測、統計、Factor、chart basis／interval detail、規則、limit 與 violation 資料。日期、FactorSerial、Factor、短程與 LatestLots 條件會傳入 Core。
- 標準 Core：`D:\iMES\CSiMES\STD\MESkc\kcQC\clsQCBasis.cs` 的 `LoadQCItemForVariables`、`LoadQCItemFactor`、`ShowQCChartBasis`、`ShowQCChartDetailLogInterval`、`ShowQCChartRule`、`ShowQCRule`；`D:\iMES\CSiMES\STD\MESkc\kcSPC\clsSPC.cs` 的 `LoadControlChartData`、Factor／Statistic／Detail log、SPC limit 與 violation 讀取方法。Core 依 Factor 欄位 metadata 組出變動查詢欄位；正式 API 不可直接接受客戶提供的欄位識別字。

## Vue DEV 行為

- QC Item picker 以假資料模擬 Data Type、已核准 IssueState、ChartType、Sample Size 與搜尋；載入一般／短程群組及要因清單。
- 支援 KeyNode、日期／最近批數條件、Show All Data、ERF、單頁、BarChart 與 Hold Rule 開關；選取群組後開啟圖表、檢測資料或 Histogram 檢視。
- 假資料可點選圖表點並查看量測值、Lot、Factor、ERF／Rule 標示。Refresh 僅在記憶體重新計算並更新時間；Save Graph／Print 只顯示模擬訊息，不讀寫檔案或呼叫列印服務。
- 所有量測、限制線、Cp／Cpk、違規點與 Histogram 分箱均為展示用假資料和簡化算法，不代表 MES Core 結果。DEV 不連 Service、Oracle、YMES API 或資料庫。
- 正式環境只顯示尚未開放提示；本交付沒有正式 API 或 schema 實作。

## 家用端 API／schema handoff

- 提供登入及 SC206 Function 權限保護的 QC Item／Factor lookup、FactorSerial 群組查詢與分析資料 API。分析 endpoint 接受 QC Item、FactorSerial、一般／短程、允許的日期區間或最近批數、KeyNode 與顯示選項；伺服器驗證查詢範圍、筆數上限及互斥條件。
- 以既有 chart basis、detail、rule、量測與限值資料為準；移植或重用來源 Core 的 chart type、sample size、限值、QC Rule、ERF／Hold 與 violation 語意。不要把 DEV 計算結果當作正式算法。
- 動態 Factor 欄位必須由已核准 QC Item Factor metadata allowlist 選取，SQL 值使用參數；不要將 Factor 名稱直接拼入 SQL。限制日期跨度、LatestLots 與返回筆數，並固定排序以支援分頁／圖表點選。
- `TBLSPCLIMIT` fallback 先由家用端核對 YMES live schema 與 migrations；缺可靠 DDL 前不新增 migration／CREATE。桌機未新增業務資料表、未產生 SC206 CREATE SQL。
- Save Graph 若納入正式功能，需另定授權、格式／bytes 上限、檔名安全及覆寫語意；若無產品需求可不開放。Print Graph 為用戶端功能，不需建立服務端寫入端點。
