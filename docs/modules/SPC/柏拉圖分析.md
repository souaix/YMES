# SC210 柏拉圖分析

## 功能範圍

- WinForms 功能：`PARETO DIAGRAM`／FunctionKey SC210，主畫面 `frmQueryPareto`，執行檔 `SC_QueryPareto.dll`。
- Vue DEV 頁：`/YMES/SPC/ParetoDiagram`，fallback menu function `PARETO DIAGRAM`。
- 查詢一個或多個計數型 Attribute QC Item 的 SPC 批次與錯誤明細；結果視窗依 Reason 數量、發生批次數、比例、面積或 Product PCS 排序繪製柏拉圖，並提供原因明細與延伸分析。

## WinForms、Service、Core 對照

- 主 Form 與 inline Designer：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_QueryPareto\frmQueryPareto.vb`。QC Item lookup 呼叫 `wsQC.LoadQCItemForAttributes`，限制 IssueState 2／-1，可多選；依所選 QC Item 的 FactorNo 聯集載入 Collect Factor。ParameterType 0／1 用 MES Parameter lookup，多值以逗號分隔；2 為自由輸入。日期起訖各自以 checkbox 啟用，預設不限制日期。預設 Count Unit 為 By Piece Qty、Normal 勾選、Excluded 未勾、Include ReTest Lot 未勾、Scrap／Defect 都勾選。
- Query 只要求至少一個 QC Item；把 QC Item、已勾日期及非空 Factor 值傳給 `wsSPC.LoadSPCAttLogData`。Main Form 收到 `AttLogData` 後，在本機設定另一組計數條件並開 `frmAnsPareto`。Factor 欄位和值由舊 Core 動態字串接 SQL；正式 API 必須使用核准 QC Item Factor metadata allowlist 限制欄位識別字，並將所有值參數化。
- Customer Service：`D:\iMES\CSiMES\Customer\Production\MESws_STD\wsSTD\wsSPC\wsSPC.cs` 的 `LoadSPCAttLogData` 解析 QC Item、日期、Factor、ReasonType／ReasonNo；本 Form 沒傳 ReasonType／ReasonNo。標準 Service 同名方法位於 `D:\iMES\CSiMES\STD\MESws_STD\wsSTD\wsSPC\wsSPC.cs`。
- 標準 Core：`D:\iMES\CSiMES\STD\MESkc\kcSPC\clsSPC.cs` 的 `LoadSPCAttLogData` 以 Attribute BasisLog left join DetailLog 與 ReasonBasis；即使批次沒有錯誤明細也保留 BasisLog。舊查詢沒有日期跨度或資料筆數上限；正式 API 應採可設定的日期／資料量界線。
- 結果 Form：`frmAnsPareto.vb` 在 client side 套用 Normal／Excluded、ReTestLot、Scrap／Defect 篩選並重算。預設顯示 10 支 bar，輸入 0 或空值顯示全部。Piece Qty、Lot Number、Defect Rate、Dimension、Defect PCs 可切換排序；柱狀圖點選後顯示 Reason No／名稱／數量／發生筆數與符合條件的 LotNo 清單。
- 舊計數細節：總 SampleQty 與批數按 SPCSerial 去重，包含沒有 Error detail 的批次；每筆符合條件的 ErrorQty 依 ErrorNo 加總。`ErrorLotNum` 是符合條件的 reason log row 次數，不保證是 distinct Lot 數。Defect Rate = `ErrorQty / total SampleQty × 100`；Dimension = `Dimension × ErrorQty`，若所需資料缺失則停用 Dimension；PCS 會用 `wsPRD.LoadProductProperty` 讀取 Product Property 的「版數 × 片數」乘上數量，查不到時回退 1。圖表依所選指標降冪排序並顯示累積曲線；Defect Rate 模式關閉曲線。
- 延伸按鈕包括 Reason Detail、Compare Selected、Fishbone、Rank Detail、Section Detail、Pie Chart、Last 4 Weeks、Export All Error、Save Graph、Print。多數視圖使用當前 in-memory data；Last 4 Weeks 會按週重查 `LoadSPCAttLogData`；Section Detail 額外呼叫 `wsSPC.LoadSPCAttDetailLogSection`／`kcSPC.LoadSPCAttDetailLogSection`，讀 `TBLSPCATTDETAILLOGSECTION` 並連 BasisLog 取得 LotNo。Section 查詢會套 QC Item、Factor、日期、Reason、Lot State、Scrap／Defect 條件。Export All Error 輸出完整錯誤彙總，Save Graph 支援 JPG／BMP／GIF，Print 走 client print。

## Vue DEV 行為

- QC Item 多選 picker、日期條件、Factor 聯集、多值 lookup／自由輸入；Query 後提供 Normal／Excluded、Include ReTest Lot、Scrap／Defect、Count Unit 與 Bar Number 控制。
- 本機假資料模擬 Attribute logs、sample totals、reason 聚合、五種排序指標、Top N bar、累積百分比、柱點多選、原因／Lot 清單及 summary；互動視窗模擬 Detail、Compare、Fishbone、Rank、Section、Pie、Last 4 Weeks。
- Export、Save Graph、Print 只顯示模擬提示，不寫檔、不呼叫印表機。DEV 所有 Item、Factor、Log、Product Property、Reason、Section 與數值皆為假資料。PCS 倍率、Dimension 可用性、累積線及延伸分析僅為介面互動示意，不代表 Legacy 元件的像素或所有商業例外。
- 正式環境顯示尚未開放提示；公司端未呼叫 Service／Oracle／API／資料庫。

## Oracle DDL 與資料表參考

- `TBLSPCATTBASISLOG`、`TBLSPCATTDETAILLOG` 沿用 [Attribute source DDL](../../../database/reference/mestest_qc_item_attributes_source_ddl.sql) 與 [YMES CREATE-only reference](../../../database/reference/mestest_qc_item_attributes_create.sql)。`TBLQCREASONBASIS` 沿用 QC218 source DDL 與既有 [CREATE-only reference](../../../database/reference/mestest_qc_reason_basis_create.sql)。
- Repo 未找到 `TBLSPCATTDETAILLOGSECTION` 的 Oracle DDL／metadata／PostgreSQL CREATE-only。公司桌機受保護 Oracle profile 不存在，本次未連 Oracle；不可由 Core SELECT 推測 section table 欄位或自行建立 SQL。家用端先核 YMES live schema／既有 migrations；若缺表，再透過 MESTEST 受保護唯讀 metadata 取得完整 DDL 後補 handoff。`TBLSPCATTDETAILLOG`／`TBLQCREASONBASIS` 之外的 Product Property lookup 也需家用端核對既有正式 schema/API。

## 家用端 API／schema handoff

- Pull 後先比對 Attribute BasisLog／DetailLog、ReasonBasis、`TBLSPCATTDETAILLOGSECTION` 與 PCS 所依賴的 Product Property live schema／既有 migrations；沿用已存在物件。Section table 缺可信 metadata 前不猜建表或補 CREATE-only。
- 提供登入與 SC210 Function 權限保護的 Attribute QC Item lookup、QC Item Factor metadata／MES Parameter lookup，以及限量唯讀 Pareto query。輸入多個 QC Item、可選日期、Factor 值；回傳 logs 與 Reason metadata。後端先限制日期跨度、批次／detail 數、最大 QC Item 數，FactorNo 僅由相關 QC Item metadata allowlist 產生；QC Item、Factor values、日期一律 SQL parameters。
- 狀態、重測批、Scrap／Defect、Count Unit、Top N 與圖表聚合可在受限 API 回傳的資料上依規格計算，或集中由後端回傳聚合結果；不得複製 Legacy 未參數化 SQL。保留 `ErrorLotNum` 的舊 row-count 語意時，API 欄位需明確命名，避免誤稱 distinct lots。
- Section Detail 需提供登入／SC210 權限保護的限量端點，限定 QC Item、日期、Factor、Reason、Excluded 與 DefectType，並確認 source section table schema 後再做查詢。PCS 需核對產品版數／片數正式 lookup；若正式端不提供，將此模式列為明確簡化。Export／Save／Print 如需正式提供，另定檔案格式、bytes 上限、權限與 client-side print 邊界。
- 公司端未連 YMES PostgreSQL，未建立 migration／schema／正式 API，未 SSH／部署。
