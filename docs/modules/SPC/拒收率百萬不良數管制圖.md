# SC211 拒收率／百萬不良數管制圖

## 功能範圍

- WinForms FunctionKey：SC211「LRR / PPM CHART」，主畫面 `frmQueryLRRandPPMChart`，執行檔 `SC_QueryLRRandPPMChart.dll`。
- Vue DEV 頁：`/YMES/SPC/LrrPpmChart`，fallback function key `function:SPC:LRR / PPM CHART`。
- 單選計數型 Attribute QC Item，依日期、週／月／年、Normal／Excluded 與 Collect Factor 彙總檢驗批次；結果可檢視 LRR 或同時檢視 Scrap PPM、Defect PPM，並可對期間設定手動目標線。

## WinForms、Service、Core 對照

- 主 Form 與 inline Designer：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_QueryLRRandPPMChart\frmQueryLRRandPPMChart.vb`。Load 預設起日為 `DateAdd("m", -2, DateAdd("d", 1, Now))`、迄日為當日；PPM、MONTH、Normal 預設勾選。QC Item picker 呼叫 `wsQC.LoadQCItemForAttributes`，帶 `ChartControl=1`、`IssueState=defInteger`，快搜清單過濾 `IssueState = 2 or -1`，最後單選一個 QC Item。選定後 `wsQC.LoadQCItemFactor` 讀取該 Item 的 Factor metadata。
- Collect Factor 使用 UltraGrid。ParameterType 0／1 的 Value 唯讀，透過 `wsSYS.LoadMesParameterRef` 查找並多選；ParameterType 2 可直接輸入，編輯後轉大寫；以逗號分隔多值。查詢前需至少選一種 Lot Report State；只選 Normal 傳 `Excluded=0`、只選 Excluded 傳 `1`、兩者都選傳預設值（不加狀態條件）。來源雖可兩者都不選，但會顯示必選訊息並停止查詢。
- 日期、QCItemNo、週／月／年 `ReportType`、Excluded 與 FactorNo／FactorValue 清單傳到 `wsSPC.LoadSPCLRRandPPMAttLogData`。標準 Service：`D:\iMES\CSiMES\STD\MESws_STD\wsSTD\wsSPC\wsSPC.cs`；同一方法亦在 Customer `D:\iMES\CSiMES\Customer\Production\MESws_STD\wsSTD\wsSPC\wsSPC.cs`，本輪對照片段一致。Service 解析日期、Excluded、Factor 與 ReportType，要求 ReportType 存在，再呼叫 Core `LoadSPCLRRandPPMAttLogData`。
- 標準 Core：`D:\iMES\CSiMES\STD\MESkc\kcSPC\clsSPC.cs` 的 `LoadSPCLRRandPPMAttLogData`。讀 `TBLSPCATTBASISLOG`，依 `CreateDate` 與期間逐段聚合 `SUM(SampleQty)`、`SUM(ScrapQty)`、`SUM(DefectQty)`、`COUNT(Result)`、拒收批數。`Result=0` 才是 Accept，其餘任何 Result 值都算拒收；Oracle 用 `DECODE(Result,0,0,1)`，其他 DB 用 `CASE`。Normal／Excluded 只在狀態值為 0 或 1 時分別加 `A.Excluded IN (0)`／`IN (1)`；預設值不加條件。Factor 多值以逗號拆分後套用 `A.<FactorNo> IN (...)`。
- Period ReportType 0 為週（Core 以週日為起點、週六為終點）；1 為月；2 為年。期間首尾會裁切到使用者查詢日期。Form 若 `gEnterpriseNo = VISERA` 且選週，改傳 3；Core 另外查 `TBLSYSCALENDAR` 的 `FROMDATE`／`ENDDATE`／`YEAR_WEEK`，要求曆區間連續且完整，使用每日 07:20 分界。DEV 只模擬通用週曆，沒有 VISERA calendar profile。
- 結果視窗 `D:\iMES\CSiMES\STD\MESWin\SPC\SC_QueryLRRandPPMChart\frmAnsLRRandPPMChart.vb`：`ReportType=0`（圖表型態）畫 `TotalRejectLotQty / TotalLotQty`，沒有乘 100，來源比率範圍是 0–1；`ReportType=1` 畫兩條線：`TotalScrapQty / TotalSampleQty × 1,000,000` 與 `TotalDefectQty / TotalSampleQty × 1,000,000`。X 軸為期間標籤，Period Summary 對應每期間日期及彙總數。手動 Limit Line 可指定起訖 Period 與一個正數，套用在該範圍；任一圖表系列高於該值標紅。LRR 的 limit 輸入值沿用 0–1 比率，不是百分數。
- WinForms 結果窗另有 Save Graph、Print、Export；DEV 僅顯示提示，不產生檔案。來源週標籤為 `W` 加 WeekOfYear、月為 `M` 加月份、年為 `Y` 加年份；若跨年週標籤可能重複，日期區間仍可辨別。

## Vue DEV 行為

- 預設 PPM／MONTH／Normal，起訖日採來源預設；QC Item 搜尋器只列假資料中 IssueState 2／-1 的 Attribute Item。選定 Item 後顯示 Factor metadata；ParameterType 0／1 使用本機選項多選，2 可輸入逗號分隔值並轉大寫。
- Query 驗證 Item、有效日期順序及至少一種 Lot Report State。Normal 與 Excluded 同時勾選代表兩種批次都納入；單選只納入相對狀態。以本機假批次按 Factor 與日期分組，再計算 Core 相同欄位與 LRR／PPM 公式；零分母用 0 顯示，圖表不會產生 Infinity。
- 結果提供 LRR 單線或 Scrap／Defect PPM 雙線、期間表、摘要、點選期間明細、可指定期間範圍的手動目標線與超標點標示。Save Graph／Export／Print 只顯示 DEV 提示；正式環境顯示尚未開放。QC Item、Factor、批次、值及彙總均為假資料，圖表呈現不代表 Oracle 資料或 VISERA 週曆。

## Oracle DDL 與資料表參考

- Core 主查詢只使用 `TBLSPCATTBASISLOG`；其 Oracle source DDL 與 PostgreSQL CREATE-only 已沿用 [Attribute source DDL](../../../database/reference/mestest_qc_item_attributes_source_ddl.sql) 與 [Attribute CREATE-only reference](../../../database/reference/mestest_qc_item_attributes_create.sql)，本模組不新增業務表。
- `TBLSYSCALENDAR` 僅在 VISERA 企業週曆分支使用。repo 未找到此表的 Oracle DDL／metadata 或 PostgreSQL CREATE-only；桌機受保護 Oracle profile 不存在，沒有連 Oracle 或推測欄位。此分支目前是明確未取得來源 DDL 的項目；未確認 live schema 前，家用端不得猜建日曆表。
- 公司桌機未連 YMES PostgreSQL，未建立 schema、migration 或正式 API。

## 家用端 API／schema handoff

- Pull 後核對 YMES live schema 與既有 migration：沿用 Attribute QC Item、Factor metadata、`TBLSPCATTBASISLOG`，不重建既有表。若需要支援 VISERA 週曆，先核 live `TBLSYSCALENDAR`；只有來源 schema 確認缺表且取得可信 MESTEST DDL／metadata 後，才提供 CREATE-only reference，否則將此分支明確列為不支援。
- 提供登入與 SC211 Function ACL 保護的 Attribute QC Item lookup、單 Item Factor metadata／Parameter lookup，以及限量彙總唯讀 API。輸入單一 QC Item、日期起訖、PeriodType、Lot Report State 與 Factor 值；回傳每期 Date／Period、五個聚合欄位。API 依 Core 的 Result 語意（只有 0 為接受）、Excluded 篩選及 LRR／PPM 定義計算，安全處理零分母。
- 日期必須驗證起訖與最大跨度，週／月／年 period enum 必須白名單驗證。所有 QC Item、日期、Excluded、Factor values 以 SQL parameters 傳遞；FactorNo 欄位識別字只可由已授權 QC Item 的 Factor metadata allowlist 產生。不要複製 Legacy Core 以 SQL 字串串接值及欄名的方式。
- LRR API 使用比率 0–1，前端可格式化百分比；PPM API 同時回傳 Scrap PPM 與 Defect PPM。手動 Limit Line 是使用者視圖設定，初版可在 client 端按 period index 套用，不需持久化。Save／Print／Export 若正式開放，另定檔案格式、授權、輸出大小及覆寫行為。
- `TBLSYSCALENDAR` metadata 尚缺時，不以推測 schema 增加 migration。公司端只交付 DEV 與規格／handoff；未連 PostgreSQL、未實作或驗收正式 API。
