## 功能目的與範圍

以 Attribute QC Item 的計數檢驗資料，繪製 Scrap 的 P／np 圖與 Defect 的 C／U 圖，檢視批次狀態、超界點及不良原因。公司端交付 DEV 假資料互動和來源規格；正式資料查詢、狀態更新、管制界線保存與 PostgreSQL schema 由家用端處理。

## WinForms 查詢畫面

| 控制項 | 預設／規則 |
| --- | --- |
| QC Item | 必選 Attribute QC Item；以 `wsQC.LoadQCItemForAttributes` 查詢，要求 `ChartControl=1`、`QCItemType=1`。結果窗使用選定 QC Item 的規格欄位。 |
| Factor | 依 QC Item 載入 `wsQC.LoadQCItemFactor`。ParameterType 0／1 使用參數參照多選；ParameterType 2 為自由輸入並轉大寫。傳入 FactorNo／FactorValue 條件。 |
| 起訖日期 | 起訖值預設約兩個月前至目前時間，但日期勾選預設關閉；未勾選的日期不傳入查詢。 |
| Lot Report State | Normal 預設勾選、Excluded 未勾選。只選 Normal 傳 `Excluded=0`；只選 Excluded 傳 `1`；兩者都選傳 `defInteger`（不篩狀態）；都不選時阻止查詢並提示。 |
| ShowBarChart | 預設勾選，控制結果視窗的長條分布圖。 |
| ShowInOnePage | 預設未勾選，控制四圖排版。 |

Query 先呼叫 `wsSPC.LoadSPCAttPChartLogRowData` 取得批次列，再呼叫 `wsSPC.LoadSPCAttPChartLogData` 取得 Error detail。Form 未傳 `LimitLotNum`，舊 Service／Core 預設值代表不限制筆數；Web API 必須另加上限與分頁策略。結果列依 `SPCSerial` 排序後繪圖。

## 結果、欄位與計算

| 圖表 | 點值 | 正常批次基準及控制界線 |
| --- | --- | --- |
| P Chart Scrap | `ScrapQty / SampleQty` | `p̄ = ΣNormal(ScrapQty) / ΣNormal(SampleQty)`；每批界線為 `p̄ ± 3√(p̄(1−p̄)/SampleQty)`，LCL 不低於 0。 |
| np Chart Scrap | `ScrapQty` | 中心線為 Normal 批次平均 ScrapQty；上下界為平均值 ± `3√平均值`，LCL 不低於 0。 |
| C Chart Defect | `DefectQty` | 中心線為 Normal 批次平均 DefectQty；上下界為平均值 ± `3√平均值`，LCL 不低於 0。 |
| U Chart Defect | `DefectQty / SampleQty` | `ū = ΣNormal(DefectQty) / ΣNormal(SampleQty)`；每批界線為 `ū ± 3√(ū/SampleQty)`，LCL 不低於 0。 |

Normal 批次（`Excluded=0`）用於計算中心線和界線；Excluded 批次仍可出現在圖上，但不參與基準。重算命令會重新計算四種圖的中心線與界線。來源另有 `US`／`LS` 規格界線：越界判斷使用它們，不等同圖上依樣本數變動的 `UCL`／`LCL`。若該點有 `ERFNo`，點狀態優先標示 ERF。

來源相容性注意：`frmAnsAttChart.funReCalLimits` 計算 Defect 圖的暫存 UCL／LCL 後，賦值處仍引用 Scrap 的暫存上下界。家用端需決定是否保留舊結果相容性或採正確的 Defect 計算，並把決定記入正式規格；DEV 使用每圖各自的統計量計算示意界線。

結果視窗可切換 Scrap／Defect／All、X 軸 LotNo／CreateDate／Factor，選點查看 QC Item Factor、LotNo、CreateDate、SampleQty、ScrapQty、DefectQty、ERFNo、各圖數值及原因明細。Error detail 以 `ErrorQty > 0` 為條件，`ErrorType=0` 為 Scrap，其餘 Defect；與 `TBLQCREASONBASIS` 連接取得原因名稱。來源明細查詢不收 Excluded 條件；Web 實作應只為當次查詢回傳的 SPCSerial 載入明細，並限制明細筆數。

## 操作與狀態

| 操作 | 舊程式行為 | Web DEV 行為 |
| --- | --- | --- |
| Query | 驗證 QC Item 與狀態選擇，依日期／Factor／Excluded 載入批次列和原因明細。 | 在本機假資料篩選；日期只有勾選時才生效。 |
| Lot 狀態 | 結果點選單將指定 `SPCSerial` 設為 Normal／Excluded，經 `wsSPC.UpdAttLotState` 更新。 | 本機覆寫並提供模擬回存提示；不呼叫 API。 |
| 界線重算／設定 | `frmAnsAttChart` 重算或開啟 `frmAnsAttChartSetLimit`；確認後重新判斷點狀態和繪圖。 | 重新計算本機界線；可編輯 US／LS／UCL／CL／LCL，套用或保存到頁面記憶體。 |
| Save Graph／Print／Export | WinForms 提供圖表檔案、列印及匯出。 | 只顯示 DEV 提示，不建立或傳送檔案。 |

舊 Core 的 `LoadSPCAttChartLimit` 會依 FactorNo 動態增加 `TBLSPCATTCHARTLIMIT` 欄位，透過 `ALTER TABLE` 修改 schema，且非 Oracle 分支還會補寫預設值。這是舊式動態欄位設計，家用端不得直接複製；Factor 欄位名稱必須白名單化，查詢／更新值必須參數化。

## 家用端 API／schema handoff

- 先比對 YMES live schema／既有 migration，核實 Attribute basis/detail、reason、`TBLSPCATTLIMIT`，以及是否已有 chart-specific limit 儲存結構。缺 `TBLSPCATTCHARTLIMIT` 的可信 metadata 時不要照舊程式猜建。
- 建立有登入及 SC212 Function 權限保護的 QC Item／Factor metadata lookup；查詢必須限制 QC Item 為 Attribute 且 `ChartControl=1`。ParameterType 0／1 的值選項需依現有授權 lookup 提供，ParameterType 2 作為受限文字條件。
- 建議唯讀查詢回傳批次列及對應圖表值／界線；條件包含單一 QC Item、可選起訖日期、`Excluded` 為 0／1／全部、Factor 條件。日期、批次數、因素數、Factor values 和 Error detail 均需限制；FactorNo 欄位名只可從該 QC Item 的 metadata allowlist 選取，其值參數化。
- Error detail 查詢限定在已回傳的 SPCSerial 集合，保留 `ErrorQty > 0` 與 Scrap／Defect 原因分類，使用 `TBLQCREASONBASIS` 取顯示名稱，避免無界全量明細查詢。
- Lot 狀態更新至少核實 `SPCSerial` 存在、目標狀態允許值、登入者權限與更新筆數；可用單筆契約對齊舊 `UpdAttLotState`，或在明確交易中提供批次更新。
- 管制界線應使用固定 schema（例如 Factor 條件 JSONB 或正規化子表），不要依使用者 FactorNo 執行 DDL。確認限制數值、QC Item／Factor 綁定、重複條件及更新交易；是否需要永久保存依 live schema／業務規則確認。
