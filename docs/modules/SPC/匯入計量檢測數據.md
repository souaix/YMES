# SC107 匯入計量檢測數據（IMPORT VAR MEASURE）

## 選單與來源

- 選單識別：Module `SPC`、FunctionNo `IMPORT VAR MEASURE`、FunctionKey `SC107`、Form `frmImport_VarMeasureData`、ExecutionFile `SC_Import_VarMeasureData.dll`，分類 `SPC管制`。
- WinForms Form／inline Designer：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_Import_VarMeasureData\frmImport_VarMeasureData.vb`；範本類型選擇 Form／Designer：`frmFileTypeSelect.vb`、`frmFileTypeSelect.Designer.vb`。
- Service：`STD\MESws_STD\wsSTD\wsSPC\wsSPC.cs` 的 `AutoBRSPCContorl_Var`，以 `SPCData` 與 `TestValue` DataSet 接收匯入列及攤平量測點；同檔另有 `LoadSPCImportData`。本 Form 搜尋未見呼叫 `LoadSPCImportData`。
- Core：Service 轉呼叫 `STD\MESkc\kcWIP\clsMDS.cs` 的 `funAutoBRSPCContorl_Var`；計量寫入與待檢資料另經 `STD\MESkc\kcSPC\clsSPC.cs` 的 `UpdVar_TestValue`、`UpdSpcLotQCList`、`AddSPCVarLimitContent`、`AddSPCViolationContent`。

## WinForms 流程與規則

- File 僅選 `.xls`；Infragistics 讀第一張工作表，第一列作欄名、後續列作資料，空白資料列即停止。欄位索引有缺口會拒絕載入；QCItemNo 轉大寫；每列加上 Execute／Result／LotSerial／Select 狀態欄。第一個資料列以 0 起算 LotSerial。
- `PrepareData` 將 `S01`–`S99` 量測欄攤平成 `TestValue` 的 LotNo／QCItemNo／SerialNo／TestValue／MEMO／ComponentNo／LotSerial，依欄位順序配置 SerialNo；每個存在的 S 欄都必須有數值。`Snn_MEMO` 是可選量測備註，其餘欄位傳入 SPCData。ComponentNo 欄位可使用元件範本。
- Template DownLoad 開啟範本類型選擇：一般 `IMPORT VAR MEASURE`／`SPCData_Template`，元件 `IMPORT VAR MEASURE_COMP`／`SPCData_ComponentNo_Template`。`wsSYS.funLoadFileExtension` 決定 xls／xlsx，`wsSYS.GetTemplateFile` 下載檔案。
- Check 與 Save 都先以目前勾選且未完成列組 DataSet。Check 送 `ChkOnly=true`，清除舊勾選後呼叫服務；成功列由 callback 重新勾選，失敗列顯示 Core 回傳訊息。Save 不要求先 Check；已成功列標記 Execute=True 並取消勾選，同批不可再次儲存。SelectAll／UnSelectAll 批次切換列選取。
- `funAutoBRSPCContorl_Var` 檢查量測值、QC Item、Lot、QC Item Factor 與管制圖；純 Check 在 SPC Chart 檢查後返回，不寫量測。Check 路徑另檢查同 Lot／QCItem 是否已存在 SPC Factor Log。Save 產生 Pass／Hold／Alarm／Alert／Wait／Warning 結果，呼叫 `UpdVar_TestValue` 寫入計量、因子、統計等資料，更新 SPC Lot QC 待檢清單並存限值快照／違規；有條件時建立 ERF 與寄送通知。交易／外部副作用不可簡化成單表 INSERT。
- `wsSPC.LoadSPCImportData` 會呼叫 Core `clsSPC.LoadSPCImportData`，執行 `SELECT * FROM TBLSPCImportData WHERE LotNo IS NOT NULL`，可附 LotNo／OPNo／QCItemNo／MeasureDate／Additional 條件；目前 Form 原始碼未使用此方法，正式端需先確認其他呼叫端是否依賴此查詢。

## Vue DEV 頁與簡化界線

- DEV 選單與 fallback 路由：`/YMES/SPC/VariableMeasurementImport`。
- 提供一般／元件範本欄位切換、瀏覽器下載開發用 XLSX 範本、載入開發假資料、讀取 `.xlsx`／`.csv` 第一張表、逐列勾選、SelectAll／UnSelectAll、Check 與 Save。檢查展示必填 Lot／QC Item、量測點數字與元件號，以及假批號／QC Item 不存在、重複檢查等結果；成功列保留勾選供 Save，儲存成功列鎖定並解除勾選。
- 假資料、選取、檢查結果及儲存結果只在頁面記憶體；沒有呼叫 Service、寫入資料庫、建立 SPC serial、ERF 或寄信。假檢查只用有限 DEV fixtures，沒有執行正式 QC Item／Lot／Factor／Chart 查核或規格計算。
- WinForms 原生 `.xls` 解析、Infragistics Grid／欄位版面與範本原檔下載沒有在瀏覽器重現；DEV 支援 `.xlsx`／`.csv`，產生的 XLSX 欄位是手動整理的開發範本，不能視為正式範本契約。手動檢視以外未執行 build／test／browser。

## 資料表、metadata 與家用端 handoff

- SPC 量測、因子、統計、限值、違規及待檢表與 SC101 共用路徑；repo 有部分 QC205／SC101 相關 MESTEST references，家用端需按本機實際 STD Core 分支逐表對照 live schema、既有 CREATE-only 及版本，不能把參考檔直接認定為 SC107 全部交易表。SC101 規格列出共用寫入面及尚未核實的交易邊界。
- `TBLSPCImportData` 只在此 Service/Core 查詢方法出現；repo 未找到其 Oracle source DDL／metadata 或 PostgreSQL CREATE-only。桌機受保護 Oracle profile 不存在，本次未連 Oracle、未猜 schema；主 Form 目前不呼叫此查詢，若正式 API 要保留該能力，家用端先確認實際使用端並取得可信 DDL。
- 正式 API 應提供受 FunctionNo 授權的範本／檔案預覽、批次檢查與批次儲存；白名單允許的標頭、S01–S99／MEMO／Component 對應、首個空白資料列終止、逐列結果均由 server 定義。用伺服器端 Lot／QC Item／Factor／Chart／權限重新驗證，不採信瀏覽器 Check 結果；儲存應以交易涵蓋計量 Online／Log、Factor、Statistic、Limit、Violation、SPC 待檢及條件式 WIP／ERF 副作用，並回傳逐列可重試結果與防重策略。
- 家用端先確認 `funAutoBRSPCContorl_Var` 交易 helper 實際提交邊界、同批多列部分失敗語意、SPC serial 配置、ERF／mail 的部分成功處理，以及 `LoadSPCImportData` 的呼叫端與篩選條件。公司端不連 YMES PostgreSQL、不實作或驗收正式 API/schema。
