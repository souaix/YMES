# SC208 散佈圖分析

## 功能範圍

- WinForms 功能：SCATTER DIAGRAM／FunctionKey SC208，Form `frmQueryScatterChart`，執行檔 `SC_QueryScatterChart.dll`。
- Vue DEV 頁：`/YMES/SPC/ScatterDiagram`，fallback menu function `SCATTER DIAGRAM`。
- 選兩個不同的計量 QC Item，設定共同收集要因、日期、Lot Report State 及 Lot Result；以 LotNo + SerialNo 配對兩組量測，繪製散佈圖與線性關係資訊。

## WinForms、Service、Core 對照

- 主 Form：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_QueryScatterChart\frmQueryScatterChart.vb`（Designer inline）。`wsQC.LoadQCItemForVariables` 載入變數 QC Item；搜尋清單只列 IssueState 2／-1，且排除另一軸已選項目。兩個 Get 各呼叫 `wsQC.LoadQCItemFactor`；FactorNo 交集才建立 Collect Factor。`MES ParameterType` 0／1 由 `wsSYS.LoadMesParameterRef` 查找單一 FactorValue，2 可自由輸入並轉大寫。至少一個共同要因必須有值才可 Query。
- 日期預設為約兩個月區間，但 From／End 兩個日期勾選預設皆關閉；可只指定單側日期。若兩側都指定，起日必須早於迄日。Lot Report State（Normal／Excluded／Isolated）及 Lot Result（Pass／Fail）預設全選，至少各選一項。
- 分析子畫面：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_QueryScatterChart\frmAnsScatterChart.vb`。分別讀兩組 QC Item 資料，再以 LotNo + SerialNo 配對；圖表點選會定位明細 Grid。提供 Factor／配對量測／統計參數 Grid、Save Graph（JPG／BMP／GIF）及 Export（XLS）。
- `ScatterChartLayer.vb` 計算 Pearson correlation、mean、slope、intercept、variance 並繪製回歸線。來源對標準差平方和先將每筆 X／Y 四捨五入為整數再減 mean；Slope = r × stdDevY / stdDevX，Variance = rounded-square-sum / (n - 1)。正式頁需確認是否保留此舊公式及零變異／極少樣本的處理。
- Customer Service：`D:\iMES\CSiMES\Customer\Production\MESws_STD\wsSTD\wsSPC\wsSPC.cs` 的 `LoadScatterChartData` 解析兩個 QC Item、日期、FactorNo／FactorValue／FactorOnLine、LotState 與 LotResult，呼叫標準 Core。
- 標準 Core：`D:\iMES\CSiMES\STD\MESkc\kcSPC\clsSPC.cs` 的 `LoadScatterChartData` 對兩個 QC Item 分別查詢 `TBLSPCVARFACTORLOG` 與 `TBLSPCVARDETAILLOG`，套用 Factor、CreateDate、Excluded、Result 條件並按 LotNo／FactorSerial／SPCSerial／SerialNo 排序。Legacy SQL 將 FactorNo 當欄位識別字串接，FactorValue 及 QC Item／日期亦字串接；正式 API 必須以核准 Factor metadata 白名單限制識別字，所有值參數化。WinForms 子畫面配對使用 LotNo + SerialNo，第二組找到多筆時只取第一筆；正式實作需核對重複配對的定義。

## Vue DEV 行為

- 兩個獨立 QC Item picker 模擬 IssueState 2／-1，避免同一項目同時放在 X、Y 軸；載入 FactorNo 交集及 ParameterType 0／1 下拉查找、2 自由輸入。
- 日期端點可各自啟用；Normal／Excluded／Isolated 與 Pass／Fail 預設全選。Query 驗證兩個 QC Item、日期順序、狀態／結果選項及至少一個 FactorValue。
- 使用記憶體假資料分別產生兩組量測，依 LotNo + SerialNo 配對。散佈點和配對資料列互相定位；顯示 correlation、slope、intercept、mean、variance 及線性關係線。
- 樣本、時間、Factor lookup、數值、配對結果及統計皆為本機假資料與近似算法。Save Graph／Export 僅顯示提示，不建立圖檔或 Excel，不呼叫 Service、Oracle、YMES API 或資料庫。正式環境顯示尚未開放提示。
- 相較來源查找視窗，DEV 將 ParameterType 0／1 呈現為單選下拉；未實作 Product Factor 的 ProductType 相依篩選及 Excel／圖片輸出。

## 家用端 API handoff

- 提供登入與 SC208 Function 權限保護的 QC Item／共同 Factor metadata lookup，以及限量的唯讀 scatter query。輸入兩個不同 QC Item、可選日期起訖、共同 FactorNo／FactorValue、LotState 與 LotResult；只允許兩項 QC Item 的 FactorNo 交集。
- Factor 欄位 identifier 僅由已核准 QC Item Factor metadata allowlist 產生；QC Item、FactorValue、日期、LotState、LotResult 一律 SQL parameter。限制最大日期跨度、資料筆數及兩組查詢成本。
- 核對正式配對鍵是否仍為 LotNo + SerialNo、重複鍵處理、兩組查詢一致性與 LotState／Result 定義；正式統計需確認來源 ScatterChartLayer 的四捨五入公式及小樣本零變異行為。
- 家用端比對既有 live schema／migration，不重建 SC205／SC206／SC207 已引用的計量表；公司端未連 YMES PostgreSQL、未實作正式 API/schema，未 SSH／部署。
