## 功能目的與範圍

依 Lot 與 QC Item 查詢計量／計數 SPC 記錄，取每組 Lot／QC Item 最新記錄，供 Certificate of Analysis（COA）活頁簿樣板填值。此頁只讀取量測結果，並可建立 token 樣板或輸出 COA；DEV 不讀取 Excel bytes、不產生本機檔案，也不寫入 SPC 或 XLS 資料表。

## WinForms 查詢畫面與預設

| 欄位 | 預設／來源行為 |
| --- | --- |
| 日期 | Form Load 預填昨天 00:00 到 23:59，但兩個勾選預設關閉，不傳日期條件。起訖相等或跨日倒置會提示日期錯誤。 |
| MONo | 勾選後以逗號分隔值查詢；快搜清單由 `wsSPC.LoadVarMONoFromFactorLog` 載入。 |
| ProductNo | 勾選後以逗號分隔值查詢；快搜清單由 `wsSPC.LoadVarProductNoFromFactorLog` 載入。勾選時起訖日期都必須啟用。 |
| LotNo | 勾選後以逗號分隔值送入查詢；Lot 快搜資料來自 `wsSPC.LoadVarLotNoFromFactorLog`。 |
| OPNo | 可透過 `wsOP.LoadOPBasis` 查詢並送入 XML，但標準及 THEIL `wsSPC.LoadLotSPCMeasureData` 都未解析此參數，呼叫 Core 時也沒有 OPNo 參數；因此舊 COA 查詢實際不會依 OPNo 篩選。DEV 保留欄位並明示此差異。 |
| 計量 QC Item | `Query QCItem For Variables` 預設勾選；可多選 Variable QC Item，也可選 Group 並展開成多個計量項目。來源要求 `IssueState=defInteger`，即查詢選擇時不限制狀態。 |
| 計數 QC Item | `Query QCItem For Attributes` 預設勾選；可多選 Attribute QC Item，同樣不限制 IssueState。 |
| Factor | 量測資料載入後由 QC Item Factor metadata 補上 FactorNo／Name。Factor chooser 控制結果 Grid 顯示哪些 Factor 欄；Form 將 FactorValue 過濾程式留在註解中，這些選擇不是查詢篩選條件。 |

至少一種 QC Item 查詢類型需保持勾選。Form 宣告了 `ByLotNo` 結果頁，但 Load 時將該頁移除；目前可見結果是 `ByQCItemType` 內的 Variable 與 Attribute 兩個 Grid。查詢結果達 30,000 列時舊程式只提示使用者確認是否繼續，未強制限制筆數。

## Service／Core 查詢規則

Form 呼叫 `wsSPC.LoadLotSPCMeasureData` 並傳 `IsCOA=true`、可選 LotNo／日期、Variable QC Item 清單、Attribute QC Item 清單、LoadVarData／LoadAttData、MONo／ProductNo。標準 Service 呼叫 `kcSPC.LoadLotMeasureData`；THEIL Service 也以相同參數呼叫 `MEStc_THEIL.clsSPC.LoadLotMeasureData`。兩種呼叫都未傳 FactorValue 條件，也未將 OPNo 帶入 Core。

COA 模式在計量與計數查詢中都以 `QCItemNo + LotNo` 分組，連回各組最大 CreateDate 的資料。因此日期篩選套用在「最新記錄」上，不代表先在日期區間內挑最新一筆。重複 Lot／QC Item 的舊 SPCSerial 不會一併輸出。

| 資料類型 | 主欄位／附加結果 |
| --- | --- |
| Variable | `TBLSPCVARFACTORLOG`、QC Item 名稱、Factor 欄位、`TBLSPCVARSTATISTICLOG` 的 Max／Min／Mean／SD，以及 `TBLSPCVARLIMITCONTENT` 中 SPCID=0 的 limit 欄位；明細資料依 SPCSerial 帶入 SerialNo／TestValue／Memo。 |
| Attribute | `TBLSPCATTBASISLOG` 的 SampleQty／GoodQty／ScrapQty／DefectQty、Factor 欄位、RankDetail 與 ErrorDetail／ErrorItem／ErrorItemQty。Core 另載入 Error detail、component 與 tape 明細。 |
| Product 顯示欄 | ShowName 設定包含 `tblPRDProductBasis` 時，COA 分支取 ProductNo 最新且 IssueState=2 的版本資料。 |

變數 FactorNo 及 Attribute FactorNo 由 QC Item metadata 動態產生 SQL 欄位識別字；舊程式亦以字串組合 LotNo、QC Item、MO、Product 條件。正式實作需用 metadata allowlist 限制識別字，並將全部查詢值參數化。

## Excel 樣板與輸出

- `Export Template` 依目前結果產生 `VAR`／`ATT` 工作表及欄位 token，例：`[(VAR,QCItemNo_批號序號,欄位名稱,列序)]`、`[(ATT,QCItemNo_批號序號,欄位名稱,列序)]。此按鈕需先有查詢資料。
- `Export COA` 載入 `XLSType=3` 的 `TBLSPCXLSFILE` 樣板，使用 `GetXlsFile` 取得 bytes，在 Excel 工作表尋找 token 並以目前量測資料替換，再另存使用者指定路徑。
- 若 XLS 樣板清單為空，Form 會把本機 `COAExport_STD01.xls`／`COAExport_STD02.xls` 自動加入 `TBLSPCXLSFILE`，編號為 `COA1`／`COA2`。來源檔位於 MESWin Resources；不複製進 YMES repo。
- 舊 `AddXLSFile` 讀本機檔案時配置並讀取 `Length - 1` bytes，可能少最後一 byte。正式 Web 輸出需完整讀取與驗證檔案 bytes，不沿用此缺陷或以 Excel COM 操作使用者電腦。

## 資料庫與 DDL 狀態

| 用途 | 資料表 | 參考／缺項 |
| --- | --- | --- |
| Variable Factor／Statistic／Limit／Detail | `TBLSPCVARFACTORLOG`、`TBLSPCVARSTATISTICLOG`、`TBLSPCVARLIMITCONTENT`、`TBLSPCVARDETAILLOG` | 來源 DDL 可沿用 `database/reference/mestest_qc205_variable_dependencies_source_ddl.sql`、`database/reference/mestest_qc205_theil_custom_source_ddl.sql`；PostgreSQL CREATE-only 依既有 QC210 handoff 核對 live schema。 |
| Attribute Basis／Detail／Tape | `TBLSPCATTBASISLOG`、`TBLSPCATTDETAILLOG`、`TBLSPCATTDETAILLOG_TAPE` | Oracle DDL 與 CREATE-only 沿用 `database/reference/mestest_qc_item_attributes_source_ddl.sql`、`database/reference/mestest_qc_item_attributes_create.sql`。 |
| Attribute component detail | `TBLSPCATTDETAILLOGCOMPONENT` | Core 查詢使用；repo 找不到 Oracle DDL／metadata／PG CREATE-only。SC202 也已登記此缺項，家用端核 live schema 後再決定是否需要 DDL。 |
| COA binary templates | `TBLSPCXLSFILE` | Core／Service 明確使用，repo 找不到 Oracle DDL／metadata／PG CREATE-only；SC204 已登記相同缺項。公司桌機受保護 Oracle profile 不存在，本輪未查 Oracle，也未推測 schema。 |
| Product display | `TBLPRDPRODUCTBASIS` | 只在 ShowName 動態欄位要求 Product Property 時 join；家用端核實既有 YMES schema／lookup API。 |

本模組沒有可信來源建立新業務表的依據。Attribute component detail 與 XLS template 的缺項不得以 Core SELECT／INSERT 欄位推測 PostgreSQL schema。

## 家用端 API／schema handoff

- Pull 後核對上述 SPC log tables、`TBLSPCATTDETAILLOGCOMPONENT`、`TBLSPCXLSFILE` 與既有 migrations。沿用 SC204 的 XLSFile investigation；缺少可信 Oracle metadata 時不要猜建表。
- 建立登入與 SC213 Function ACL 保護的 QC Item／Group lookup、Lot／MO／Product lookup、OP lookup、Factor metadata lookup。決定 OPNo 在正式 API 實際套用篩選，或明確取消此無效舊欄位；不要把「畫面已送參數」誤當成舊服務真的有過濾。
- COA query 支援 Variable／Attribute QC Item 集合、可選日期、LotNo、MONo、ProductNo；日期先套用方式需維持或明確修正「先取跨全期最新 QCItemNo＋LotNo，再套日期」的舊 COA 語意。對日期跨度、QC Item／Lot 清單數、回傳列與 Attribute component detail 設硬上限和分頁。
- 所有 QC Item／Lot／MO／Product／日期條件參數化。Factor 欄位識別字只能來自已授權 QC Item 的 metadata allowlist；不要接受任意 FactorNo 作 SQL 欄名。畫面 Factor chooser 是欄位顯示設定，不是 FactorValue 查詢條件。
- COA response 回傳每筆 SPCSerial、Item／Lot、CreateDate、Result／ERF、Factor values、Variable statistic／limit／sample detail，或 Attribute quantities／rank／reason／component detail。對 Attribute error detail 限定查詢結果 SPCSerial，避免每筆逐次全表查詢。
- Template list／download／optional seed／export 使用受限檔案 API。`TBLSPCXLSFILE` 需 Function 權限、XlsType allowlist、檔案大小／格式／檔名驗證、完整 byte stream 與更新交易；Export 需限制產出列數與 bytes。正式生成不可依賴用戶端 Excel COM，也不要自動將固定模板 seed 寫入正式 DB，除非家用端確認此初始化契約。
