# SC209 不良率管制圖看板

## 功能範圍

- WinForms 功能：`PCHART SIGNBOARD`／FunctionKey SC209，主畫面 `frmQueryPChartSignBoard`，執行檔 `SC_QueryPChartSignBoard.dll`。
- Vue DEV 頁：`/YMES/SPC/PChartSignboard`，fallback menu function `PCHART SIGNBOARD`。
- 選一個計數型 Attribute QC Item，設定 Collect Factor 與刷新分鐘數，開啟不良率 P Chart 看板；依批次顯示 `ScrapQty / SampleQty`、限值、違規識別及點選批次的錯誤原因明細。

## WinForms、Service、Core 對照

- 主 Form 與 inline Designer：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_QueryPChartSignBoard\frmQueryPChartSignBoard.vb`。Get 呼叫 `wsQC.LoadQCItemForAttributes`，傳 `ChartControl=1`、`IssueState=defInteger`；選定 QC Item 後呼叫 `wsQC.LoadQCItemFactor` 載入 Factor metadata。ParameterType 0／1 透過 MES Parameter lookup，2 為自由輸入；多值以逗號分隔。查詢把 QC Item、Factor、`intFrequency` 傳給 `frmPChartSignBoard`。刷新預設 6 分鐘；WinForms scrollbar 最小值為 1，文字欄只檢查為數字且大於 0。
- 子 Form：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_QueryPChartSignBoard\frmPChartSignBoard.vb`。載入後呼叫 `funLoadQueryData`，使用 ChartS 顯示 Scrap ratio；ChartD、ChartR 與 ErrorType 1 的 Defect 顯示目前隱藏／未啟用。只取最近 `LimitLotNum` 筆，按 `SPCSerial` 排序後繪圖；`SampleQty <= 0` 不繪點。`Excluded=1` 以排除點樣式標示但仍保留在圖上；預設 `Excluded=defInteger` 不額外篩選，所以 Isolated 也會出現在資料中。
- 點選圖表資料點會顯示 LotNo、CreateDate、全部 Factor 值、SampleQty、ScrapQty、Scrap ratio、ErrorType 0 的 ErrorNo／ErrorName／ErrorQty 及 violation／rule 資訊。US、LS、UCL、CL、LCL 僅在來源值為有效正數時畫水平線。Timer 依分鐘重載；Save Graph 可存 JPG／BMP／GIF，畫面沒有 Export 按鈕。
- Customer Service 位於 `D:\iMES\CSiMES\Customer\Production\MESws_STD\wsSTD\wsSPC\wsSPC.cs`。主畫面由 `wsQC` 載入 Attribute QC Item／Factor；子畫面呼叫 `LoadSPCAttPChartLogRowData`（`ChartSignBoard=Y` 時另呼叫 `ShowSPCAttViolation`）、`LoadSPCAttPChartLogData` 與 `LoadSPCAttLimit`，並呼叫 `wsQC.ShowQCRule` 取得規則說明。
- 標準 Core：`D:\iMES\CSiMES\STD\MESkc\kcSPC\clsSPC.cs` 的 `LoadSPCAttPChartLogRowData`、`LoadSPCAttPChartLogData`、`ShowSPCAttLimit`、`ShowSPCAttViolation`。RowData 依 `SPCSerial DESC` 限制最近批次；子畫面再反向排序供圖表顯示。錯誤明細連結 `TBLSPCATTBASISLOG.SPCSERIAL = TBLSPCATTDETAILLOG.SPCSERIAL`，並以 `ErrorQty > 0`、`ErrorNo = TBLQCREASONBASIS.ReasonNo` 取得 ErrorName／ReasonType。Violation 由 `TBLSPCATTVIOLATIONCONTENT` 連到 BasisLog，Service 呼叫沒有傳 `LimitLotNum`，是正式 API 應限制範圍的查詢。
- Limit lookup 只對 `FactorOnline=Y` 的要因組條件。來源先查符合 Factor 值的列；沒有完全符合列時，以這些在線 Factor 的 `'*'` 值查通用限值，未處理多個 Factor 的所有排列組合。Legacy Core 將 FactorNo 當 SQL 欄位識別字串接、QC Item 與 FactorValue 也串入 SQL；正式 API 必須由核准 metadata allowlist 產生識別字，所有值使用 SQL parameters。

## Vue DEV 行為

- Attribute QC Item picker、Factor metadata、ParameterType 0／1 多選 lookup、2 逗號分隔輸入、刷新頻率（預設 6 分鐘）、Query 與 Close。
- 本機假資料模擬最近 `LimitLotNum` 批次、Scrap／Sample 比例折線、US／LS／UCL／CL／LCL 假限值、Excluded 標記、violation 點、批次 Factor 與 ErrorType 0 錯誤明細。點圖表點位會同步更新批次與明細；自動／手動 Refresh 只重算本機假資料。
- Save Graph 僅顯示提示，不產生檔案。正式環境顯示尚未開放。DEV 的 QC Item、Factor choices、值、限值、Log、Error、Violation、規則均為假資料；統計卡片、視覺樣式與 timer 是互動示意，不代表舊元件的像素或數值算法。

## 家用端 API／schema handoff

- Pull 後比對 Attribute basis/detail logs、`TBLSPCATTLIMIT`、`TBLQCREASONBASIS`、`TBLQCRULEBASIS` 與 `TBLSPCATTVIOLATIONCONTENT` 的 live schema／既有 migrations；沿用已存在物件，不重建。缺少 violation content DDL 前不建立新表或猜欄位。
- 提供登入與 SC209 Function 權限保護的 Attribute QC Item lookup、該 Item 的 Factor metadata／MES Parameter lookup，以及限量唯讀 P Chart query。回傳最近批次、ErrorType 0 detail、factor values、匹配的 limit、violations 與 rule descriptions；後端以 QC Item `LimitLotNum` 作上限並採穩定排序。Detail 與 Violation 只載入該批回傳的 SPCSerial 集合，避免目前 Legacy 無日期條件的全歷史明細／違規查詢。
- Query 可含多個 Factor 值；FactorNo 只允許來自該 QC Item 的 Factor metadata allowlist，Factor values 以 array parameters 傳入，禁止用使用者輸入拼 SQL 欄位或值。QC Item、Factor values、日期及任何識別值均參數化。限制單次點數、錯誤明細與 violation 數量；刷新應由 client 遵照頻率設定，並對同一使用者節流。
- 不新增 CREATE SQL、schema 或 migration，直到 `TBLSPCATTVIOLATIONCONTENT` 來源 metadata／live schema 已確認。公司端未實作或驗收正式 API/schema，也未連 PostgreSQL。
