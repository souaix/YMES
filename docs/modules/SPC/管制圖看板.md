# SC205 管制圖看板

## 範圍與來源

- Function：`CHART SIGNBOARD`，FunctionKey `SC205`，Form `frmQueryChartSignBoard`，ExecutionFile `SC_QueryChartSignBoard.dll`。
- 主 Form／inline Designer、圖表子窗 `frmVar_ChartSignBoard`：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_QueryChartSignBoard\`。
- 查詢 Service：Customer `wsQC.LoadQCItemForVariables`／`LoadQCItemFactor`、`wsSPC.LoadControlChartData`／`LoadVarQCItemChartData`。
- Core：`kcQC.clsQCBasis.LoadQCItemForVariables`／`LoadQCItemFactor`／`ShowQCChartBasis`／`ShowQCChartDetailLog`／`ShowQCRule`；`kcSPC.clsSPC.LoadControlChartData`／`ShowVarFactorOnLine`／`ShowVarDetailOnLine`／`ShowSPCVarViolation`。

## WinForms 主查詢與圖表互動

- QC Data Type 選單是空白、Particle、InLine、OffLine。Get 以 `ChartControl=1`、選取的 QCDataType（若有）及未限定 IssueState 載入 QC Item；快搜表只顯示 `IssueState=2` 或 `-1`。QC Item Factor 查詢後只將 `FactorOnLine='Y'` 的在線要因顯示在群組 Grid。
- 選 QC Item 後，`LoadControlChartData` 依 QCItemNo 讀 `TBLSPCQCCHARTBASIS`，帶出每個 FactorSerial 的 `TBLSPCVARFACTORLOG` 首批時間、末批時間與 Lot 數。Grid 另顯示在線 Factor 欄及 `KeyNode`；雙擊或選列後按 Query 開啟管制圖。
- 主 Form 預設 Frequency 為 6 分鐘，可設正整數；Show Trend Chart 控制是否顯示個別量測趨勢。開圖時傳 QC Item、Factor 資料與 FactorSerial。ChartType 0 為 X-R、1 為 X-S、2 為 X-Rm；X-Rm 強制 SampleSize=1。
- 圖表子窗啟動 `LoadVarQCItemChartData`，傳 `OnlyOnLine=Y`、`ChartSignBoard=Y` 和 FactorSerial；Service 組合 Chart Basis／Detail Log、在線 Factor／Detail、QC Rule 與 SPC Violation 資料。顯示 X-Bar、R／S／Rm 及條件式 Trend 圖、管制界線、違規點和最近量測資訊；圖表以 Frequency 分鐘自動重載。Save Graph 將影像傳到 Service `SaveImage`。
- Core 的 `LoadControlChartData` 對 Chart Basis 查詢沒有 IssueState 條件；IssueState 篩選發生於 QC Item 快搜。主 Form 對格線資料按 FactorSerial 選取，若 LotCount 小於等於 0 不開圖。
- Save Graph 將畫面截成 JPEG、暫存到程式目錄後呼叫 `wsSPC.SaveImage`；來源同樣以 `FileStream.Read(..., Length - 1)` 讀取，可能漏最後一個 byte。家用端若重做儲圖需用完整讀取迴圈／正確長度並清理暫存檔。

## 資料與既有 DDL 參照

- 主清單使用 `TBLSPCQCCHARTBASIS`、`TBLSPCVARFACTORLOG`。圖表子窗使用 `TBLSPCQCCHARTBASIS`、`TBLSPCQCCHARTDETAILLOG`、`TBLSPCVARFACTORONLINE`、`TBLSPCVARDETAILONLINE`、`TBLSPCVARVIOLATIONCONTENT`、`TBLQCRULEBASIS`，及透過 QC Item／Factor 查詢使用的 QC／SYS 基本表。
- Chart Basis／Detail／Rule Oracle source 與 PG CREATE-only 參照已在 `database/reference/mestest_qc302_spc_qc_chart_source_ddl.sql`、`mestest_qc302_spc_qc_chart_create.sql`；線上計量 Factor／Detail／Violation 參照沿用 `mestest_qc205_variable_dependencies_source_ddl.sql` 和 QC205／QC210 已有結構。SC205 沒有新增業務表或猜建 DDL；本次使用 repo 內已存在的 DDL，不連 Oracle。家用端仍須比對 live schema／migrations 與本機引用版次。
- Service／Core 查詢以字串組 SQL；正式 API 必須參數化。部分欄名來自 Factor metadata，服務端須由已核准的 QC Item Factor 清單映射，不得接受任意欄名。

## Vue DEV 頁

- 路由：`/YMES/SPC/ChartSignboard`，選單鍵 `function:SPC:CHART SIGNBOARD`。
- DEV fixtures 模擬 QC Data Type／QC Item 選取、FactorSerial 群組清單、在線 Factor、首末批／Lot 數、KeyNode、Frequency、Show Trend、雙擊開圖、X-R／X-S／X-Rm 假圖、能力指標、違規點選取明細、手動／計時刷新與 Save Graph 提示。所有內容在記憶體；沒有呼叫 Service、Oracle 或正式 API。
- DEV 圖形為固定假資料產生的簡化計算，Cp／Cpk、管制界線和違規標示僅供 UI 互動，不代表 MES 正式 SPC 算法／Rule 結果。自動刷新只更新本機狀態，不會向資料服務重載。Save Graph 不建立或傳送檔案。

## 家用端 API／schema handoff

- 先 pull 後比對 QC／SYS lookup、Chart Basis／Detail Log、Variable Factor／Detail Online／Violation 等既有 live schema 與 migrations；重用現有表，不因 SC205 新增重複 CREATE／migration。核對畫面來源使用的資料集合與 YMES schema 版次相符。
- 提供登入及 `SC205` Function 權限保護的 QC Item lookup、Factor lookup、FactorSerial summary 與 chart data 查詢；日期／QC Item／FactorSerial 參數化，限定 IssueState／ChartControl／DataType、筆數／圖表時間窗及線上 Factor 欄位白名單。查詢回傳要含 chart type、sample size、limit／rule／violation 和線上 detail，避免多次往返時讀到不一致資料。
- 若保留 Save Graph，需明確授權、限制影像 bytes／格式、正規化伺服端檔名、避免路徑輸入，並處理同 FactorSerial 覆寫及讀取權限；沒有需求可先不開放正式儲圖。
- 正式圖表算法需依實際版次重用／移植 Core 的 ChartType、計量統計、QCRule、SPEC limit 與 violation 規則；不得用 DEV 的簡化 Cp／Cpk 或假資料標記代替正式判定。公司桌機未連 PostgreSQL、未實作或驗收 API/schema。
