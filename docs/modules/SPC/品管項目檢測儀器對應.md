# SC501 品管項目檢測儀器對應

## 功能與來源

- MES 選單：品質管理 → SPC檢測設備 → 品管項目檢測儀器對應。FunctionNo=`INSP MACHINE PARAMETER SETUP`、FunctionKey=`SC501`、Form=`frmInspMachineParameterSetup`。
- 主 Form 與 inline Designer：`D:\iMES\CSiMES\STD\MESWin\SPC\SC_InspMachineParameterSetup\frmInspMachineParameterSetup.vb`；儀器測試子 Form：同目錄 `frmInspMachineParameterTest.vb`。
- 查詢 Service：`STD/MESws_STD/wsSTD/wsQC/wsQC.cs` 的 `LoadQCItemForVariables`、`LoadInspMachineParameter`、`LoadQCItemGroupDetail`。Core 為 `STD/MESkc/kcQC/clsQCBasis.cs` 與 `clsInspMachine.cs`。
- Web 路由：`/YMES/SPC/InspMachineParameterSetup`；正式與 DEV 共用 `web/src/components/SpcInspMachineParameterSetupPage.vue`，由 `SpcInspMachineParameterSetup.vue` 包裝。
- 這不是 QC502 檢測儀器主檔 CRUD。SC501 編輯操作站本機對應清單，沒有呼叫儀器參數的 Add/Edit/Delete Service。

## WinForms 畫面與流程

- Form Load 建立本機 `Setup` DataTable、COM1–COM20 與 Channel 1–6 候選、只加入 `0.RS232` 檢測類型，載入 `%LocalAppData%\iMESTech\InspMachineSetup.xml`；UserDefine 與 `LoadInspDriver` 啟動呼叫均被註解，InspType 控制項在 Designer 隱藏。
- Grid 依 COMPort、InspMachineNo、Channel 分組並展開。欄位為 COMPort、InspMachineNo、Channel、GroupNo、QCItemNo、QCItemName、InspType、COMSetup、EndCode、Format1、Format2、ChNo、Enable、UnitConversion。只有 Enable 與 UnitConversion 可在 Grid 直接編輯。
- Add／Copy 可透過 QC Item 多選或 Group Tree 多選加入一筆或多筆項目；儀器查詢帶入 InspType 與 RS232 設定。Edit 鎖住 QC Item 與儀器編號；Copy 依所選列預填，再新增一組對應。
- Complete 必填 QC Item、檢測儀器、InspType、COM Port；僅支援 RS232，且 Format1 拆出多組欄位時必填 Channel。Add／Copy 重複檢查鍵為 COMPort、QCItemNo、GroupNo、InspMachineNo、Channel；Edit 的舊檢查另將 Enable 納入條件。啟用一筆 QCItemNo／GroupNo 後，同組其他對應會停用；Grid 直接勾選 Enable 也套用相同規則。
- Delete 可刪多選列並要求確認。Load 重新載入本機 XML。Import 會清空目前清單後讀取 XML；Export 輸出含設定欄位的 XML。Confirm 覆寫本機 `InspMachineSetup.xml`、成功後關閉；已有檔案時先詢問是否取代。Dirty 時 Close 詢問是否放棄。
- Simulation 從所選對應開啟 `frmInspMachineParameterTest`，內容含 QC Item、儀器、COM Setup、COM Port、Channel、Format1/2、ChNo、接收資料及解析結果；原程式會進行 RS232 測試。Web DEV 僅產生示例接收值，不存取實體 COM Port 或儀器。

## Service／Core 查詢行為

- QC Item picker 呼叫 `LoadQCItemForVariables`，Form 傳 `CollectType=1`；Service 預設 `IssueState=2`。Core 讀 `tblQCItemForVariables`，依該條件回傳計量 QC Item。
- 儀器 picker 呼叫 `LoadInspMachineParameter` 且不帶條件；Service 預設 `IssueState=2`，Core 查 `tblQCInspMachineParameter` 中 `InspMachineNo IS NOT NULL` 的儀器主檔。
- Group picker 呼叫 `LoadQCItemGroupDetail` 且不傳 GroupNo。Core `ShowQCItemGroupDetail` 讀 `tblQCItemGroupDetail`，左聯 `tblQCItemForVariables` 取 QCItemName／CalType，依 ShowOrder 排序。
- `LoadInspDriver` Service／Core 存在，但 SC501 Form 啟動呼叫註解，且 UserDefine 類型選項不可見；不列為本頁可操作流程。

## 正式 Web/API 與設定保存

- 正式頁呼叫 `GET /api/spc/insp-machine-setup/lookups`，環境 API base URL 仍由正式入口設定在 `/YMES/API` 下。API 只提供 lookup，不新增設定 CRUD，也不寫入 QC502 儀器主檔。
- API 使用登入保護，並以唯讀 Repeatable Read 交易讀取 QC Item、群組明細與儀器選項；分別限量 5,000 筆，超限回應錯誤而不靜默截斷。QC Item 固定 `CollectType=1 AND IssueState=2`；儀器固定 `IssueState=2` 且有編號；群組明細依 `GroupNo, ShowOrder, QCItemNo` 排序。頁面只提供 RS232 (`InspType=0`) 儀器選項。
- Web DEV 使用隔離的假 lookup 資料；正式頁由 API 載入 YMES 資料，選項失敗會顯示錯誤並允許重試。
- 設定保存沿用舊功能的本機範圍概念，但瀏覽器使用各自瀏覽器的 localStorage：DEV 與正式環境分開，正式 key 為 `ymes.spc.insp-machine-setup.v1`。Load／Confirm／XML Import／Export 均只作用於目前瀏覽器設定，不會同步到伺服器或其他使用者。
- Confirm 只寫瀏覽器 localStorage；此頁沒有後端設定寫入。XML 匯入／匯出是使用者明確操作的檔案交換，不會直接寫入 `%LocalAppData%\iMESTech\InspMachineSetup.xml`。
- Web 測試按鈕只模擬接收資料；一般瀏覽器不直接存取真實 COM Port 或儀器。若日後要真實設備 I/O 或跨人員同步，需另行定義受控本機設備代理或伺服器設定範圍與版本，不能把 mapping 存入 QC502 儀器主檔。

- API endpoint 目前只有登入保護；依目前產品指示，角色／Function ACL 暫不實作，後續權限模組另行處理。DB 查詢使用參數化固定 SQL、唯讀交易及 5,000 筆上限。
- SC501 本身沒有 MES 資料庫寫入表、簽核或設定 CRUD；不把本機 XML 對應清單持久化到 `TBLQCINSPMACHINEPARAMETER`，該表是儀器主檔而非 mapping 表。
- 跨使用者同步本機設定不是舊 Form 行為；若產品日後要求共享，需先定義使用者／工作站範圍、版本及設備代理模式，再另提 server-side schema/API。
- 其餘來源可參考 `database/reference/mestest_qc501_inspection_machine_source_ddl.sql`、`database/reference/mestest_qc501_inspection_machine_create.sql` 與 `database/reference/mestest_mtl_qc_item_tables_create.sql`。
