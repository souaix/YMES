## 主 Form 條件與互動

- Form Load 預設報表類型為 MONTH；日期值從 Now 加一天再減兩個月的日期 00:00:00 起，到今天 23:59:59 止。兩個 DateTimePicker 的 Checked 預設都是 False。
- QC Item lookup 可多選，呼叫 `LoadQCItemForVariables` 時指定 `ChartControl=1`、`IssueState=2`，只載入 Issue 且允許管制圖的計量 Variable QC Item。選取後依每個 QC Item 載入 Factor 欄位和 `FactorOnline`、`FactorSpec`；MES Parameter 參照提供表格型 Factor 的候選值，其他型態由使用者輸入。
- Collect Factor 對每個已選 QC Item 列出 FactorNo、FactorName、FactorValue、FactorOnline、FactorSpec 等欄位。FactorValue 可逗號分隔多值；有設定值的 Factor 會送入查詢。`FactorOnline=Y` 的要因會顯示在報表，`N` 的要因仍可作查詢篩選。
- Lot Report State 預設 Normal／Excluded／Isolated 全選，Core 值分別是 0／1／2；Lot Result 預設 Pass／Fail 全選，值為 0／1。Capability Type 預設 CP、CPK、PP、PPK、CA、Mean、EstSd、Sd 全選。Calculate Principle 預設 `CalRule=0`（累計樣本數至少 25 才計算），另一選項 ALL 為 `CalRule=1`。
- Query 必須至少選一個 QC Item、一種 Lot State、一種 Lot Result、一項 Capability Type。起迄時間相同或 From 晚於 End 會拒絕。週／月／年模式在日期未勾選時會先詢問是否重新定義；若選擇繼續，仍將畫面日期值傳給報表。ALL 模式只傳已勾選的日期端點。
- Report Type 對應 Week=0、Month=1、Year=2；ALL 使用另一個 Service／Form 路徑。週／月／年會開啟 `SC_RPTChartYMWCapability` 報表物件，ALL 開啟 `frmRPTChartCapability`。報表列可選取後按 Chart，開啟 `frmOneChartYMWCapabilityALL` 顯示各期能力趨勢。

## Service／Core 資料行為

- ALL 詳細報表由 `LoadChartCapabilityData` 讀取 `TBLQCITEMFORVARIABLES`、`TBLSPCQCCHARTBASIS`、`TBLSPCQCCHARTDETAIL`、`TBLSPCVARFACTORLOG` 與 `TBLSPCVARDETAILLOG`。限制 `IssueState=2`、Chart Detail `SPCID=0`，並依 QC Item、時間、Factor、Lot State、Lot Result 建立每組 FactorSerial 的 LotCount 和原始量測統計。輸出包含 QCItemNo、US／LS、LotCount、Mean／EstSd／Sd、PP／PPK／CP／CPK／CA，以及按啟用指標顯示的 FactorOnline 欄。
- 週／月／年報表由 `LoadChartYMWCapabilityData` 讀取同一組 QC Item、Chart Basis／Detail 與計量 Factor／Detail log，按報表區間增加 `PP_n`、`CPK_n` 等週期欄位。主報表 Form 將 FactorOnline=Y 的 Factor 值合併成 Factor 欄，並補 QCItemName；列依 QCItemNo 排序。主 Form 使用週、月、年三種區間，Core 另有 ReportType=3 的 07:20 週界分支，主 Form 不會傳該值。
- 查詢兩條路徑都將 QC Item 清單、日期、FactorNo／FactorValue、LotState、LotResult 拼接進 SQL。FactorNo 是動態欄位識別字，值也以字串拼接，沒有分頁、區間數上限或結果列上限。Service 設定 6,000,000ms timeout。
- Core 原始量測值的 `RawData` 查詢固定 `Excluded=0`，後續又按使用者 LotState 選項追加條件；因此計數與能力指標可能和 Excluded／Isolated 選項不一致，或選擇非 Normal 時沒有統計值。ALL 與週／月／年兩條路徑都有此限制。家用端應以明確狀態語意統一分母、統計值與指標，並記錄與舊系統的行為差異。
- Core 依原始量測和 QC Item 規格計算能力指標；DEV 以固定指標樣本呈現互動，不重新實作 SPC 統計公式。月報日期會以日界 00:00:00 至 23:59:59 套用；週期以星期日到星期六切分。ALL 路徑傳入的日期保留時間值。

## Vue DEV 頁

- 路由：`/YMES/SPC/ChartAllCapability`；選單鍵：`function:SPC:CHART ALL CAPABILITY`。
- 完成多選 Issue Variable QC Item、Factor 值輸入／候選清單、Week／Month／Year／ALL、Lot State／Result、CalRule、能力指標、Query 驗證、動態欄位報表與列選取後 Chart 趨勢視窗。
- 預設 MONTH、表單兩個月日期值、所有 Lot State／Result／指標。DEV 假資料支援 Factor 值、日期、狀態／結果及 QC Item 篩選；LotCount 依假 Lot 分布切換，指標值是靜態樣本並依區間加權呈現，不代表 Core 公式重算，CalRule 也不會重算指標。DEV 在日期未勾選的週／月／年查詢會顯示原表單提示，並使用目前畫面的預設日期值；週期欄位最多顯示 36 期。
- 頁面不呼叫 Oracle、Service、正式 API 或 YMES PostgreSQL，不持久化修改，不執行匯出。

## DDL／metadata 與家用端 handoff

- SC301 不新增業務資料表。QC Item／Factor 參照 `database/reference/mestest_mtl_qc_item_tables_source_ddl.sql`、`database/reference/mestest_qc_item_attributes_source_ddl.sql` 及對應 PostgreSQL CREATE-only；Chart Basis／Detail 參照 `database/reference/mestest_qc302_spc_qc_chart_source_ddl.sql`、`database/reference/mestest_qc302_spc_qc_chart_create.sql`；Variable Factor／Detail log 參照 `database/reference/mestest_qc205_variable_dependencies_source_ddl.sql`、`database/reference/mestest_qc205_theil_custom_source_ddl.sql` 和 `database/reference/mestest_qc210_variable_measurement_log_delete_create.sql`。先比對 live schema／既有 migrations，不把 reference 當 production migration。
- 本桌機沒有可用的受保護 Oracle profile；本次只用 repo 既有 source DDL／CREATE-only 交叉比對，未連 Oracle 或 YMES PostgreSQL，未猜 DDL。
- 正式 API 需按登入者 FunctionNo `SC301` 授權；QC Item 數、日期跨度、週期欄數、Factor 數及輸出列數設上限；所有值參數化，FactorNo 只接受已核准 QC Item Factor metadata allowlist，不能把 client 傳入的 FactorNo 拼成 SQL 欄名。父資料、量測點及統計值應使用一致 snapshot。
- 統計查詢須核對 `TBLSPCVARFACTORLOG`／`TBLSPCVARDETAILLOG` live schema 與時間、LotState／LotResult 語意；修正 Core 固定 `Excluded=0` 的不一致時記錄行為差異。週報表界日、month/year 部分區間、CalRule=0 門檻與能力指標分母都要建立正式契約；移除 6,000,000ms 超長 timeout，採取消、資源上限及可觀測的查詢期限。
- 建議回傳以 QCItemNo＋FactorSerial（或穩定 factor-value key）識別的列，附 US／LS、LotCount、線上 Factor 值與每個日期區間的指標字典。Chart 使用已查詢的區間結果，不另以未授權的 Factor 欄位查詢。
