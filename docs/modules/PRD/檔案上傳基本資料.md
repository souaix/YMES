# PDB04 檔案上傳基本資料

- `PRD / B_UPLOAD FILE BASIS`，Web `/YMES/PRD/UploadFileTypes`。核對 `Industry_Base/MESWin_Industry_Base/PRD/PD_B_UploadFileBasis/frmUploadFileBasis.vb`、`frmUploadFileBasisDef.vb` 與內嵌 Designer。依檔案類型維護 FTP 主機、帳號、密碼、埠、路徑樣式與說明；新增／修改前由桌面程式檢查 FTP 連線。
- DEV 支援查詢、檢視、新增、修改、複製、核准與刪除。FTP 欄位使用保留的 `.invalid` 假主機與 DEV 帳號，提供欄位檢查。DEV 儲存資料只含展示欄位，正式憑證不進入瀏覽器儲存與 DEV 介面。50／51 提供 PDB05 使用，90001 用於演練新增。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBL_BPRDMESFILETYPE` 14 欄，PK FILETYPE。只讀資料字典，沒有查詢上傳設定資料。參考 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_upload_file_type_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_upload_file_type_create.sql)。
- `Industry_Base/MESws_Industry_Base/wsPRD/wsPRD.cs` 的 Load／Add／Edit／Approve／DelUploadFileBasis 呼叫 `MEStc_Industry_Base/tcPRD/clsPRD_Industry_Base.cs`。原系統以 ValueList 提供檔案類別，`FILESERVICETYPE=1` 表示 FTP。舊資料表有 `FILESERVICEPASSWORD`，桌面程式傳送 Base64 格式，遷移時需核對獨立伺服器端憑證管理方式。
- 建議 `/api/prd/upload-file-types` 提供查詢和 DataStamp 資料異動，讀取回傳設定狀態與授權範圍。連線驗證由正式服務端處理，限制實際可用服務位置，使用受保護憑證。核准的檔案類型供 PDB05 查詢與上傳。
