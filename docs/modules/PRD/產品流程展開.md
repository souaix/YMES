# 產品流程展開（PD102 Expand All）

## WinForms、Service 與 Core

- PD102 流程分頁的 `Expand All` 以選定的產品版本、流程版次、`MOTypeNo` 和區段 `PSNo` 開 `PD_ExpandProcess`。父頁先透過 `wsPRS.LoadProductionSegment` 取得區段 `IsNetFlow`。
- `STD/MESWin/PRD/PD_ExpandProcess/frmExpandProcess.vb` 含 Form 和 Designer。產品模式顯示產品、主流程、ItemNo、製程模組、子流程、作業站、短名稱、說明與製造層別，依 `ItemNo`、`OPOrder` 排序。此畫面唯讀。
- 一般流程呼叫 `wsPRD.LoadExpandProcess` → `STD/MESkc/kcPRD/clsProduct.cs` 的同名方法，以 `tblPRDProductProcess` 選版本及工單類型，必要時將 `*` 解析為目前版，再以 `tblPRSNodeBasis`、`tblPRSNodeRelation` 走訪 PASS 和其他連線並展開子流程及模組。
- 網狀流程呼叫 `wsWIP_NetFlow.LoadExpandProcess` → `STD/MESkc/kcWIP/clsNetFlow.cs`。Core 依 `PSOrder` 取產品流程，解析 `*` 後查 `tblPRSNodeBasis` 與 `tblOPBasis`。這個入口的模組與製造層別欄回 `N/A`。
- `dtExpandOP` 背景模式供用料表與配件取展開後的作業；按多段流程累積並以 `OPNo` 去重。畫面的 `Expand All` 使用目前選定流程。

## 公司端 DEV

- 從現有選取流程開啟唯讀表格，示範一般、網狀、`*` 目前版、模組、層別、排序與無資料狀態。資料按 DEV 流程及固定版本準備，區段類型配合假資料。
- 正式節點走訪、版本與工單類型解析、背景作業清單待 API 接入。

## Oracle 字典與家用端 API/schema

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDPRODUCTPROCESS`（16 欄）、`TBLPRSPRODUCTIONSEGMENT`（16 欄）、`TBLOPBASIS`（26 欄），並沿用已核對的流程主檔、節點與連線表。既有 CREATE-only 包含 [產品主檔](../../../database/reference/mestest_prd_product_basis_create.sql)、[生產區段](../../../database/reference/mestest_prs101_production_segment_create.sql)、[流程與節點](../../../database/reference/mestest_prs104_process_basis_create.sql)、[作業主檔](../../../database/reference/mestest_operation_and_system_create.sql)。
- 建議 `GET /api/prd/products/{productNo}/versions/{productVersion}/process-expansion` 以 `psNo`、`moTypeNo`、`processNo`、`processVersion` 固定這次查詢的流程，伺服器回傳已解析版本、`isNetFlow` 和排序結果。伺服器驗證產品流程指派及區段權限，依區段類型選擇展開分支，依舊系統規則處理缺資料、迴圈及多工單類型。
