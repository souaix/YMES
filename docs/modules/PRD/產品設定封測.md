# PDB02 產品設定_封測

- `PRD / B_PRD BASIS_IC`，Web `/YMES/PRD/PackagingProducts`。入口為 `Industry_Base/MESWin_Industry_Base/PRD/PD_B_ProductBasis_IC_PKG/frmProductBasis.vb` 的 `frmProductBasisPKG`。核對主 Form、Def、ECNBasic／ECNProcess／ECNOP、SENQuery、清線呼叫及其 Designer 定義。
- DEV 封測入口共用 PD102 產品主檔、版次及基本子功能的假資料。產品編輯省略 THEIL SAP 專用欄位，封測新增／修改設定 `ECNControl=Y`。正式入口需要獨立核對封測 BOM、EquipmentRelease、工單流程及 Industry_Base 產品服務。
- 工程變更視窗依產品／版次區分基本設定、流程、站點參數。DEV 可新增、修改、複製、核准與作廢 ECN／TECN／SEN，TECN 有時間範圍，SEN 有限定批號，清線顯示本機狀態。這些操作存於獨立 DEV 快照。DEV 的變更內容簡化為目標和值，正式 ECN 明細影響、SEN 批號增刪權限、清線步驟、表單欄位與簽核待接續。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDECNBASIC`、`TBLPRDECNBASICDETAIL`、`TBLPRDECNPROCESS`、`TBLPRDECNOP`、`TBLPRDMOPROCESS`、`TBLPRDSENLOTDETAIL`，欄數依序為 16／9／15／16／8／5。參考 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_packaging_product_ecn_source_ddl.sql)、[CREATE-only](../../../database/reference/mestest_prd_packaging_product_ecn_create.sql) 與 [PD102 產品表](../../../database/reference/mestest_prd_product_basis_create.sql)。
- `Industry_Base/MESws_Industry_Base/wsPRD/wsPRD.cs` 的 Load／Approve／AbortECNBasic、ECNProcess、ECNOP 分別到 `MEStc_Industry_Base/tcPRD/clsPRD_Industry_Base.cs`。明細包含基礎元素、工單類型與流程版次、站點參數、SEN 批號。清線入口依類別呼叫 `WP_CleanLine_Basic`、`WP_CleanLine_PRS`、`WP_CleanLine_OP`。
- 建議復用產品主檔 API 並提供 `/api/prd/packaging-products/{productNo}/versions/{version}/changes`。核准／作廢前驗證範圍、正式狀態、必填元素、流程區段唯一性及預期 DataStamp。正式變更及清線按 WIP、SEN 資料與權限協調，歷史狀態和清線結果應可追溯。
