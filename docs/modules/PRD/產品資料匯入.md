# 產品資料匯入（PD102 Import）

## WinForms、Service 與 Core

- PD102 `btnDataImport_Click` 以 ObjectFileHandler 開 `PD_ProductDataImport_PRS`，收到 `success` 後重載產品主檔。原始 Form 與 Designer 位於 `STD/MESWin/PRD/PD_ProductDataImport_PRS/frmProductDataImportPRS.vb`、`frmProductDataImportPRS.Designer.vb`。
- WinForms 接收單一 `.xls`／`.xlsx`，依位置讀五張工作表（Process、PRD Data、PRD OP Data、OP Parameter、QC Item）。PRD Data 的必備標記依序是 `[PRD Basis]`、`[PRD Process]`、`[PRD Property]`、`[Recipe Group]`、`[EQP Constraint]`、`[Accessory]`、`[Packing Set]`、`[EQP Capitem]`。PRD OP Data 使用 `[OP Description]`、`[Sub OP]`、`[Run Time]`，OP Parameter 使用 `[Attrib]`、`[EQP Recipe]`。
- 預覽依流程／版本和產品／版本去重。匯入先對每組流程呼叫 `DataImporter.DataImport.ProcessDataChecker`，再對每組產品呼叫 `DataImporter.ProductDataImport_PRS.ProductDataChecker_PRS`，分別回報進度與結果。支援下載與更新範本，以及取消待執行項目。
- `STD/MEStc/DataImporter/ProductDataChecker_PRS.cs` 檢查產品版次是否重複及產品類別是否已核准，再匯入主檔與該產品的流程指派和子設定。源碼接受 `ERPUnitNo` 欄，這條 `AddProduct` 呼叫未帶入該欄。

## 公司端 DEV

- 讀測試 `.xlsx` 的前五張工作表，檢查三張工作表的區段順序，列出流程版次及 `[PRD Basis]` 產品。產品編號／版本和類別正規化為大寫。確認時只新增 DEV 產品主檔並逐列回報結果；檢查主檔必填、重複版次及 DEV 產品類別。
- DEV 支援 XLSX 內既有的儲存格值。舊式 `.xls`、重算公式、流程與子資料匯入、範本更新／下載和執行中取消待正式接入。

## Oracle 字典與家用端 API/schema

- 以 PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDPRODUCTBASIS`（84 欄）、`TBLPRDTYPE`（11 欄）、`TBLPRSPROCESSBASIS`（16 欄）、`TBLPRSNODEBASIS`（17 欄）、`TBLPRSNODERELATION`（7 欄）。類別主鍵是 `PRODUCTTYPE`；其 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_product_type_source_ddl.sql) 與 [CREATE-only 參考](../../../database/reference/mestest_prd_product_type_create.sql) 已附。產品和流程沿用 [產品主檔](../../../database/reference/mestest_prd_product_basis_create.sql) 和 [PS104 流程](../../../database/reference/mestest_prs104_process_basis_create.sql) 參考，子表沿用對應規格。
- 建議上傳後先回傳可匯入的流程／產品群組及逐列錯誤，由伺服器再次核對權限、群組相依、範本、流程合法性、類別狀態與重複鍵。依流程先行、產品後續的關係處理交易，回報各群組成功、失敗或尚未執行。使用可安全重試的匯入識別，取消只阻止未開始的群組。
- 範本由既有 SYS 範本服務核對功能與權限後提供，沿用原始位元組及副檔名。產品頁在收到成功提交結果後重新載入。
