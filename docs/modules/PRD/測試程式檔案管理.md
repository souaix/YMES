# PDB05 測試程式檔案管理

- `PRD / B_TEST PROGRAM FILE MANAGEMENT`，Web `/YMES/PRD/TestProgramFiles`。核對 `Industry_Base/MESWin_Industry_Base/PRD/PD_B_TestProgramFileManagement` 的 `frmTestProgramFileManagement`、`frmProgramUpload` 與內嵌 Designer。
- 依檔案類型 50／51 查詢 CP／FT 程式，可篩程式編號、類別、版次、目前版及檔案更新歷程。明細依所選程式版本與歷程顯示。原管理入口允許各簽核狀態上傳，與程式定義內的上傳入口不同。
- DEV 共用 PD202／PDP02 程式及 PDB04 核准類型，提供設定預檢、選檔、多檔登錄、更新歷程與下載。每批存檔名、路徑、操作者與時間，選取的檔案內容保留於本頁記憶體。重新開頁仍可查歷程與檔名。正式傳輸、批次打包、路徑規則及檔案內容持久化待接續。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBL_BPRDMESFILEMANAGEMENT` 與 `TBL_BPRDMESFILEMGT_LOG` 各 10 欄，主表 PK `(FILETYPE,FILENO,FILENOVERSION)`，歷史表再加 CREATEDATE。FILENAME 為 CLOB。參考 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_program_file_source_ddl.sql)、[CREATE-only](../../../database/reference/mestest_prd_program_file_create.sql)、[PDB04 設定交接](檔案上傳基本資料.md)。
- `Industry_Base/wsPRD.LoadProgram` 查程式及歷程，`LoadUploadFileBasis` 取得檔案類型，`LoadFile` 查檔案，`UpdFileManagement` 記錄批次與程式 FolderNo。由 `Industry_Base/MEStc_Industry_Base/tcPRD/clsPRD_Industry_Base.cs` 處理資料。
- 建議 `/api/prd/test-program-files` 提供程式、檔案與歷程查詢，另提供有授權的一批登錄及下載。正式服務需關聯核准類型與程式版本，核對底層檔案與資料庫交易的失敗重試，處理同程式版本的併發上傳與歷程時間鍵。檔案與憑證採伺服器端管理。
