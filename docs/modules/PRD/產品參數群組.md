# PD105 產品參數群組

- `PRD / PRD RECIPE BASIS`，Web `/YMES/PRD/RecipeGroups`。WinForms 和內嵌 Designer 在 `STD/MESWin/PRD/PD_Recipe/frmPRDRecipe.vb`、`frmPRDRecipeDef.vb`、`frmPRDRecipeDetailDef.vb`。
- 主檔按 `RecipeGroup/RecipeVersion` 識別。ADD 與 Copy 的版次為 `1`，Edit 鎖定鍵。核准且為目前版才可 Version，原 Form 以選取版加一。`wsPRD.CopyPRDRecipe` 複製來源明細。刪除 `0/-1` 走實體刪除，`2` 轉 `-1`，`1` 禁止。
- `wsPRD.ApprovePRDRecipeBasis` 依簽核設定直接核准或進入簽核；核准成功的新版本成為目前版。DEV 模擬直接核准，批次遇到同群組多版時要求逐版核准。
- 明細以 `RecipeGroup/RecipeVersion/OPNo/RecipeNo` 識別，只有未核准群組可新增、修改、刪除。OP 從 `LoadOPBasis` 查，RecipeNo 從 `wsSYS.LoadElement` 的 `ElementType=6` 查；RecipeValue 必填，Sequence `0–99`。DEV 使用固定查找和逐筆刪除；核准、版本與明細按同一筆本機資料保存。
- PD102 與 PD103 的 Recipe Group 指派共用 PD105 DEV 清單，只接受 `IssueState=2` 且 `CurVersion=1` 的群組。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDRECIPEBASIS` 10 欄、`TBLPRDRECIPEDETAIL` 12 欄及其主鍵。主檔沿用 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_recipe_group_source_ddl.sql) 和 [CREATE-only](../../../database/reference/mestest_prd_recipe_group_create.sql)。明細補 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_recipe_detail_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_recipe_detail_create.sql)；舊 first-phase 也有一份共用定義。
- 建議 `GET/POST /api/prd/recipe-groups` 和群組版本子路徑，提供 `approve`、`copy`、`version` 和 `details`。伺服器驗證狀態、資料戳、元素與作業權限，並以交易處理完整副本、目前版切換及實體刪除。刪除前核對產品的群組指派。正式簽核與權限待接續。
