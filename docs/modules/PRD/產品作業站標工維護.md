# PD901 產品作業站標工維護

- `PRD / PRD WORKTIME`，Web `/YMES/PRD/WorkTime`。核對 `Customer/Production/MESWin/PRD/PD_RunTimeSetup_THEIL_BU1/frmRunTimeSetup_THEIL_BU1.vb`（含內嵌 Designer）。此畫面維護客製標工，以及由 SAP 工序與產品料號識別的批次資料。PD102 RunTime 另使用 `TBLPRDRUNTIMESETUP`。
- 查詢時科技類別必選；可篩 TH 料號、GBOM、站點、產品類別、未設定工時、最新版次與建立／下線時間。最新版次需料號或 GBOM；時間區間上限 30 天。DEV 使用三筆產品／SAP 版次組合模擬查詢。
- 匯入第一張工作表，依 A–N 位置讀取，C／D／E／F／I 為必填（料號、SAP_KTEXT、工序順序、站點、標準工時）。DEV 提供 XLSX 預覽、逐列錯誤、同鍵替換和原列歷史。匯入日期保留工作簿的原始字串，XLS、公式重算、日期型別轉換、正式 SAP 與工時公式由 API 承接。轉 SAP 的 DEV 操作僅預覽查詢結果去重後的料號／SAP_KTEXT。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `XX_TBLPRDRUNTIME_THEIL_BU1` 與 `XX_TBLPRDRUNTIME_LOG_THEIL_BU1` 各 13 欄。主表 PK `(PRODUCTNO, PRODUCTVERSION, OPNO, SEQUENCE)`，歷史表字典未回報 PK。主表工時三位小數、歷史表兩位小數。參考 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd901_work_time_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd901_work_time_create.sql)。
- `VIEWSAP_TECH` 字典可見 6 欄，查詢用 TE_NO、TE_DESC。完整 view 定義與上游 SAP 資源待核對。客製 `wsTHEIL/wsPRD/wsPRD.cs` 的 `LoadViewSAP_Tech`、`LoadRunTime`、`exeRunTimeImport` 與 `exeTurnSAP` 提供四種操作。Core `MEStc_THEIL/tcPRD/clsProduct.cs` 依產品、物料、Lot、預設流程、節點與作業站屬性解析查詢與匯入。匯入需確認 SAP_KTEXT 與內部版次、預設流程、SAP_STEUS 及人機比。
- 建議 `/api/prd/work-times` 提供查詢、逐列預檢與批次確認。替換前保存原列至歷史，並核對歷史精度是否需調整。轉 SAP 使用獨立動作與權限，回報每組料號／版次狀態。正式時間篩選採實際 Lot 的下線／建立時間。
