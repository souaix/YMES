# PD102 產品主檔查找選項

正式頁與 DEV 選項完全分開。正式選項不讀取 localStorage，不補入 DEV 編號，也不把缺少目錄當成預設選項。

| 欄位 | 正式來源／契約 |
| --- | --- |
| ProductType | `GET /api/products/options/product-types`，讀 PD101 owner 的 `tblprdtype`，僅 IssueState=2。 |
| UnitType、UnitNo | `GET /api/products/options/units`，讀既有 `tblsysunitbasis`，僅 IssueState=2；UnitType 取真實單位目錄 distinct，UnitNo 限選定 UnitType。這是明確的 YMES 查找契約，未聲稱已取得舊 SYS ValueList provider。 |
| SerialTypeNo_Lot | 重用 PS101/SYS `GET /api/system/serial-rule-basis?serialType=LOTNO`，不新增同義表或 provider；沿用包含 Enable=0/1 的來源查找契約。 |
| SerialTypeNo_Comp | 舊來源 SerialType 篩選尚未核實，正式選擇器明確不可用，保留既有欄值，不猜測分類或填 DEV 值。 |

- 所有端點須登入。資料庫／權限失敗回簡潔503，真實空目錄回空清單；不因應用程式未獲權限而略過檢查。
- 選項載入中不允許選取；關閉或切換選擇器後，舊請求不得填入新視窗。變更 UnitType 時清除原 UnitNo，避免殘留另一類別的單位。
