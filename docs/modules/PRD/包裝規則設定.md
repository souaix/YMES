# PD112 包裝規則設定

- `PRD / PRD PACKING RULE BASIS`，Web `/YMES/PRD/PackingRules`。舊 Form 在 `STD/MESWin/PRD/PD_ProductPackingRuleBasis`，主頁 `frmProductPackingRuleBasis.vb`、定義 `frmProductPackingRuleBasisDef.vb`、明細 `frmProductPackingRuleSetting.vb`，序號、標籤、多段和配件有各自 Form／Designer。
- `wsPRD.Load/Add/Edit/Del/ApprovePRDPackingRuleBasis` 以 `PackingRuleNo + PackingRuleVersion` 操作主檔。定義包含 InlinePackingFlag、LevelMax 及連續 1–6 層的名稱、箱數或數量、單位、SOPPath。名稱不可重複；DEV 依欄位數字限制驗證第一層數量、上層整數及箱數。
- 只允許未核准資料修改，核准後切換目前版；已核准目前版可開換版。未核准或停用版本可實刪，核准版本轉停用。Copy／Version 帶入序號、標籤、多段及配件明細。正式 mapped/in-use 規則與箱數／數量的站點差異需接入。
- Detail 依層級產生序號 `11–16` 與標籤 `L1_T1/L1_T2` 至 `L6_T1/L6_T2`，DEV 重用 PD102 序號、標籤及文字預覽編輯器，並提供配件維護。產品版次與規則版次各自儲存。PD102 的 DEV 包裝規則候選讀取 PD112 已核准版本。正式站點專屬標籤來源、格式檔、列印、用量及權限待接入。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 7 張表，含 `TBLPRDPACKINGRULEBASIS`、`TBLPRDPACKINGRULEACCESSORY`、序號主／明細、標籤主／明細／多段。附 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_packing_rule_basis_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_packing_rule_basis_create.sql)。規則版次表的 `TBLPRDPACKING*` 和 PD102 產品版次的 `TBLPRDPRODUCT*` 各有不同主鍵。
- 建議 `GET/POST /api/prd/packing-rules`，依版本提供更新、拷貝、換版、核准、刪除及子資源。伺服器核對產品對應使用情況、版本狀態、DataStamp、包裝層級及站點參數。以交易保存主檔、完整複製及刪除明細，正式預覽交由標籤引擎。
