# PD111 產品作業站批次複製

- `PRD / PRODUCT OP COPY`，Web `/YMES/PRD/OperationCopy`。主 Form 與內嵌 Designer 在 `STD/MESWin/PRD/PD_ProductOPCopy/frmProductOPCopy.vb`。
- `wsPRD.LoadProduct` 取得已核准來源版次和未核准目標版次。目標依產品編號前綴查詢。舊系統在 ECN 功能啟用時排除 ECN 控制的來源／目標，DEV 以 `ECNControl` 空白或 `N` 判斷。
- `wsPRD.UpdPRDOP_BatchCopy` → `STD/MESkc/kcPRD/clsProduct.cs`。旗標為 Product Process、Parameter、Description、QC Item、Business Rule、OP Resource、SubOP、APS。Core 依群組取代目標內容，Parameter 為目標生成新 SerialNo，並以該鍵複製明細。舊窗逐版處理，程式註記已因資料庫 deadlock 停用平行複製。
- DEV 重用批次工作頁與 PD102 本機產品資料，支援來源選取、目標全選、六組作業內容與 Product Process、覆寫前確認、按版次結果及取消未開始項目。使用目標自己的 SerialNo；選取項目隨來源內容取代，來源若該項無資料，目標該項會清空。APS 與正式權限依舊系統功能開關接入。
- 與 PD109／PD110 共用 [產品作業站表參考](../../../database/reference/mestest_prd_parameter_setup_create.sql) 及產品流程、QC、SubOP、APS 參考。已沿用本機對 Oracle MESTEST 的唯讀校驗。家用端依每版交易處理來源／目標權限、狀態及 ECN，重設參數序號與關聯，再回傳成功／失敗及取消進度。
