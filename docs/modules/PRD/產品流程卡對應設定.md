# PD115 產品流程卡對應設定

- `PRD / PRODUCT RUN CARD MAP BASIS`，Web `/YMES/PRD/ProductRunCardMap`。WinForms 來源為 `STD/MESWin/PRD/PD_ProductRunCardBasis/frmProductRunCardBasis.vb`、`frmProductRunCardBasisDef.vb`，兩者皆含內嵌 Designer。
- 維護每產品編號一筆對應，可查詢、新增、修改、複製與刪除。複製帶入流程卡並另選產品；修改時產品編號唯讀。產品候選限定 `IssueState=2`，另有 `*` 選項；流程卡候選限定 `MainRunCard=1`。原清單用產品編號連目前版取得產品名稱，挑選器無目前版時取第一筆核准資料顯示。
- Vue DEV 共用 PD102 產品與 PD114 流程卡假資料。對應用獨立 localStorage；DEV 中仍被對應使用的卡禁止刪除或取消主流程卡。正式 `*` 的套用優先順序由實際列印／WIP 呼叫端核對。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDRUNCARDMAP` 共 7 欄，主鍵 `PRODUCTNO`，`RUNCARDNO` 必填。見 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_run_card_map_source_ddl.sql)、[CREATE-only](../../../database/reference/mestest_prd_run_card_map_create.sql) 和 [PD114 自定義流程卡](自定義流程卡.md)。
- 來源 `wsPRD.cs` 的 `LoadRunCardMap`、`AddRunCardMap`、`EditRunCardMap`、`DelRunCardMap` 轉交 `kcPRD/clsProduct.cs`。原新增比對大寫產品號防重複；編輯表單送出 DataStamp。建議 `/api/prd/product-run-card-maps` 提供列表、候選與 CRUD。新增、修改及刪除須驗證權限，修改以預期 DataStamp 防止覆寫，寫入時驗證主流程卡與產品候選，並核對現有資料中的 `*` 與孤立參照再決定額外約束。
