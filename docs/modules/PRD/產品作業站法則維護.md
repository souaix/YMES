# PRD OP RULE 產品作業站法則維護

- `PRD / PRD OP RULE`，Web `/YMES/PRD/StationRules`。核對 `Customer/Production/MESWin/PRD/PD_PRDOPRule_THEIL_BU1` 的 `frmPRDOPRule_THEIL_BU1`、`frmPRDOPRuleDef_THEIL_BU1`、`frmPRDOPRuleEdit` 及 Designer。匯入來源是 `PD_PRDOPRuleDataImport_THEIL_BU1` 的 Form 和 Designer。
- 依產品、作業站與法則篩選。新增選產品版次、站點、法則、階段與 Lot／Component。可全選、批量刪除，或對相同一般法則批量更換法則號與腳本文字；每筆仍沿用原產品版次、站點與階段。
- DEV 共用 PD102 作業站及 SerialNo 假資料。一般、CP、FT 類別使用共用欄位，CP／FT 專屬條件、目錄、輸入格式、Script Builder 和正式腳本執行由服務端接續。XLSX 第一頁 A–H 為產品號、版次、站點、站名、法則號、法則觸發階段、參數與參數觸發階段。DEV 以假階段、假法則做一般法則預檢，參數欄顯示在預覽；正式參數轉換、舊版 XLS 和伺服器範本維護待接入。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀確認 `TBLPRDOPRULE` 9 欄，PK `(SERIALNO,RULENO)`；`XX_TBLPRDOPRULELOG_THEIL` 11 欄，未查得 PK，舊法則號欄位長度 20，小於主法則號長度 55。參考 [既有作業站 Oracle DDL](../../../database/reference/mestest_prd_parameter_setup_source_ddl.sql)、[既有作業站 CREATE](../../../database/reference/mestest_prd_parameter_setup_create.sql)、[Oracle 歷史 DDL](../../../database/reference/mestest_prd_op_rule_history_source_ddl.sql) 與 [歷史 CREATE-only](../../../database/reference/mestest_prd_op_rule_history_create.sql)。
- 客製 `THEIL.wsPRD.LoadPRDOPRule` 透過 SerialNo 關聯產品站點及 `TBLOPCONTROLRULE`；`AddPRDOPRule`、`EditPRDOPRule`、`DelPRDOPRule` 轉交 `MEStc_THEIL/tcPRD/clsProduct.cs` 並保存歷史。CP／FT 有各自的 Add／Edit／Del 入口與條件表。正式匯入檢查由 `DataImporter_THEIL_BU1/PRDOpRuleDataImport_THEIL_BU1.cs` 的 `PRDOPRuleChecker` 處理。
- 建議 `/api/prd/station-rules` 提供查詢、候選、單筆新增、批次替換／刪除與匯入預檢。核對來源 serial、法則組合鍵、替換衝突及異動記錄，再提交整批交易。CP／FT 專屬條件使用實際部署對應的 API 與表。
