# PD113 產品包裝規則對應設定

- `PRD / PRD PACKINGRULE MAP`，Web `/YMES/PRD/PackingRuleMap`。源碼在 `STD/MESWin/PRD/PD_ProductPackingRuleMap/frmProductPackingRuleMap.vb` 與 `frmProductPackingRuleMapDef.vb`，含 Form、Designer。
- `wsPRD.LoadPRDPackingRuleMap` 經 `clsProduct` 取得產品對應。`AddPRDPackingRuleMap` 用於新增與複製，`EditPRDPackingRuleMap` 使用 DataStamp，`DelPRDPackingRuleMap` 刪除對應。每產品版次一組規則；Current 儲存 `*`，Specified 儲存明確規則版次。
- 儲存和刪除前維持使用中卡控。WinForms 以產品號／版次呼叫 `wsWIP.LoadLotBasisJoinState`，限制 `A.LotNo` 出現在 `TBLINVPACKSTATE`。查到包裝中的批號即阻止更改。DEV 使用固定的使用中產品假資料，並重用 PD102 的對應操作及 PD112 核准目錄。
- DEV 有獨立路徑與產品號篩選，支援新增、修改、複製、刪除及兩種規則版次模式。修改保存到 PD102 共用關聯假資料；從任一頁重開即可讀回對應。正式 WIP／庫存卡控及資料權限待接入。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDPACKINGRULEMAP` 9 欄、主鍵 `(PRODUCTNO,PRODUCTVERSION)`，另核對規則主表、`TBLWIPLOTBASIS`、`TBLWIPLOTSTATE` 和 `TBLINVPACKSTATE`（37 欄，主鍵 `LOTNO`）。沿用 [PD102 包裝來源 DDL](../../../database/reference/mestest_prd_packing_set_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_packing_set_create.sql)、[PD112 包裝規則](包裝規則設定.md)。WIP／庫存查詢為共用依賴，PD113 無新增這些表的 migration。
- 建議共用 PD102 的產品版次對應 API，另提供管理頁查詢與候選。目標每版唯一，核對 `*` 當前版及指定核准版，在異動交易內驗證 DataStamp 和使用中狀態。
