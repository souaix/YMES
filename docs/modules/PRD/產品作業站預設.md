# PD109 產品作業站預設

- `PRD / PRODUCT OP DEFAULT`，Web `/YMES/PRD/OperationDefaults`。Form 與內嵌 Designer 在 `STD/MESWin/PRD/PD_ProductOPDeafult/frmProductOPDeafult.vb`。
- `wsPRD.LoadProductByProcessOP` / `clsProduct.LoadProductByProcessOP` 以產品、流程、作業站編號起始值查詢 `IssueState=0` 的所有版次。流程與作業關聯使用產品編號／版次。選取作業站用於這次批次 scope；與查詢條件分開。
- Default 需確認，呼叫 `UpdPRDOP_BatchDefault` 並傳 `DefaultOP=2` 產品流程作業或 `1` 全區段與選取站清單。Amend 呼叫 `UpdPRDOP_BatchAmend`，只補缺項而保留已存值，無 `DefaultOP` 參數。共用勾選項為 Parameter、Description、QC Item、Business Rule、OP Resource、SubOP、APS。`ExecuteAPS` 控制 APS 顯示，`PRDDefault_QCItemAutoChecked` 控制 QC 預勾選。
- DEV 提供前綴查詢、全選／取消、指定站、Default／Amend、逐筆進度及取消未開始的產品。以 PD102 共用假資料作目標並寫回其關聯；預設來源使用已建置的 DEV 作業站樣板。Default 重建選取站的項目，Amend 依資料鍵補缺項。DEV 設定下隱藏 APS、QC 初始未勾選。正式動態預設來源、平行工作設定、完整 XML／規則及 APS 接入待續。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對產品作業、Description、Resource、Business Rule、QC、SubOP 及 APS 兩表欄數和主鍵。這項功能重用現有表，沿用 [Parameter／作業共用表](../../../database/reference/mestest_prd_parameter_setup_create.sql)、[標準 Default APS](../../../database/reference/mestest_prd_default_aps_create.sql) 及各 PD102 子功能 DDL。
- 建議批次候選查詢加旗標與作業站 payload，明確區分 Default／Amend。伺服器在每一產品版本的交易內重查 IssueState、區段權限、作業範圍及異動版本。回報每列結果、進度、取消狀態。取消只影響未開始項目；同一版本的並發更新應由伺服器處理。
