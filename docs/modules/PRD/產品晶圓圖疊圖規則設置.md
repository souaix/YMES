# PDP04 產品晶圓圖疊圖規則設置

- `PRD / P_PRD WAFERMAP MERGE RULE`，Web `/YMES/PRD/CPMergeMapRules`。核對 `IC_CP_PKG/MESWin_IC_CP_PKG/PRD/PD_P_WaferMAPMergeRule` 的主清單、Def、Detail、Detail_PostTest、BatchCopy 桌面 Form 與內嵌 Designer。
- 主鍵為客戶、產品類別、產品、版次、供應商、站點。畫面儲存供應商 `N/A`，以 `*` 表示選全部。測前固定進站前；測後要指定執行、來源、參考站點，圖譜限定 Probed／AOI 型別 3／6，時機為出站前或出站後。核准前須有明細；未核准可改，核准明細唯讀。
- DEV 支援查詢、主檔新增／修改／刪除、明細與條件、核准、單筆及批次複製。明細可輸入 LotNo／SlotNo／WaferID 規則、校驗與重算旗標。來源、參考、結果與失敗訊息以簡化欄位示範；正式值型別、特定值排除、Bin 映射和疊圖執行仍需原引擎。範本與站點為假資料，批次遇目標重複會保留原設定並回報衝突。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBL_BPRDMERGEMAPRULE`、`TBL_BPRDMERGEMAPRULEDETAIL`、`TBL_BPRDMERGEMAPRULE_SUB` 為 21／17／25 欄。三表使用相同六欄範圍鍵，條件表另加 ITEMSEQNO。參考 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_cp_merge_map_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_cp_merge_map_create.sql)。
- `IC_CP_PKG/wsIC_CP_PKG/wsPRD/wsPRD.cs` 的 Load／Add／Edit／Del／ApproveMergeMAPRule、`LoadMergeMAPRuleDetail`、`AddMergeMAPRuleDetail`、單筆與批次 Copy 交給 `MEStc_IC_CP_PKG/tcPRD/clsProduct.cs`。範本由 `IC_CP_PKG.wsSYS.LoadMAPTemplate` 取得。測後另核對產品流程與來源／參考作業站。
- 建議 `/api/prd/cp-merge-map-rules` 提供三層資訊、候選、核准與批次複製。依六欄範圍和預期 DataStamp 更新，維持主檔與明細交易一致。正式疊圖與校驗規則的列舉沿用原程式與圖譜引擎。
