# PD114 自定義流程卡

- `PRD / USER DEFINED RUNCARD`，Web `/YMES/PRD/RunCards`。來源 `STD/MESWin/PRD/PD_UserDefinedRunCard` 的 `frmUserDefinedRunCardData`、`frmUserDefinedRunCardDataDef`（內嵌 Designer）及 `frmUserDefinedRunCardDataTest` 與其 Designer。
- 主檔依流程卡編號查詢，支援新增、修改、複製及刪除。主檔保存類型、主流程卡旗標、格式檔名、印表機、描述和 Detail 表頭範圍。欄位明細以格式欄位名稱識別，依類型設定表欄位、自訂值、腳本、SQL 或子流程卡，另有擷取設定、預設值及備註。
- DEV 使用 localStorage 和假資料測試欄位值。格式檔名與印表機只作為設定值，腳本與 SQL 僅存文字，子流程卡回傳參照名稱。正式格式檔、條碼圖片、子卡展開、WIP 值解析和列印都需要原報表／WIP 引擎。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDDEFINERUNCARDBASIS` 13 欄，PK `RUNCARDNO`，以及 `TBLPRDDEFINERUNCARDDETAIL` 12 欄，PK `(RUNCARDNO, FILEFIELD)`。`DATASCRIPT` 為 CLOB。參見 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_run_card_source_ddl.sql) 和 [CREATE-only](../../../database/reference/mestest_prd_run_card_create.sql)。兩檔重建字典中的欄位、可空性與主鍵，未驗證 Oracle 實體儲存與觸發器。
- `STD/MESws_STD/wsSTD/wsPRD/wsPRD.cs` 將 `LoadRunCardBasis`、`LoadRunCardDetail`、`AddRunCardBasis`、`EditRunCardBasis`、`DelRunCardData` 交給 `STD/MESkc/kcPRD/clsProduct.cs`。建議以 `/api/prd/run-cards` 提供列表與單筆，以單一交易寫入主檔和明細。修改以預期 DataStamp 驗證更新，刪除前檢查子卡及產品對應引用。確認來源代碼及數值範圍，欄位名在同卡內唯一。
- 測試值源於 `wsWIP.GetRunCardValue`。接線前確認測試資料權限、允許的來源表與欄位、腳本與 SQL 的執行政策，以及報表格式檔的管理方式。
