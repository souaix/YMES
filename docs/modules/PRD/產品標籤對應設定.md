# PD108 產品標籤對應設定

- `PRD / PRODUCT LABEL MAP BASIS`，Web `/YMES/PRD/ProductLabelMap`。主 Form 與 Designer 位於 `STD/MESWin/PRD/PD_ProductLabelBasis/frmProductLabelBasis.vb`，編輯與批次窗分別為 `frmProductLabelBasisDef.vb`、`frmProductPrintLabelDefault.vb`。
- 主畫面 `LoadProductLabelBasis` 查 `TBLPRDLABELMAP`，包含標籤來源、產品、客戶、作業站、標籤類型與編號的條件。ADD／Copy 呼叫 `wsPRD.AddProductLabelData`，EDIT 以 `DataStamp` 更新 `LabelNo`，DEL 依原鍵刪除。對應鍵是 `ProductNo, CustomerNo, LabelType, OPNo, LabelSource`，產品版本來自目前版查找。
- 過帳來源 `LabelSource=2` 要求具體產品和客戶，OP 可選指定站或 `*`。其餘來源讓產品／客戶選 `*`，作業站使用 `N/A`。標籤候選依來源及類型篩選。DEV 候選重用 PD107 標籤及 PD102 已核准的目前產品版，客戶與部分作業候選使用固定假資料。
- `ParDefault` 經 `LoadDataForPrintLabelDefault` 與 `UpdProductPrintLabelDefault` 處理來源 2。Core 取得已核准目前版的 `TBLPRDOP.SERIALNO`，新增或更新 `TBLPRDOPATTRIB.PrintLabel`。明確指定站優先，萬用站只涵蓋沒有明確對應的站。服務更新 LastAction 稽核欄，逐列回報結果。
- DEV 支援批次查詢、選取、確認、逐列結果及目前綁定。寫入 PD108 模組的本機綁定假資料，供本頁重查；PD102 的 `PrintLabel` 參數跨頁同步與正式執行待接入。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDLABELMAP` 13 欄和五欄主鍵，附 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_product_label_map_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_product_label_map_create.sql)。標籤主檔與作業參數沿用 [PD107](標籤設定.md) 和 [PD102 Parameter](產品參數設定.md) 的參考。
- 建議 `GET/POST /api/prd/product-label-maps`，以複合鍵支援更新與刪除，提供批次預設查詢及執行。核對已核准目前版、客戶、候選標籤、作業與群組權限，執行時以明確對應排除萬用列的同站寫入。每列以交易更新 `PrintLabel` 和 LastAction，回傳成功與錯誤，保留 DataStamp 併發語意。
