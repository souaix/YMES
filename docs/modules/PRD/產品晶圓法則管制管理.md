# PDP03 產品晶圓法則管制管理

- `PRD / P_WAFER RULE MANAGER`，Web `/YMES/PRD/CPWaferRules`。核對 `IC_CP_PKG/MESWin_IC_CP_PKG/PRD/PD_P_PRDWaferRuleManager` 的 `frmPRDWaferRuleManager`、`frmFileImport_WaferRule`、`frmFormulaScript` 與 Designer。
- 產品、Device、作業站須至少填一項才查詢法則摘要。DEV 顯示低良率、OS 比例與數量、Bin 法則及 Hold 代碼，點入可檢視來源檔案、列與欄位。DEV 範本及匯入讀第一張工作表 A–S、第三列起讀資料，檢查產品、站點、數字欄、AND／OR 與同站同法則。確認後依產品替換本機摘要，保留輸入列。
- DEV 以展開後的欄位匯入，產品與站點須逐列填寫。來源 WinForms 還原合併儲存格，驗證設備／站點、法則參數與控制 Bin，並顯示運算腳本。合併、正式腳本、略過／覆蓋規則、舊版 XLS 與 ERP 晶圓 Bin 摘要待正式服務。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBL_PPRDWAFERRULEIMPORTSUMMARY`（16 欄，PK PRODUCTNO／PRODUCTVERSION／SERIALNO／WAFERRULENO）、`TBL_PPRDWAFERRULEIMPORTDETAIL`（17 欄，PK PRODUCTNO／ROWINDEX／COLUMNINDEX／IMPORTFILENAME）。參考 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_cp_wafer_rule_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_cp_wafer_rule_create.sql)。
- `IC_CP_PKG/wsIC_CP_PKG/wsPRD/wsPRD.cs` 的 `Load_PPRDWaferRuleImportSummary` 與 `FileImport_WaferRule` 經 `MEStc_IC_CP_PKG/tcPRD/clsProduct.cs` 讀寫摘要／明細，連作業站顯示站名與順序。匯入依原始儲存格列／欄及實際產品版次、SerialNo、摘要與明細各自 ImportType 處理。
- 建議 `/api/prd/cp-wafer-rules` 提供條件查詢、腳本檢視、匯入預檢及確認。正式匯入需依合併格來源展開、驗證產品／站點與 Hold／Bin 查詢、計算參數及描述，交易內按原產品範圍更新正式摘要及來源明細。
