# PD107 標籤設定

- `PRD / LABEL DATA`，Web `/YMES/PRD/LabelData`。WinForms 和內嵌 Designer 在 `STD/MESWin/PRD/PD_LabelData/frmLabelData.vb`、`frmLabelDataDef.vb`、`frmLabelTest.vb`。
- `wsPRD.LoadPRDLabelBasis` 依編號／類型查主檔，明細由 `LoadPRDLabelDetail` 取得。`AddPRDLabelData`／`EditPRDLabelData` 把主檔和全量明細交給 `STD/MESkc/kcPRD/clsProduct.cs`，Edit 帶 DataStamp。`DelPRDLabelData` 刪主檔與明細。Copy 經新增流程另存標籤編號。
- 主檔含 LabelNo、LabelType、FormatFileName、LabelSource、PrinterNo、Description。至少一筆明細；ItemName 必填且不可重複。原編輯器在送出前整理明細排序，寫入 `Piece=0`。Direction=`All/Left/Right`；擷取模式要求起點及長度。RAW 只配 MATERIAL，SORTBIN 只配 SORT_PASS／SORT_NG／SORT_INV。
- DEV 可新增、編輯、複製、刪除主檔及明細；支援排序、欄位和類型檢查。Test／Preview 組合固定假資料、使用者輸入的測試批號與字串片段。LabelSource 採用數值代碼，正式值清單透過 `ValueListProvider`；編輯和預覽保留來源代碼、格式檔名及 DataScript 文字。
- 正式 `GetLabelValue_Preview`、批號／原料取值、腳本產值、印表機、BarTender／LabelManager、格式檔渲染待接入。DEV 預覽只顯示文字欄位；`SC`、`SQL` 顯示等待正式產值。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀確認 `TBLPRDLABELBASIS` 11 欄，主鍵 `LABELNO`，沿用 [主檔 CREATE-only](../../../database/reference/mestest_prd_label_basis_lookup_create.sql)。`TBLPRDLABELDETAIL` 11 欄，主鍵 `LABELNO, POSITION, PIECE`，`DATASCRIPT` 為 CLOB；附 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_label_detail_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_label_detail_create.sql)。
- 建議 `GET/POST /api/prd/label-data` 與 `PUT/DELETE /api/prd/label-data/{labelNo}`。帶 DataStamp，交易式替換明細；既有資料若保有非零 Piece 需可讀並驗證保留策略。刪除前核對產品／物料標籤對應。預覽的正式取值由受控伺服器端引擎執行並回傳具名欄位。
