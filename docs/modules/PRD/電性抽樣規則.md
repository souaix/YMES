# PD204 電性 (EQC) 抽樣規則

- `PRD / EQC SAMPLE RULE`，Web `/YMES/PRD/EQCSampleRules`。核對 `STD/MESWin/PRD/PD_EQCSampleRule/frmEQCSampleRule.vb`、`frmEQCSampleRuleDef.vb`，含內嵌 Designer。Vue DEV 支援查詢、依狀態篩選、新增、修改、檢視、複製、核准及刪除，維持未核准才能改與核准的行為。
- AQL 使用規則代碼 10–15；指定抽樣量使用 20–24，抽樣量限 1–99999。11／20 必選單一 Bin，12／22／23 為多 Bin，依畫面順序給 1 起算的 BinOrder；14 需要 1–99 的最大 Bin 數。16／25 為程式保留的函式設定，新的選項清單只列 10–15、20–24。
- `wsPRD.LoadEQCSampleFunction` 透過 `udEQCFunction.clsEQCFunction` 反射取得方法名稱。DEV 保留既有函式欄位供檢視，Bin 候選為固定假資料，核准直接更新本機狀態。正式函式、系統 Bin 目錄、抽樣執行與簽核服務待接續。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDEQCSAMPLERULE`（14 欄，主鍵 RULENO）與 `TBLPRDEQCSAMPLERULEBIN`（3 欄，主鍵 RULENO／BINORDER）。主檔 ASSIGNBINNO 為字串。參考 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_eqc_sample_rule_source_ddl.sql)、[CREATE-only](../../../database/reference/mestest_prd_eqc_sample_rule_create.sql)、[TBLSYSBIN CREATE](../../../database/reference/mestest_prd_bin_create.sql)。
- 標準 `wsPRD.cs` 的 Load／Add／Edit／Del／Approve／CopyEQCSampleRule、LoadEQCSampleRuleBin 連到 `STD/MEStc/tcPRD_IC/clsEQCRule.cs`。更新 Bin 明細為整組刪除後插入。建議 `/api/prd/eqc-sample-rules` 按規則號讀寫主從，新增與修改驗證抽樣模式和必要欄位，修改、核准、刪除核對 DataStamp，依簽核配置與現有使用狀態決定正式轉態。
