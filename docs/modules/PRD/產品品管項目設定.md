# PD102 產品品管項目設定（QC Item）

## WinForms、Service 與 Core

- `PD_ProductBasis_THEIL_BU1/frmProductBasis_THEIL_BU1.vb:1799` 的 `btnQCItem_Click` 將產品編號、版次及名稱傳給 `PD_ProductQCItem`。產品狀態未傳入，啟用及存取受功能權限控制。主窗和 Designer 位於 `STD/MESWin/PRD/PD_ProductQCItem/frmProductQCItem.vb`，視窗約 1008×729。
- OP lookup 呼叫 `wsOP.LoadOPBasis`，查已核准（IssueState=2）且有 PS 權限的作業站。選站後呼叫 `wsOP.LoadOPQCItem` 四次，依 QCItemType 載入該站的計數項目（0）、計量項目（1）、計量群組（2）和計數群組（3）。`clsOpBasis.LoadOPQCItem` 以 `TBLOPQCITEM` 查各對應目錄。
- 右表透過 `wsPRD.LoadPRDOPQCItem`／`clsProduct.LoadPRDOPQCItem` 載入同產品、版次和 OP 的設定。已指派項目會從左側可選清單隱藏。左側可將選取項目加入 InLine 或 OffLine，雙擊走 InLine，右側可移除選取項目。InLine 加入時檢查 LotIsValid，儲存前每列至少要勾 FAI、IPQC、PQC 一項。OffLine 不編輯 ExecuteOrder，檢驗類型旗標清空。右表另顯示 Reviser／ReviseDate。
- Apply 經 `wsPRD.UpdPRDOPDQCItem` 呼叫 `clsProduct.UpdPRDOPQCItem(DataTable, ...)`，儲存後留窗。Confirm 成功後關窗。Core 刪除該產品版次及 OP 的舊行，再插入這個分組的完整清單，空清單表示清除該 OP。產品綁定另呼叫 `clsQCBasis.UpdQCItemBindLog`（BindType=4），Service 記錄事件。`Reviser`／`ReviseDate` 未設定時由舊 Form 補上登入者與時間，Web 正式實作改由伺服器取得。
- QC Import 派送到 `PD_ProductQCDataImport`，來源檔案與模板呼叫 `wsSYS`，資料檢查交給 `DataImporter.ProductQCItemImporter.ProductDataChecker`。QC Chart 開啟同專案的 `frmImportQCChartBasis`，有 File、Check、Select/UnSelect All、Save，儲存走 `wsQC.ImportQCChartBasis`。Apply 後重新開放 QC Chart。

## Oracle metadata 與 SQL 交接

- 2026-11-18 使用 Windows PowerShell 5.1 + ODP.NET 透過本機受保護 profile 唯讀查 MESTEST。新查 `TBLPRDQCITEM` 有 13 欄及主鍵 `(PRODUCTNO, PRODUCTVERSION, OPNO, QCITEMNO)`，只有 PK 索引，字典未列 FK 或其他 unique key。`XX_FREQ NVARCHAR2(300)` 可為 NULL，QC213 的舊 SQL 參照尚未列此欄。相同 PD102 更新方法並未讀寫此欄，正式 API 實作前應確認其他流程是否使用它。
- `GET_DDL` 回 `ORA-03135`。由 `ALL_TAB_COLUMNS`、`ALL_CONSTRAINTS`、`ALL_CONS_COLUMNS`、`ALL_INDEXES` 重建目前 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_qc_item_source_ddl.sql) 及 [PostgreSQL CREATE-only](../../../database/reference/mestest_prd_qc_item_create.sql)。此輪只讀 metadata。
- 另核對 `TBLOPBASIS`、`TBLOPQCITEM`、`TBLQCITEMFORATTRIBUTES`、`TBLQCITEMFORVARIABLES`、`TBLQCITEMGROUPBASIS`、`TBLQCITEMATTGROUPORDERBASIS` 與 `TBLQCITEMBINDLOG`。保留既有共用表。BindLog 主鍵為 `(QCITEMNO, BINDTYPE, QCITEMLOGSERIAL)`，家用端先核對 [物料 QC 共用 migration](../../../database/migrations/0019_mtl_qc_item_library_api.sql) 及 live schema。

## Vue DEV 與家用端待辦

- `ProductQCItemSetup.vue` 由 PD102 QC Item 開啟，DEV 以固定 OP／QC 目錄示範四類、InLine／OffLine、多選移除、檢驗旗標、稽核、Apply／Confirm／Cancel。變更存入產品版次關聯的 `qcItems`，儲存只替換選中的 OP，保留其他 OP。DEV 儲存依 Oracle 主鍵阻止同項目同時 InLine 與 OffLine，ExecuteOrder 設為 0–99。
- QC Import 與 QC Chart 目前提供選檔視窗。Excel 解析、格式檢查、列選取及寫入仍待實作。正式頁顯示 API 未接線。
- 建議登入保護的 `GET/PUT /api/products/{productNo}/versions/{version}/operations/{opNo}/qc-items`，GET 回傳該站已指派與可選目錄，PUT 驗證產品版次、OP／PS 權限、型態、LotIsValid、重複項目、旗標和數值範圍。寫入侷限選中 OP，在同一交易處理替換及稽核，支援空陣列清除，並核對來源的變更比較及並發規則。
- 家用端須先比對 YMES live schema 及 migration history，再確認 `xx_freq` 演進及是否需在替換時保留。核對既有 BindLog 服務，避免重複建立。公司端僅靜態檢查，瀏覽器、API 與匯入驗收尚待執行。
