# PDB01 挑片規則設定

- `PRD / B_CHOOSE WAFER RULES`，Web `/YMES/PRD/ChooseWaferRules`。核對 `Industry_Base/MESWin_Industry_Base/PRD/PD_B_ChooseWaferRules` 的 `frmChooseWaferRules.vb`、`frmChooseWaferRulesDef.vb` 及內嵌 Designer。
- 維護規則號、名稱、生產區段、參考產品／類別、選定倉、供應商、條件及說明。倉庫必須同為原物料倉或同為半成品倉。原表單的條件工具由固定欄位或區段對應的動態欄位選一，依欄位型別、運算子與值組合文字。
- DEV 提供查詢、CRUD、複製、檢視、套用與核准。規則編號與區段在修改時唯讀。條件欄位以固定假資料示範文字／數字／日期，僅產生及保存文字；正式區段 metadata、庫存、供應商及挑片執行待接續。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDCHOOSEWAFERRULES`（15 欄，PK CHOOSEWAFERRULENO）及 `TBLSYSMOCHOOSEWAFERTABLE`（15 欄，PK FUNCTIONNO）。`ASSINGSCRIPT` 為 CLOB；資料表沿用既有的 `ASSING` 欄位拼字。見 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_choose_wafer_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_choose_wafer_create.sql)。
- Industry_Base 的 `MESws_Industry_Base/wsPRD/wsPRD.cs` 的 Load／Add／Edit／Del／ApprovePRDChooseWaferRule 經 `MEStc_Industry_Base/tcPRD/clsPRD_Industry_Base.cs` 與 Base UPD 類別讀寫。區段候選由生產區段服務取得；`LoadSYSMOChooseWaferTable` 支援依 PSNo 取得對應欄位 metadata；測試摘要來自 `Industry_Base.wsSYS.LoadTestSummaryTable`。
- 建議 `/api/prd/choose-wafer-rules` 提供查詢、候選、CRUD、核准。依規則號與 DataStamp 異動，正式條件透過欄位與運算子允許清單及參數化執行，核對倉型、區段、母體來源及簽核權限。已儲存條件需要版本兼容。
