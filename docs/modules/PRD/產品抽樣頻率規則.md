# PD206 產品抽樣頻率規則

- `PRD / PRD QCRULE BASIS`，Web `/YMES/PRD/QCFrequencyRules`。來源 `STD/MESWin/PRD/PD_QCRuleBasis/frmPRDQcRuleBasis.vb` 與 `frmPRDQcRuleBasisDef.vb`（含內嵌 Designer）。依產品、設備、作業站維護抽樣頻率，未指定的鍵以 `*` 儲存。修改保持複合鍵與模組唯讀。
- 三種頻率依序為多批抽一批、每天第一批、每班第一批。多批模式要有抽樣批次數；每天要有 A 班時間；每班要有 A、B 班時分。DEV 依庫表兩位數精度檢查 1–99，時分沿用原表單的時 00–24、分 00–59。
- DEV 支援篩選、CRUD、複製與套用。新資料使用 WIP，因 Designer 隱藏 SPC 選項。既有 SPC 資料保留品管項目，複製成 WIP 時清除品管項目。產品候選共用 PD102 核准產品，其餘候選使用固定假資料。正式設備／站點候選、SPC 品管選取和抽樣執行待家用端接續。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDQCRULEBASIS` 16 欄，PK `(PRODUCTNO, EQUIPMENTNO, OPNO)`。`SHIFTA`、`SHIFTB` 保留字串，`QCNUM` 為兩位數。參閱 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_qc_frequency_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_qc_frequency_create.sql)。
- 標準 `wsPRD.cs` 的 `LoadQCRuleBasis`、`AddQCRule`、`EditQCRule`、`DelQCRule` 交由 `STD/MESkc/kcPRD/clsProduct.cs`。候選來自產品、設備和作業站主檔；既有 SPC 配置曾透過 `LoadQCItem` 依產品／站點與 InLine 取候選。WIP 執行端在 `STD/MEStc/tcWIP_IC/clsBusinessRule.cs` 讀取 WIP 規則。
- 建議 `/api/prd/qc-frequency-rules` 提供 CRUD、複製與正式候選。用複合鍵與預期 DataStamp 更新，依 frequency 送必要欄位並核對舊資料的空值。正式執行的班別跨日及批次計數仍需核對。

- 所列 SQL 條件用綁定參數表示其等值語意。檢閱上述 Form、Service、Core 及全來源的表名／方法引用，這些路徑均未找到 PD206 guard、更新或刪除關聯。PD206 自身的 `DelQCRule` 在 `kcPRD/clsProduct.cs:37151–37180`，只以 `ProductNo = :productNo AND EquipmentNo = :equipmentNo AND OPNo = :opNo` 刪指定一組。MESTEST 資料字典只回 PD206 主鍵及四個 NOT NULL 約束，四張主表未查得可見觸發器，也未查得依賴 PD206 的 Oracle 物件。查證範圍為目前可讀來源及 MESTEST metadata。
- 標準 `wsPRD.cs:1696 DisApproveProduct` 對 Active／UnUsed 呼叫 `kcPRD/clsProduct.cs:1615 SetProductIssueState`，將指定產品版改為未核准並清除 CurVersion。一般核准切換目前版按 ProductNo 先清目前版，再核准指定版；THEIL 另有 `Customer/Production/wsTHEIL/wsPRD/wsPRD.cs:785 ApproveProduct`。上述變更的產品識別都有 ProductVersion，PD206 只存 ProductNo。可讀來源未見刪單版、最後存在版、最後核准版、取消核准或並發時的 PD206 特別政策。現有家用端儲存時父鎖與資格檢查屬 YMES 決策。若要新增生命週期保護，需先決定是否接受暫無合格版的規則與後續復用，再定義並發政策。
- `STD/MEStc/tcWIP_IC/clsBusinessRule.cs:11222–11329` 先讀取 `ModuleNo='WIP'` 的規則，以 `(產品, 設備, 作業站)` 實際順序比對 `(P,E,O)`、`(P,E,*)`、`(P,*,O)`、`(*,E,O)`、`(P,*,*)`、`(*,E,*)`、`(*,*,O)`、`(*,*,*)`。每個 `*` 是該欄使用全域範圍的字面值，獨立於個別父主檔生命週期。
