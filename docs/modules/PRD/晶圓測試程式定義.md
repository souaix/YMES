# PDP02 晶圓測試程式定義

- `PRD / P_CP PROGRAM DEFINE`，Web `/YMES/PRD/CPPrograms`。核對 `IC_CP_PKG/MESWin_IC_CP_PKG/PRD/PD_P_CPProgramDefine` 的 `frmPRDCPProgram`、`frmPRDCPProgramDef`、`frmFileImport_CPBin`、`frmProgramUpload`，及 `PD_PRDCPProgramBin/frmPRDCPProgramBin.vb`，含內嵌 Designer。
- DEV 共用 FT 版次畫面的基本資料、查詢和異動流程。CP 使用獨立 localStorage、程式類別及十字元版次。複製帶入 Bin；開新版限核准的目前版，新版保留類別並從空 Bin 開始。只有未核准可修改、設定 Bin、選擇檔案或核准，核准至少需要一筆 Bin。
- Bin XLSX 第一工作表的 B1／B2 要等於程式／版次，第五列起讀 BinNo／PASS 或 FAIL／OS／說明。PASS 不可為 OS。匯入依 BinNo 合併，提供綠／紅／紫預設顏色並可修改。DEV 用假程式類別和 Bin 編號格式，檔案只記檔名；伺服器原範本、正式 Bin 目錄、權限、編碼、簽核與檔案內容待接續。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBL_CPPRDPROGRAMBASIS`（12 欄，PK PROGRAMNO／PROGRAMVERSION）與 `TBL_CPPRDPROGRAMBIN`（8 欄，PK PROGRAMNO／PROGRAMVERSION／BINNO）。主表版次長度 10，Bin 表版次欄長 20。參考 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_cp_program_source_ddl.sql) 與 [CREATE-only](../../../database/reference/mestest_prd_cp_program_create.sql)。
- `IC_CP_PKG/wsIC_CP_PKG/wsPRD/wsPRD.cs` 的 Load／Add／Edit／Copy／Approve／DelProgramNo、`LoadPRDCPProgramBinDefine` 與 `UpdPRDCPProgramBin` 使用 `MEStc_IC_CP_PKG/tcPRD/clsProduct.cs`。程式類別取系統 ValueList，檔案類型為 50，透過 FolderNo 關聯正式檔案管理。
- 建議 `/api/prd/cp-programs` 提供條件查詢、CRUD、複製、核准及 Bin 預檢／儲存。異動以 DataStamp 驗證，核准時於同一交易確認 Bin 與目前版狀態，複製需兼顧主檔和 Bin。Bin 顏色維持 Oracle 的 ARGB 整數及 RGB 字串格式。
