# PD104 產品內容查詢

- MES 選單 `PRD / PRODUCT SEARCH`，Web `/YMES/PRD/ProductSearch`。原始 Form 與內嵌 Designer 在 `STD/MESWin/PRD/PD_ProductSearch/frmProductSearch.vb`。
- `MaterialNo`、`ProcessNo`、`PropertyNo` 由查找視窗選取，所選條件自動勾選；取消勾選清除該值。屬性查詢也需要 `PropertyValue`。WinForms 以 `wsPRD.LoadBOM_Distinct`、`wsPRS.LoadProcess`、`wsPRD.LoadProductProperty` 提供候選。
- `wsPRD.LoadProductSearch` → `STD/MESkc/kcPRD/clsProduct.cs` 的同名方法。當多個條件同時啟用時取交集，所有關聯比對都使用 `(ProductNo,ProductVersion)`。用料以 `TBLPRDBOM.NodeNo` 查直接節點，流程只比對 `ProcessNo`，屬性以 `PropertyNo` 加 `DefaultValue` 比對。沒有條件時可查全部。
- DEV 查找與查詢直接使用 PD102 本機假資料，同一版次才符合交集。已實作取消條件、缺值提示、空結果、表格及數量欄靠右。表格顯示主檔常用欄與包裝數量；舊系統可回傳完整主檔欄，另依 FT_PKG 系統開關隱藏 `I_CUSTOMERNO`、`BATCHUSERNO`。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBLPRDPRODUCTBASIS` 84 欄、`TBLPRDBOM` 19 欄、`TBLPRDPRODUCTPROCESS` 16 欄、`TBLPRDPRODUCTPROPERTY` 12 欄。沿用 [PD102 Oracle 來源 DDL](../../../database/reference/mestest_prd_product_basis_source_ddl.sql) 及 [CREATE-only 參考](../../../database/reference/mestest_prd_product_basis_create.sql)。此查詢沿用既有表。
- 建議 `GET /api/prd/product-search`，支援 materialNo、processNo、propertyNo、propertyValue 及分頁。屬性鍵與值視為一組；伺服器為每個條件使用帶參數的 `EXISTS`，依同一產品版次關聯，避免多筆明細讓結果重複。沿用既有候選 API 或提供唯讀 options 端點；正式資料權限及完整欄位依產品主檔與站點開關確認。
