# PDP01 晶圓良率與出貨報告維護

- `PRD / P_CP WAFER YIELD SHIP REPORT`，Web `/YMES/PRD/CPWaferShipReports`。來源 `IC_CP_PKG/MESWin_IC_CP_PKG/PRD/PD_P_CPWaferYieldShipReport` 的 `frmCPWaferYieldShipReport.vb`、`frmCPWaferYieldShipReportDef.vb`（含內嵌 Designer）。
- 設定以客戶／產品識別，允許指定客戶與指定產品、指定客戶與 `*`、或兩者均 `*`。出貨 MAP、出貨明細各自選 `LAST FULL TEST` 或 `USER DEFINE`。自訂需選至少一個站點，序列化為 `SHIP MAP`／`SHIP DETAIL`。主檔另有出貨後 MAP、MAP 一致與 GoodQty 一致三個檢查旗標。
- DEV 支援查詢、新增、修改、來源站點明細與停用，亦可選擇顯示停用資料及修改後啟用。修改保持客戶及產品唯讀。站點使用固定假 CP 站點，產品候選使用對應客戶的 PD102 DEV 資料。DEV 以整數模擬 ComboSeqNo 和歷史，正式報告產出、檢查執行、客戶目錄與站點候選待接入。

## Oracle 與家用端交接

- PowerShell 5.1 + ODP.NET 唯讀核對 `TBL_CPSYSCOMBOMAPBASIS`、`TBL_CPSYSCOMBOMAPDETAIL`、`TBL_CPSYSCOMBOMAPLOG`、`TBL_CPSYSCOMBOMAPDETAILLOG`，欄數為 11／5／11／5。主檔使用客戶／產品複合鍵，明細再加來源／站點；兩個歷史表的鍵含 ComboSeqNo。見 [Oracle 邏輯 DDL](../../../database/reference/mestest_prd_cp_ship_report_source_ddl.sql) 和 [CREATE-only](../../../database/reference/mestest_prd_cp_ship_report_create.sql)。
- `IC_CP_PKG/wsIC_CP_PKG/wsPRD/wsPRD.cs` 之 `LoadComboMAPBasis`、`LoadComboMAPDetail`、`UpdAddComboMAP`、`UpdEditComboMAP`、`UpdDelComboMAP` 呼叫 `MEStc_IC_CP_PKG/tcPRD/clsPRD.cs`。站點由 `LoadOPBasisJoinOPProperty` 取 `CP_PROBE=Y`。核對客戶產品及精確／萬用值的正式挑選優先序。
- 建議 `/api/prd/cp-wafer-ship-reports` 提供查詢、候選、新增、更新和停用。送主檔與兩組站點明細，以交易寫現況與歷史，狀態為 Actived／NotUsed。正式 ComboSeqNo 是時間型識別字串，需要處理併發唯一性與停用後重啟流程。
