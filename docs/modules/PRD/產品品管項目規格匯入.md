# PD116 產品品管項目規格匯入

- `PRD / PRD QCITEM SPEC IMPORT`，Web `/YMES/PRD/QCSpecImport`。來源 `Customer/Production/MESWin/PRD/PD_ProductQCSPECImport_THEIL_BU1` 的 `frmPRDQCSPECImport_THEIL_BU1` 及 `FrmPRDBasisExport_THEIL_BU1`，兩者皆核對 Designer。
- 匯入讀第一張工作表、第一列為標題、首欄空白跳過；A–AY 共 51 個位置欄位。A–P 為產品／版次、群組、品管項目、類型、站點、檢驗設定與量測基礎。後面依 T/X/R/S/M 各七欄，分別為 US、CS、LS、UCL、CL、LCL 及 rule。規則單筆為 `RuleNo,Action`，以分號隔開，Action 為 WARNING／WAIT／HOLD／ALERT。
- DEV 提供空白或選定假產品的 XLSX 範本、New Plan／Override、51 欄預覽、列級錯誤與本機套用。檢查假產品版次、必填欄位、重複列、群組一致性、列舉欄位與規則格式。New Plan 保留本機已有的相同對應，Override 替換本機同鍵資料。DEV 結果單獨存放，包含 XLSX 文字值與順序；舊版 XLS、正式範本帶回現有規格、Oracle 業務驗證，以及轉換成 SPC 生效計畫由正式服務承接。

## Oracle 與家用端交接

- Form 送 `ImportType`（0／1）與 `ImportExcel` 至客製服務 `Customer/Production/MEStc_THEIL/tcPRD/clsProduct.cs` 的 `QCItemSPECDataChecker`；由 `UpdPRDQCItem` 建立或替換指派，類型 1／2 經 `UpdPRDOPQCItemSPEC_Import` 更新圖表規格、規格歷史及規則。範本端透過 `THEIL.wsPRD.LoadProduct_C`、`LoadPRDOPQCItem_C`、`LoadSPCQCChartAndDetail_C` 取得現有資料。
- PowerShell 5.1 + ODP.NET 唯讀核對 13 欄的 `TBLPRDQCITEM`（產品、版次、站點、品管項目複合鍵）及 SPC 主檔、明細、明細歷史、規則表（32／12／15／7 欄），並確認作業站、計量品管主檔、抽樣方案及規則字典表。沿用 [PD102 指派來源 DDL](../../../database/reference/mestest_prd_qc_item_source_ddl.sql)、[PD102 CREATE](../../../database/reference/mestest_prd_qc_item_create.sql)、[QC302 圖表來源 DDL](../../../database/reference/mestest_qc302_spc_qc_chart_source_ddl.sql)、[QC302 CREATE](../../../database/reference/mestest_qc302_spc_qc_chart_create.sql) 及 [抽樣參數 CREATE](../../../database/reference/mestest_qc301_chart_sampling_parameter_create.sql)，本功能使用既有 schema。
- 建議 `/api/prd/qc-spec-import` 列級預檢並回報錯誤、確認後以同一批交易重新驗證再寫入。正式服務需核對品管項目／群組是否核准、群組成員、LOTISVALID、站點、因子、抽樣方案、上下規格線及規則目錄，並保留 New Plan／Override 對圖表歷史的既有語意。
