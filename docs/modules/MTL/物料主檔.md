## 主清單畫面

- 預設 IssueState=0；可切換 0 未簽核、1 簽核中、2 已簽核、-1 不使用。查詢欄位為 MaterialNo，WinForms 另將共用查詢條件加入 `LoadMaterialBasis`。
- 清單依 MaterialType、MaterialNo 排序；欄位值由 ValueListProvider 將 PutInPlace、CountWay、CheckLotNo、OpenLimitTimeFlag、ExpireDateFlag、ResetOpenDate 轉成顯示文字。DataStamp 與 IssueState 不顯示，數量與時間欄靠右格式化，建立/修改人與日期為稽核欄位。
- 動作順序：ADD、EDIT、DEL、Copy、Approve、Property、QC Item、Import、GumHour。EDIT 與 Approve 只對未簽核資料啟用；Copy 以目前列為來源，建立新的未簽核資料。
- WinForms Delete/Approve 會以目前作用列加入 Selected.Rows，再逐筆處理多選列。Delete 對 0/-1 實體刪除、對 2 設為 -1；Approve 只核准狀態 0。Vue 以列選取核取方塊支援多選，仍逐筆呼叫既有單筆 API，不虛構批次端點；API 失敗時先前成功項目不會自動回滾，畫面需呈現已完成筆數並重新查詢。
- 主清單下方 Vendor 子 Grid 隨作用列載入，顯示 VendorNo、VendorName、Description；支援新增、修改、刪除，名稱由 `LoadMaterialVendorMapWithVendorName` 回傳。切換作用列也重新載入供應商明細。
- `MATERIALMULTITIMECTRL=0` 時 WinForms 隱藏 GumHour；啟用時只有 MaterialType 符合 `GumMaterialType` 才能開啟。核准也只在此參數啟用且類別符合時檢查 GumHour 設定。DEV 預覽假設參數為 1、`GumMaterialType=GUM`；Production 需由 options API 傳回實際設定。
- Development 假資料存在瀏覽器 localStorage 並有提示；Production 未有 API 時不得回退成假資料。

## 新增、修改、複製與狀態規則

- 必填：MaterialNo、MaterialName、MaterialType、UnitNo、PutInPlace。
- MaterialNo 不可與物料類別編號衝突。若 ProductMaterialcoexist 未啟用，還須檢查產品編號衝突。
- 新增與複製建立 IssueState=0。新增時，服務會複製該類別已核准的物料屬性範本，以及物料類別 QC Item 範本至物料明細表。
- 修改只允許未簽核資料；更新須維持 DataStamp 並行控制及建立/修改人員與日期稽核欄位。
- SafeQty 必須是大於或等於 0 的數值。開封時限啟用時，OpenLimitTime 必須是大於或等於 0 的數值。
- PutInPlace 已由表單固定值確認：0=EQP、1=OP、2=WIP INV、3=MO。CountWay 與 CheckLotNo 由 ValueListProvider 提供；值/顯示文字待正式 ValueList 核實，不以舊程式註解推定。
- 刪除前檢查 TBLOEMOMaterialList（MaterialLevel=0）及 TBLPRDBOM（NodeType=0）引用；被引用時拒絕。
- WinForms 可刪狀態為 0、2、-1；未簽核/不使用資料實體刪除，已簽核資料依舊服務規則轉為不使用。實體刪除需同交易移除屬性、供應商對應、物料群組明細與 QC Item 子資料。

## 核准規則

- 僅可核准 IssueState=0，並以 DataStamp 防止舊資料覆寫。
- MATERIALMULTITIMECTRL=1 且物料類別屬於 GumMaterialType 時，核准前須有該物料的 TBLMTLTYPEACCLIMATION 設定。
- 物料屬性 Controlled=1 會阻擋核准；Controlled=2 會顯示確認提示；其他值不因該檢查阻擋。
- 核准、狀態修改與屬性檢查需在 API 端執行，不能只靠 Vue 按鈕狀態。
- 2026-11-17 檢視 YMES PostgresMasterDataRepository.ApproveMaterial：目前服務端檢查 Controlled=1 與 DataStamp/IssueState，但尚未按 MATERIALMULTITIMECTRL、GumMaterialType 檢查 TBLMTLTYPEACCLIMATION。此為家用端 Production API 待補項；Vue 端提示不能替代服務端檢查。

## 子功能

### 物料屬性

- 使用 TBLMTLMATERIALPROPERTY，主鍵為 (MaterialNo, PropertyNo)。
- WinForms 提供新增、修改、刪除、複製、核准、關閉。新增物料時會從類別已核准屬性複製初始資料。
- 核准檢查讀取 Controlled 值；需與物料核准維持一致性。

### QC Item

- TBLMTLQCITEM 儲存物料已指派項目；TBLMTLTYPEQCITEM 儲存物料類別範本。新增物料時由類別範本複製。
- 表單分 Attributes、Variables、Group 三種類型，舊系統代碼為 0、1、2；支援可選與已指派清單間移入/移除。
- Vue Development 對話框示範三種類型及移入/移除；Production API 需提供正式候選項目與整批更新。

### 供應商對應

- 表 TBLMTLMATERIALVENDORMAP，複合鍵 (MaterialNo, VendorNo)，另有 Description。
- 主畫面下方顯示供應商編號、名稱、說明；名稱由 LoadMaterialVendorMapWithVendorName 關聯供應商主檔取得。
- 支援新增、修改、刪除。修改時不能任意更換複合鍵；供應商名稱來源表/Join 條件需按舊服務 SQL 落實。

### Import

- WinForms 欄位、表單、範本與分組規則詳見[物料資料匯入](物料資料匯入.md)。
- 公司端 Vue Development 已支援 CSV/`.xlsx` 預覽、範本下載、按物料編號/名稱分組、本機假資料逐組回報及取消；Production 的 `.xls` 解析、正式範本與 API 群組交易契約仍待家用端完成。

### GumHour / Acclimation

- 表 TBLMTLTYPEACCLIMATION，鍵值 (MaterialType, MaterialNo)；MaterialNo='*' 表示類別層級通用設定。
- 欄位：ACCMin、ACCMax、RefrozenFlag、FrozenMin、ReForzenTimes、ReAcclimateFlag、ReAccMin、ReAccMax。
- 編輯權限依物料 IssueState 鎖定。Vue Development 視窗有數值與上下界檢核，仍待逐欄與 Designer/舊服務核對。

## Oracle 表與 YMES 差異

Oracle DDL 已唯讀查得 8 張表：

| Oracle MESTEST 表 | 用途 |
| --- | --- |
| TBLMTLMATERIALBASIS | 物料主檔 |
| TBLMTLMATERIALTYPE | 物料類別 |
| TBLMTLMATERIALPROPERTY | 物料屬性 |
| TBLMTLTYPEQCITEM | 類別 QC Item 範本 |
| TBLMTLQCITEM | 物料 QC Item |
| TBLMTLMATERIALVENDORMAP | 物料供應商對應 |
| TBLMTLTYPEACCLIMATION | 類別/物料膠材時效設定 |
| TBLMTLMATERIALGROUPDETAIL | 物料群組明細 |

來源擷取與轉換參考：database/reference/mestest_mtl_master_source_ddl.sql、database/reference/mestest_mtl_master_create.sql。Oracle DATE 轉 timestamp without time zone、NUMBER 轉 numeric；省略 Oracle tablespace/storage 物理設定，不搬 MES 業務資料。

現有 mestest_first_phase_create_tables.sql 的 tblmtlmaterialbasis 比目前 MESTEST DDL 多 7 個 YMES 參考欄位：sap_frameqty、sap_framesize、sap_grossdie、sap_thickness、sap_technology、sap_resolution、framsize。先保留，不刪除既有 YMES 欄位；家用電腦比對實際結構後決定相容方式。Bootstrap 已按來源補上 IssueState、PutInPlace、CountWay、CheckLotNo、SafeQty、KeyMaterials、DataStamp 的 DEFAULT。未經 Oracle column comment 核實的物料主表欄位註解已移除。

套用 CREATE TABLE IF NOT EXISTS 前先比對家用端 YMES schema；該語句不會修正已存在的表。

## 建議 Production API

| 方法 | 路徑 | 用途 |
| --- | --- | --- |
| GET | /api/materials?issueState=&keyword= | 物料清單與篩選 |
| GET | /api/materials/{materialNo} | 主檔與 DataStamp |
| POST/PUT | /api/materials、/api/materials/{materialNo} | 新增/修改並複製類別屬性與 QC 範本 |
| POST | /api/materials/{materialNo}/approve | 現行 API 檢查 Controlled/DataStamp/IssueState；GumHour 條件式檢核待家用端補齊 |
| DELETE | /api/materials/{materialNo} | 引用檢查及子表交易刪除/停用 |
| GET/POST/DELETE | /api/materials/{materialNo}/properties | 讀取、儲存、刪除物料屬性 |
| POST | /api/materials/{materialNo}/properties/{propertyNo}/approve | 核准物料屬性 |
| GET/PUT | /api/materials/{materialNo}/qc-items | 讀取/取代指派 QC Item |
| GET/POST/PUT/DELETE | /api/materials/{materialNo}/vendors | 供應商對應維護 |
| GET/PUT | /api/materials/{materialNo}/gum-hour | 讀寫 Acclimation 設定 |
| GET | /api/materials/lookups/options | 類別、單位、單位類別、PutInPlace、CountWay、CheckLotNo 及 GumHour 參數設定；CountWay/CheckLotNo ValueList 與多次回溫參數由家用端按來源核實後補齊 |
| GET | /api/materials/import/template | 正式 Excel 範本下載（家用端待實作） |
| POST | /api/materials/import/preview | `.xls` multipart 預覽（家用端待實作） |

新增物料複製範本、刪除子表及核准等跨表操作應使用 PostgreSQL transaction。DataStamp 衝突或被引用回 409；格式驗證回 400；Production 不呼叫 Oracle。
