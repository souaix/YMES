# 計量品管項目_群組（QC212）

## 功能識別

| 項目 | 值 |
| --- | --- |
| FunctionNo | `QCITEM_G` |
| FunctionKey | `QC212`（目前 YMES 未啟用逐功能角色權限；依使用者決策採登入保護） |
| 選單 | 品質資料 → 品管設定 → 計量品管項目_群組 |
| Vue route | `/YMES/QC/VariableItemGroup` |
| API base path | `/YMES/API` |
| Oracle 主檔 | `MESTEST.TBLQCITEMGROUPBASIS` |

此功能管理計量品管項目群組、所屬項目、抽樣計畫、共用 Parameter/OP、計算腳本與 Memo 欄位。Web 與 API 分開部署；兩者位於同一伺服器，API 固定由 `/YMES/API` 提供。

## 功能與資料規則

- 群組清單支援 IssueState（未凍結 `0`、簽核中 `1`、已核准 `2`、未使用 `-1`）及 GroupNo 模糊查詢。API 最多回傳 2,000 筆。
- 新增群組時由伺服器設定 Creator、CreateDate、IssueState=0、DataStamp=0；群組編號忽略大小寫與前後空白檢查唯一性。編輯只允許 IssueState=0，並用 DataStamp 檢查並行更新。
- `ComponentCollect=0` 驗證一般抽樣計畫；`ComponentCollect=1` 驗證 Wafer 計畫。Wafer 來源沒有 PlanName 欄位，因此 lookup 以 PlanNo 顯示名稱。
- 明細只能修改 IssueState=0 的群組；每群組最多 1,000 筆、ShowOrder 必須從 0 連續遞增，QC Item 必須已核准且 ComponentCollect 與群組一致。移除明細時同一交易清除對應計算腳本並重排 ShowOrder。
- Copy 僅複製來源群組的明細到未凍結目標，不複製腳本；來源程式沒有群組腳本複製流程。來源與目標 ComponentCollect 必須相同。
- 刪除 IssueState=1 一律拒絕；IssueState=2 轉為 -1；IssueState=0/-1 硬刪。硬刪會在單一交易檢查 `tblwiptemp_qcitem`，並清除群組明細、計算腳本、`tblqcitemparameter`、`tblopqcitem` 的 QCItemType=2 關聯及 Memo Type=1 關聯。Memo 清理是 YMES 一致性決策；Legacy Core 不會清除 Memo。
- 核准只接受未凍結且至少一筆明細的群組。live YMES 目前沒有 Issue/Job 表，因此直接將狀態轉為 2 並更新 Reviser、ReviseDate、DataStamp；若日後出現共用簽核表，API 會回 503，避免跳過簽核流程。
- 群組 Parameter 只提供已核准且 `ParameterClass=1` 的 MES Parameter。來源 `TBLQCITEMPARAMETER` 沒有 `SpecType` 欄位，API 目前只接受 `SpecType=0`；公司端需確認原生表單中 1/2 的實際語意後，再決定 UI 對齊方式。
- 作業站對應重用 `tblopqcitem`，僅讀取已核准作業站，儲存為 `QCItemType=2`、Inline=1、依清單順序設定 ExecuteOrder。未凍結或簽核中的群組不能改作業站。
- WinSPC Form 與 QC Class lookup 目前由既有群組主檔及變數型 QC Item 的 FormName/ExecutionFile/QCClass 去重整理；沒有獨立參照表。公司端需確認原生 MES 真正的來源與篩選條件。

## API 契約

所有端點均要求登入。以下路徑相對於 `/YMES/API`；FunctionKey 權限檢查尚未實作，因目前專案尚未啟用角色／逐功能權限。

| Method | Route | 用途 |
| --- | --- | --- |
| GET | `/api/qc/item-groups?functionNo=QCITEM_G&issueState=&groupNo=` | 群組清單 |
| POST | `/api/qc/item-groups` | 新增群組 |
| PUT / DELETE | `/api/qc/item-groups/{groupNo}` | 編輯／依 IssueState 刪除或停用 |

| DELETE | `/api/qc/item-groups/{groupNo}/details/{qcItemNo}` | 移除明細 |
| POST | `/api/qc/item-groups/{sourceGroupNo}/copy-details` | 複製明細 |
| GET / PUT | `/api/qc/item-groups/{groupNo}/parameters` | 讀取／完整替換 Parameter |
