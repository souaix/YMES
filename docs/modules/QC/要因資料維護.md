## WinForms 畫面

- Form ClientSize 為 1008×591。上方參數 Grid 區域約 1008×160；下方動態資料 Grid 區域約 1008×428；底部 StatusBar 顯示 UserNo、SystemDateTime、執行狀態。
- 上方 Grid 只顯示 `ParameterNo`、`ParameterName`、`TableName`，欄寬約 100、150、150；其他 `TBLSYSMESPARAMETER` 欄位隱藏。表格唯讀，使用者先選一筆再按 `DetailData` 載入內容；只點選參數不會自動載入下方 Grid。
- 下方 Grid 由所選參數對應的資料表動態產生欄位，全部資料欄位顯示，可新增底部資料列、編輯儲存格、刪除選取資料列。無固定的新增/修改對話框、狀態篩選、搜尋欄或簽核按鈕。
- `LoadTablesConstraints` 取得欄位 metadata；`IS_NULLABLE=false` 的儲存格以黃色標示。`CreateDate` 欄位使用 `yyyy/MM/dd HH:mm:ss` 格式。每個儲存格更新後會自動轉大寫。
- 右側按鈕為 `Delete`、`Import`、`Paste`、`Save`、`Close`；上方另有 `DetailData`。Save 初始停用；有修改或刪除才啟用。
- 切換/關閉時若有未儲存資料會詢問是否放棄。Save 前詢問確認；保存成功後重新載入目前資料表。

## 參數查詢與動態資料來源

- Form 載入時呼叫 `wsSYS.LoadMesParameter`，查詢條件是 `IssueState=2`、`ParameterType=0`（Table）、`ParameterClass=1`，並加上 `TableName LIKE 'FC_%'`；回傳目錄只在前端顯示上述三欄。
- `DetailData` 以 `ParameterNo` 呼叫 `wsSYS.LoadMesParameterRef`。舊服務再從 `TBLSYSMESPARAMETER` 取得 `TableName`、`FieldName`、`Condition`，查詢該 Table 的資料、套用 Condition、依 FieldName 排序。
- `wsSYS.LoadTablesConstraints` 依服務設定的 database owner 與 TableName 取得欄位名稱、型別、長度與 nullable metadata。欄位清單與型別不可由瀏覽器自行指定。
- `TBLSYSMESPARAMETER` 是系統參數目錄；其 TableName/FieldName/Condition 屬伺服器管理的設定。Web API 必須以登入權限允許的 `ParameterNo` 查回設定，限制到已核准、Table 類別、ParameterClass=1 與允許的 `FC_%` 表，並從資料庫 metadata allowlist 驗證識別字。不得接受瀏覽器直接傳入任意 SQL、schema、table、column 或條件式。
- 本次只依 `ALL_TABLES` 的 `table_name LIKE 'FC_%'` 讀取名稱及 DDL metadata，該 schema 目前符合篩選的表為三張。這是結構盤點結果，不代表所有 MES 環境都只有三張；家用端應以 YMES 自身已核准的參數目錄與 schema 為準。

## 編輯、刪除、Save 與匯入

- Grid 的新增/編輯/刪除都只作用在前端 DataSet。`Delete` 刪除選取列但不立即呼叫資料庫；使用者再按 `Save` 才送出整份 Grid。
- `Save` 呼叫 `wsQC.UpdFactorMaintain`，帶入 `ParameterNo`、DataSet schema/data 與 `FirstData=true`。Core 依該 ParameterNo 取得 TableName/Condition，先刪除符合 Condition 的舊資料，再插入目前 Grid 的全部列。沒有 DataStamp/CAS；API 應用單一資料庫交易包住刪除與全部插入，失敗時整批 rollback，且刪除範圍必須完全套用既有 Condition，保留條件外資料。Grid 為空時代表清除 Condition 範圍內所有資料，API 應明確確認/允許此結果。
- Core 以 array binding 執行插入。舊程式依 DataColumn 型別組參數；Web API 應依資料庫欄位 metadata 做型別轉換與 nullable/長度驗證，使用參數化 SQL。
- `Import` 接受 CSV 與舊 Excel `.xls`。CSV 以欄位順序將每列追加到 Grid；Excel 第一列為欄名，依欄名對應欄位。匯入僅改前端 Grid，仍須按 Save。DEV 預覽支援 CSV 假資料；正式 API 提供 `.xls` 匯入解析/preview，不直接寫資料庫。
- `Paste` 讀剪貼簿的逗號分隔資料，從目前選取儲存格開始逐列逐欄填入；超出既有列數時新增 Grid 列。Web 版另可辨識 Excel 常見的 Tab 分隔剪貼簿格式。
- 匯入/Paste/格內變更都標記為未儲存；關閉或切換參數前提示放棄。DEV 假資料只存在瀏覽器 localStorage，正式環境不使用假資料。

## Vue DEV 頁與 API handoff

DEV 頁路徑 `/YMES/QC/FactorMaintain`，呈現 WinForms 上方參數清單、DetailData、metadata 驅動欄位 Grid、必填黃色格、新增列、刪除、Import、Paste、Save、Close 與 StatusBar。localStorage 假目錄/假資料只用於開發預覽；三個 Demo table schema 取自 Oracle DDL，假資料不包含 MES 實際記錄。

建議 API 以 FunctionKey `QC109` 保護：

- `GET /api/qc/factor-maintain/parameters`：依 MES 參數目錄的 IssueState/ParameterType/ParameterClass/TableName 條件回傳 ParameterNo、ParameterName、TableName。
- `GET /api/qc/factor-maintain/parameters/{parameterNo}/data`：服務端依 ParameterNo 解析設定，回傳欄位 metadata 與依 FieldName 排序且套用 Condition 的資料列。
- `PUT /api/qc/factor-maintain/parameters/{parameterNo}/data`：接收目前完整 Grid rows，schema/table/欄位只由伺服器目錄決定；在單一 transaction 內刪除 Condition 範圍並插入 rows，支援空清單作為清空操作，錯誤 rollback。
- `POST /api/qc/factor-maintain/parameters/{parameterNo}/import-preview`：解析 `.xls` 並回傳欄名映射後資料列，不寫資料庫。CSV 可由 Vue 本地解析，兩種匯入都先進 Grid 再由 Save 寫入。
- 驗證 ParameterNo 在允許目錄、TableName/column 在 YMES metadata allowlist、欄位集合完整、NOT NULL/長度/型別有效。查詢/刪除/插入須固定在 YMES schema；資料表名稱不得直接採用 request body。
- 保留 FieldName 排序與 Condition 資料範圍；若不能安全解譯舊 Condition SQL，改用服務端對應的固定 Predicate 設定，將每個環境差異記錄於 API 規格。
