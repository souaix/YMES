# QC402 次分類基本資料

## 功能來源

- MES 選單：品質資料 → 異常設定 → 次分類基本資料。
- 目錄資料：FunctionNo `SCLASS BASIS`、FunctionKey `QC402`、Form `frmSClassBasis`、ExecutionFile `QC_SClassBasis.dll`；資料表 `MESTEST.TBLQCSCLASSBASIS`。
- WinForms：`STD/MESWin/QC/QC_SClassBasis/frmSClassBasis.vb`、`frmSClassBasisDef.vb`。
- 獨立匯入視窗：`STD/MESWin/QC/QC_SClassDataImport/frmSClassDataImport.vb`；檢查器 `STD/MEStc/DataImporter/SClassDataImporter.cs`。
- Service：`STD/MESws_STD/wsSTD/wsQC/wsQC.cs` 的 Load/Add/Edit/Del/ApproveSClassBasis；Core：`STD/MESkc/kcQC/clsHoldBasis.cs` 的 SClass CRUD/查詢/狀態方法。
- 規則根據 WinForms、Service、Core、Importer 原始碼與公司端 Oracle 資料字典查詢結果整理。

## 主清單畫面

- WinForms `frmSClassBasis` ClientSize 為 1008×591。上方沿用共用狀態列：未簽核 0、簽核中 1、已簽核 2、不使用 -1，初始選未簽核。
- 查詢條件只有 SClassNo；主表 Service 載入所有狀態，WinForms 於本機套用狀態篩選，依 SClassNo 排序。
- Grid 顯示 SClassNo、MClassNo、Description、Creator、CreateDate、Reviser、ReviseDate；MClassNo 顯示位置緊接 SClassNo。IssueState、DataStamp 隱藏。Description 多行/寬 150；人員欄寬 80；日期欄寬 150，格式 `yyyy/MM/dd HH:mm:ss`。
- 操作按鈕為新增、修改、刪除、複製、核准；右下另有 `SClassImport` 與關閉。主清單支援多選，刪除及核准逐筆呼叫 Service；第一筆失敗即停止並重載資料。
- Vue DEV 頁 `/YMES/QC/SClassBasis` 對照四狀態、SClassNo 查詢、含 MClassNo 的主 Grid、多選、同一組操作鈕、匯入與筆數。列點選只更新 Vue 狀態，不改 URL、不重新載入頁面。標頭和輸入欄採 KD 黃色系。

## 新增、修改、複製表單

- `frmSClassBasisDef` ClientSize 為 484×312。SClassNo 區塊位於 (12,6)，尺寸 460×50；MClassNo 與說明區塊位於 (12,61)，尺寸 460×119；建立/修改資訊位於 (12,188)，尺寸 460×70。底部按鈕為確定、關閉、套用。
- SClassNo 必填、最多 30 字；MClassNo 必填、最多 30 字，但欄位唯讀，透過 `...` 搜尋選取；候選 MClass 必須已簽核。Description 可空、最多 255 字。
- 新增與複製預設 IssueState=0，建立者/時間顯示目前使用者/現在時間。複製會帶入原 SClassNo、MClassNo、Description，作為新增處理，使用者需改成新的 SClassNo。
- 修改時 SClassNo 唯讀；MClassNo 欄位本身唯讀，但旁邊查找按鈕會依 `ExeIssueControl` 權限/狀態啟用。Service/Core 接受 MClassNo 與 Description 的更新；只有 IssueState 0/2 可寫入。簽核中與不使用列以唯讀方式呈現。
- 確定儲存後關閉；套用保存後保留視窗。資料表 Create/Revise audit 與 DataStamp 由 API 依登入者/伺服器時間維護。

## 狀態及操作規則

- 刪除前顯示確認。IssueState 0、-1：實體刪除；2：保留資料列並改為 -1，更新 Reviser、ReviseDate、DataStamp；1：拒絕刪除。
- 核准只接受 IssueState=0，可多選逐筆處理。Issue Job Map 使用 `SCLASS BASIS`：找不到 Job 或沒有 Job Detail 時直接核准為 2；有簽核設定則建立 Issue、進入簽核中，核准後轉 2、退回轉回 0，並通知第一簽核群組。
- 更新與狀態異動以 SClassNo、IssueState、DataStamp 做樂觀版本檢查；Production API 衝突應回 409，不可接受前端送來的 audit 欄位。
- DEV 核准目前只演示無 Job 的 0→2 分支；正式 Issue Job/Issue/通知/退回必須由 API 串接共用簽核機制。

## Oracle DDL 與 PostgreSQL CREATE

本次使用 Windows PowerShell 5.1 + Oracle.ManagedDataAccess，從公司端既有受保護連線直接唯讀呼叫 `DBMS_METADATA.GET_DDL`，取得表與 PK index。未讀取 MES 業務列，未在 Oracle 執行 DDL；連線值沒有輸出或放入 Git。

- Oracle 原始 DDL：[`mestest_qc_s_class_basis_source_ddl.sql`](../../../database/reference/mestest_qc_s_class_basis_source_ddl.sql)。
- YMES PostgreSQL 空表 CREATE 參考：[`mestest_qc_s_class_basis_create.sql`](../../../database/reference/mestest_qc_s_class_basis_create.sql)。家用端先比對 PostgreSQL live schema/migrations，不要直接重建現有表。

| 欄位 | Oracle 型別 | Nullable / 預設 | 備註 |
| --- | --- | --- | --- |
| SClassNo | VARCHAR2(30) | NOT NULL | Primary Key |
| Description | VARCHAR2(255) | NULL | 說明 |
| Creator | VARCHAR2(10) | NULL | 建立人 |
| CreateDate | DATE | NULL | 建立時間 |
| IssueState | NUMBER(1,0) | NOT NULL DEFAULT 0 | 簽核狀態 |
| MClassNo | VARCHAR2(30) | NULL | UI/API 要求已簽核主分類；Oracle 沒有 FK |
| DataStamp | NUMBER(11,0) | NULL DEFAULT 0 | 版本欄位 |
| Reviser | VARCHAR2(10) | NULL | 修改人 |
| ReviseDate | DATE | NULL | 修改時間 |

Oracle 只有 `PK_TBLQCSCLASSBASIS` 對應 SClassNo 的 unique index，沒有 FK、額外 index 或 check constraint。PostgreSQL 空表 SQL 保留 DataStamp nullable DEFAULT 0；MClassNo 不可自行加 FK，避免改變來源 schema。UI/API 必須驗證 MClassNo 存在且 IssueState=2。

## 次分類資料匯入

- 主清單用 ObjectFileHandler 開啟 `QC_SClassDataImport`。匯入 UI/檢查器為 `frmSClassDataImport` 與 `SClassDataImporter.SClassDataChecker`。
- 支援 `.xls`、`.xlsx`，讀第一個工作表；略過第一列，不驗證標題文字。第 1 欄 SClassNo 必填、第 2 欄 MClassNo 必填、第 3 欄 Description 可空；第 4 欄起不讀。公式會求值，數值/日期轉成字串。缺少任一必填 cell 時 Excel 解析即失敗。
- 選檔預覽以 `(SClassNo, MClassNo)` distinct，結果 Grid 顯示 SClassNo、MClassNo、Description、Message。實際匯入會把原始資料依 SClassNo 分組；每組資料超過一列時整組回報 duplicate data，因此相同 SClassNo 即使 MClassNo/Description 相同也可能在 preview 摺疊、匯入時失敗。不同 SClassNo 各自執行，可部分成功。
- Checker 以大小寫不敏感方式拒絕已存在 SClassNo；MClassNo 必須存在且 IssueState=2。成功新增時 SClassNo/MClassNo 轉大寫、IssueState=0、Creator 使用登入者、Description 空白時由 Core 略過欄位寫入。每筆 SClassNo 回傳 Message；可取消後續列，完成後若有成功列則重載主畫面。
- 範本副檔名透過 `wsSYS.funLoadFileExtension`，範本二進位透過 `wsSYS.GetTemplateFile`，FunctionNo 為 `SCLASS BASIS`；範本更新按鈕隱藏。來源樹沒有找到範本 binary，Production 需遷移 SYS template storage。DEV 下載 CSV 只供假資料操作，不能當作官方 Excel 範本。

## Vue API 契約與家用端交接

- `GET /api/qc/s-class-basis?searchFieldName=SClassNo&searchFieldValue=`：查全部狀態，僅接受 SClassNo 搜尋；回傳主鍵、MClassNo、Description、IssueState、DataStamp 與 audit 欄位。
- `GET /api/qc/s-class-basis/m-class-options`：依 QC402 權限回傳 IssueState=2 的 MClassNo/Description lookup，避免呼叫者必須另外擁有 QC401 權限；不要新增 lookup table。此靜態子路由需先於 `/{sClassNo}` 路由解析。
- `POST /api/qc/s-class-basis` body `{ sClassNo, mClassNo, description }`：兩編號必填/最多 30 字；Description 最多 255 字；SClassNo 大小寫不敏感唯一；MClassNo 必須存在且已簽核。伺服器設定 Creator/CreateDate、IssueState=0。
- `PUT /api/qc/s-class-basis/{sClassNo}?issueState=&dataStamp=` body `{ mClassNo, description }`：SClassNo 唯讀；只允許 IssueState 0/2；MClassNo 必須是已簽核主分類；更新 Reviser/ReviseDate/DataStamp，使用 CAS。
- `DELETE /api/qc/s-class-basis/{sClassNo}?issueState=&dataStamp=`：0/-1 實體刪除、2 改為 -1 並更新 audit/DataStamp、1 拒絕。
- `POST /api/qc/s-class-basis/{sClassNo}/approve?issueState=0&dataStamp=`：依 `SCLASS BASIS` Issue Job 規則直接核准或啟動簽核，回傳真實 IssueState/DataStamp。
- `POST /api/qc/s-class-basis/import/preview` 及 `/import` 接受 `.xls/.xlsx` multipart file；第一 sheet/前三欄解析、distinct preview、按 SClassNo 分組並拒絕多列組、驗已核准 MClass、每組交易與逐組部分成功結果必須依來源碼實作。支援取消後續處理。
- `GET /api/qc/s-class-basis/import/template` 讀取 YMES template storage 中 `SCLASS BASIS` 原始範本及副檔名。
- 全部端點要求登入與 FunctionKey `QC402` 權限；使用參數化 SQL、檔案大小/格式限制與 DataStamp CAS。API 不能接受前端指定 Creator、CreateDate、Reviser、ReviseDate、IssueState。

DEV 頁元件為 `web/src/components/QcSClassBasisMaster.vue`，localStorage key `ymes-dev-mock:qc-s-class-basis:v1`。Production 頁不使用 localStorage。此段沒有新增 YMES API/Database migration；家用端需先核對現況再建立缺漏 migration/API。
