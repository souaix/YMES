# IV211 退料單記錄（Material Return Log）

- FunctionKey：`IV211`；FunctionNo：`MATERIAL RETURN LOG`；表單：`frmINVMaterialReturnLog`；分類：原物料倉。
- Vue DEV 頁：`/YMES/INV/MaterialReturnLog`，功能鍵 `function:INV:MATERIAL RETURN LOG`。
- 範圍：唯讀查詢 Material Return Basis、Detail 及可用時的元件子列；本功能不確認退料、不改庫存。

- Service：`D:\iMES\CSiMES\STD\MESws_STD\wsSTD\wsINV\wsINV.cs` 的 `LoadINVMaterialReturnBasis` 與 `LoadINVMaterialReturnDetail`。

- IV206 單據確認來源：`D:\iMES\CSiMES\STD\MESWin\INV\IV_RawInventory\frmINVMaterialReturnConfirm.vb`、`wsINV`／`clsInventory.ExeMaterialReturn`；退料日存於 Basis `ReturnDate`。

## 原程式查詢與結果

Form 開啟只初始化 State ValueList 與條件值，沒有自動查詢。CreateDate 與 MaterialReturnDate 的起迄預設最近 14 天至今天，但八個條件核取方塊預設都未勾，因此日期值不會自動套用。查詢條件為單號、庫房、Vendor、State、From／End CreateDate、From／End MaterialReturnDate；單號／庫房／Vendor 使用查找視窗。每個條件須勾選後才會加入 Service request。表單沒有「至少一條件」檢查，無條件可能查回整張 Basis；Core 無分頁、上限或 `ORDER BY`。

State ValueList 來源為 `TBLINVMATERIALRETURNBASIS.STATE`，State 0／1／2／3 分別是 UnConfirm／Handling／Confirm／Failed。Service 將 Form 的 `SelectedIndex` 作為 State 傳入。CreateDate 與 ReturnDate 篩選由 Core 執行；From 起日自當日開始，End 欄位若只傳日期，Core 會延伸到當日 23:59:59。

Form 直接查 `wsINV.LoadINVMaterialReturnBasis`。Core 讀單頭 `TBLINVMATERIALRETURNBASIS` 的所有欄位，Form 將資料欄 `ReturnDate` 改名為 `ConfirmDate` 顯示；**ReturnDate 是單頭確認日期，不是 `TBLINVTRANSACTIONLOG` 的 CreateDate，也不是獨立的交易日查詢**。主 Grid 可見欄為 `MaterialReturnNo`、`InventoryNo`、`VendorNo`、`State`、`ConfirmDate`、`Description`、`Creator`、`CreateDate`；其餘欄位隱藏。`Query` 將結果載入 Basis Grid，選取／啟用單頭列後，`AfterRowActivate` 才用該 MaterialReturnNo 載入明細；Close 關閉頁面。

Detail Grid 可見欄為 `MaterialNo`、`MaterialLotNo`、`LocatorNo`、`UnitNo`、`Qty`；Qty 顯示最多 8 位小數（舊註解寫 6 位）。若系統 `ActiveModule` 含 `BASE`，Core 另查 `TBLINVMATERIALRETURNCOMPONENT`，用 DataRelation 展開 `ComponentNo`、`DEV_CassetteNo`、`DEV_SlotNo`；否則不回元件子列。Relation 只以 MaterialNo＋MaterialLotNo 關聯，不含 LocatorNo，重複料號／批號但不同 Locator 時可能將元件列重複關聯至多個 Detail。

## Service／Core 行為與限制

- Basis request 將可選條件解析後傳給 Core；SQL 以字串串接，沒有條件數、日期跨度或輸出列數上限，且無穩定排序。正式 API 必須參數化、限制查詢範圍，回傳有上限分頁與穩定排序。
- Detail Service 接受 MaterialReturnNo，但舊 Core 僅在參數非空時加入父單篩選；空字串會回傳整張 `TBLINVMATERIALRETURNDETAIL`。正式 Detail／Component API 必須要求有效單號；無效或缺少單號回空／拒絕，不得放大成全表。
- Component 子查詢僅在 `ActiveModule='BASE'` 時執行；正式 API 應明確確認產品是否要提供此子資料，並以可信完整鍵關聯，避免只用 MaterialNo＋LotNo 導致重複。
- 舊 Core SELECT `*` 不能作為正式 DTO 欄位依據；回傳欄位依 Form 可見欄及上方 Component 欄投影。

## Vue DEV 頁

- `web/src/components/InvMaterialReturnLog.vue` 是唯讀 DEV fallback；只有 Vite DEV 且 `developmentPreview=true` 時載入 `InvMaterialReturnLogDevPreview.vue`。
- Form 開啟時不查詢。頁面有八個獨立核取條件、單號輸入、庫房／Vendor 假 lookup、State 0–3、CreateDate／ReturnDate 起迄日期；日期預設 14 天至今天但不勾選。按 Query 後載入假 Basis，選列載入該單假 Detail，點元件展開按鈕看 ComponentNo／Cassette／Slot。
- DEV 使用固定 fixtures，不呼叫正式 API。為避免舊 Core 空單號全表回傳風險，Detail 始終限於有效選取單號；沒有主檔選取時顯示空明細。DEV 結果不模擬 Core 的無排序／無上限危險，會提示其為小型假資料。
- DEV 為了方便看元件，固定 fixture 可展開 Component 子列；舊 Core 只有 ActiveModule 含 BASE 才提供，需家用端確認正式頁要不要顯示。頁面沒有 CRUD、Confirm、Print 或庫存副作用。

## 資料表、DDL 與 Oracle 查證

直接讀取 `TBLINVMATERIALRETURNBASIS`、`TBLINVMATERIALRETURNDETAIL`，以及 `BASE` 模式下的 `TBLINVMATERIALRETURNCOMPONENT`。Repo 沒有這些 Return 專用表可核實的 Oracle source DDL／metadata／PostgreSQL CREATE-only；公司桌機指定受保護 Oracle profile 不存在，本輪未使用 PowerShell 5.1／ODP.NET 查 MESTEST、未讀業務列、未猜 CREATE SQL。`ReturnDate` 的寫入在 IV201 Return Confirm，不需要從 TransactionLog 推導欄位。

## 家用端 API／schema handoff

- 先 pull 最新 `main`，核對 Basis／Detail／Component 的 PostgreSQL live schema 與 migration。Basis、Detail 無可信 DDL／metadata；缺結構時先取得可信來源，不從 Core `SELECT *` 推測型別、nullable、default、PK／FK／index／trigger。
- 提供登入及 `MATERIAL RETURN LOG` Function ACL 保護的唯讀 Basis 查詢；參數化 MaterialReturnNo／InventoryNo／VendorNo／State、CreateDate 與 ReturnDate 日期條件，限定日期跨度及最大列數，穩定排序／分頁。若允許無條件查詢，也必須以 server-side page size 限制回傳量。
- Basis Return Date 直接投影 `TBLINVMATERIALRETURNBASIS.ReturnDate`，前端可映射為 ConfirmDate；不可誤用 TransactionLog `CreateDate` 替代。日期迄日要包含當日末端時間。
- Detail endpoint 強制一個有效 MaterialReturnNo，無效單號回空陣列；永不把空字串送入會回全表的舊 Core 條件。依 Form 可見欄投影 MaterialNo／MaterialLotNo／LocatorNo／UnitNo／Qty。先確認是否包含 Component 子列及 `BASE` feature 語意；若包含，限制同父單，並核實 Component 真實鍵和父子關聯，不直接照搬只 join MaterialNo＋LotNo 的舊 relation。
- IV211 是唯讀功能；IV206 草稿維護與 IV201 Source=3 退料確認分開處理。不要讓查詢端改寫 ReturnDate／State 或扣帳。

## 本輪限制

本輪未執行 Vue build、測試或瀏覽器操作。Return Basis／Detail／Component 缺可信 Oracle DDL／metadata；受保護 profile 不存在，未猜 DDL。這些資料庫查證工作交由家用端取得可信結構後處理。
