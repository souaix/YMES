# IV301 在製品庫庫房資料

更新日期：2026-11-25。公司端完成 WinForms／Service／Core 核對、Vue 3 DEV 假資料查詢與家用端 API／schema handoff；未連 YMES PostgreSQL，未實作正式 API。

## 功能與入口

- MESTEST 選單 FunctionNo／功能代碼：`WIP INVENTORY`／IV301；Form `frmINVWIPInventory`，執行檔 `IV_WIPInventory.dll`。
- Vue DEV fallback FunctionKey：`function:INV:WIP INVENTORY`，路由 `/YMES/INV/WipInventory`，位於庫存管理／在製品庫。
- 此頁是 InventoryType=6 的在製品庫存查詢；不是生產批數量調整（WP907），也沒有修改或過帳操作。

## 舊畫面與查詢行為

- Form Load 先初始化 Grid、日期設為最近一週起日 00:00:00 至當日 23:59:59，再載入系統 Bin、已發行的 WIP Inventory Basis（InventoryType=6、IssueState=2）及客製設定；不會自動 Query。
- InventoryNo 是必要條件。LotNo Checkbox／輸入框提供前綴查詢，文字非空會勾選；清除文字會取消勾選。INVDate Checkbox 控制是否傳起訖日期；未勾選時即使日期控制項顯示預設週區間也不套用。
- Query 呼叫 `wsINV.LoadWIPInventory_All(InventoryNo, LotNo?, StartINVDate?, EndINVDate?)`。Core 僅在起訖兩端都不是預設日期時套用 `A.InputDate >= start AND A.InputDate <= end`，四組庫存查詢共用日期條件。
- Core 回傳 `WIPInventory_Raw`、`WIPInventory_SEMI`、`WIPInventory_Comp`、`WIPInventory_Bin` 四表；Form 依 Raw 的 MaterialNo／MaterialLotNo／LocatorNo、三組 SEMI 的 ProductNo／LotNo／LocatorNo 排序後各自繫結。
- RAW：讀 `TBLINVWIPINVENTORY_RAW`，依 InventoryNo、可選 MaterialLotNo 前綴及 InputDate 篩選；左連 IssueState=2 的 Material Basis 取 MaterialName。
- SEMI Lot：讀 `TBLINVWIPINVENTORY_SEMI`，限 Qty>0、BookingFlag=0、指定 InventoryNo；排除存在於 `TBLWIPCOMPONENTSTATE` 及 `TBLWIPGOODBINSTATE` 的 LotNo。左連 Lot Basis／Lot State（State 僅 11、99），內連 Product Basis（ProductNo + ProductVersion）。
- SEMI Component：同一 SEMI 庫存表，限 Qty>0、BookingFlag=0，且 LotNo 存在於 `TBLWIPCOMPONENTSTATE`；本 SQL 沒有排除同時存在 GoodBin 的 Lot。
- SEMI Bin：同一 SEMI 庫存表，限 Qty>0、BookingFlag=0，且 LotNo 存在於 `TBLWIPGOODBINSTATE`；本 SQL 沒有排除同時存在 Component 的 Lot。
- Component Tab 上方選列後呼叫 `LoadInventory_Component(InventoryNo, LotNo)`；Detail 顯示 ComponentNo、GoodQty、ScrapQty、UnitNo。Bin Tab 上方選列後呼叫 `LoadGoodBinState(LotNo)`；Grid 依系統 Bin 定義呈現 Lot 的 GoodBin State。
- 四個主結果集合沒有明確 SQL ORDER BY；Form 再以 DataView.Sort 排序。Lot 前綴直接串入 `LIKE '<prefix>%'`；InventoryNo／LotNo／日期 SQL 皆非參數化。

## Vue DEV 復刻

- App 選單加入 `function:INV:WIP INVENTORY`，路由 `/YMES/INV/WipInventory`。
- 查詢面板提供必選 InventoryNo、可選 LotNo 前綴及 INVDate 區間。日期控制項預設最近一週但 Checkbox 預設未勾；未勾選不套日期。按 Query 才套用條件並顯示結果；Clear 清除結果並還原表單初始值。
- 四個 Tab 分別呈現 RAW、SEMI Lot、SEMI Component、SEMI Bin；Component 與 Bin 保留上表選列、下表明細的主從互動。假資料包含兩個庫房、不同產品／批號／儲位及 InputDate。
- DEV 只用虛構 fixture，查詢與明細留在本頁記憶體，不呼叫正式 API、不修改庫存。頁面為查詢用表格，未實作列印、編輯、匯出或實際 System Bin 動態欄位設定；DEV 未 build、test 或 browser 驗收。

## 資料表、DDL 與家用端 handoff

| 表 | 用途 | 原生 Oracle reference |
|---|---|---|
| `TBLINVWIPINVENTORY_RAW`、`TBLINVWIPINVENTORY_SEMI` | RAW／SEMI 庫存 | WP201 `mestest_wip_wp201_dependency_source_ddl.sql`、`mestest_wip_wp201_create.sql` |
| `TBLWIPLOTBASIS`、`TBLWIPLOTSTATE`、`TBLWIPCOMPONENTSTATE` | Lot 與 Component State | WP101 `mestest_wip_wp101_source_ddl.sql`／`mestest_wip_wp101_create.sql` |
| `TBLWIPGOODBINSTATE` | GoodBin State | QC409 `mestest_qc409_wip_disposition_dependencies_source_ddl.sql` |
| `TBLMTLMATERIALBASIS` | RAW MaterialName | `mestest_mtl_master_source_ddl.sql`／`mestest_mtl_master_create.sql` |
| `TBLPRDPRODUCTBASIS` | SEMI ProductName／Version join | `mestest_prd_product_basis_source_ddl.sql`／`mestest_prd_product_basis_create.sql` |
| `TBLINVINVENTORYBASIS`、`TBLSYSBIN` | 庫房及系統 Bin Lookup | 本 repo 未找到可確認同版的專用 source DDL／metadata |

除兩張 Lookup 表外，Core 查詢依賴表已有其他功能的 DDL references，不為 IV301 重複建立 CREATE SQL。桌機受保護 Oracle profile 在本接手環境不存在，本輪未連 MESTEST；`TBLINVINVENTORYBASIS`、`TBLSYSBIN` 的 DDL／metadata 因而待補，不推測欄位或產生 CREATE。家用端先核對 YMES PostgreSQL live schema／migration 與既有 references，不可把 CREATE-only 當 migration 直接執行。

- Inventory Lookup API 要限制 `InventoryType=6 AND IssueState=2`；頁面 Query API 必須要求有效 InventoryNo，限制日期跨度／最大筆數並採穩定排序及 bounded paging。
- 使用參數化的 InventoryNo、LotNo 前綴、InputDate 起訖條件；明確定義日期區間端點，避免舊 Core 只有兩端都傳才生效的隱性規則。
- Query API 可回四類庫存集合，或拆成可分頁的四個端點；不得用單一大回應無界載入所有資料。Component Detail 必須要求 InventoryNo + LotNo，並依 live schema 的完整庫存鍵／Lot 關係查詢。
- GoodBin Detail 舊查詢僅用 LotNo，沒有傳 InventoryNo；若 LotNo 可跨庫房重複，會有越界或重複資料風險。正式 API 應以庫房及 live schema 可證明的 Lot／Inventory 關係限定範圍。
- 三種 SEMI 分組查詢的 Component／GoodBin 判斷集合可能重疊；舊 Core 沒有要求互斥。先按來源保留重疊，再核對實際資料模型與業務預期；不要自行把一類排除另一類。
- 舊 SQL 字串串接存在注入風險；父子查詢必須用參數並在 server 驗證使用者對 InventoryNo 的 Function ACL／資料範圍。
