# 設備狀態監控_區域（SMD SD108）

## 功能來源

- MES FunctionNo：PRODUCTION CONFIG；模組：SMD；FunctionKey：SD108。
- WinForms：STD/MESWin/SMD/SD_AreaShow/frmAreaShow.vb。
- 班別子視窗：frmAreaShift.vb、frmAreaShiftDef.vb。
- 核心規則：STD/MESkc/kcSMD/clsSMDBasis.cs 的 AreaShift、AreaOperator 與 ChkAreaShiftLoginState；WIP 狀態/歷史由 WP_AreaOperatorState、WP_AreaOperatorLog 表單提供。
- WinForms 視窗 ClientSize 1008×591；以 Lassalle AddFlow 顯示 Base Area 的關聯圖。Vue 初版不重建 AddFlow 編輯能力，僅顯示、縮放、網格切換與開啟區域功能。

## 主畫面

1. 按 Base Area 的「...」後呼叫 LoadBaseArea，使用共用搜尋窗選 AreaNo；選取不同區域時清除舊節點，再呼叫 LoadAreaRelationDefine。
2. 節點取自 TBLSMDAREARELATION。ObjectX/ObjectY 是座標；AddFlow Node 尺寸依序使用 ObjectWidth、ObjectLength；ObjectText 顯示名稱，ObjectNo 作為節點代碼，ObjectColor 為填色。
3. ObjectType 對應圖形：0 區域矩形、1 庫房六角形、2 設備橢圓、3 設備類別圓角矩形、4 設備群組圓角矩形。區域標籤靠上置中。
4. 工具列縮放值為 100%、150%、75%、50%；網格按鈕切換格線。
5. 在 Type 0 區域節點雙擊開啟班別設定。WinForms 的右鍵功能只在企業別 IMESTECH 顯示，包含班別設定、目前狀態與歷史紀錄；Web 版以登入權限控管這三個入口。
6. 關閉回三層選單。底圖原先由 ResourcePath/AreaNo.bmp 載入；Vue 首版未搬移用戶端本機 BMP。

## 班別設定 frmAreaShift

- 視窗 ClientSize 1008×591。AreaNo、DepartmentNo 唯讀；DepartmentNo 由 TBLSMDAREABASIS 取得。
- 上方 Grid 依 AreaNo、DepartmentNo 載入 TBLSMDAREASHIFT，顯示班別、管理者、異常時間、說明及建立/修改稽核欄位；支援多選。
- 右側按鈕：新增、修改、複製、刪除。新增/修改/複製均開 frmAreaShiftDef；複製使用新 ShiftNo 並複製原班別人員。
- 下方左側為已核准且屬於該部門的可選人員，右側為目前班別人員。右移加入、左移移除；「確定」以目前班別 DataStamp 和完整成員集合呼叫 UpdAreaOperator。
- Grid 切換班別時重載該 ShiftNo 的 TBLSMDAREAOPERATOR 明細與人員清單。
- 刪除可多選，依序刪除；每筆由 Service transaction 同時刪除 operator 明細與 shift 主檔。出錯即停止其餘刪除。
- 新增、修改、刪除與成員變更需檢查 ChkAreaShiftLoginState：找出該班別人員，若任一人在 tblWIPAreaOperatorState 有登入紀錄則拒絕變更。

## 班別定義 frmAreaShiftDef

- 視窗 ClientSize 492×326、固定視窗。欄位：AreaNo、DepartmentNo（唯讀）、ShiftNo（依部門班別清單選取）、ManagerNo（人員選取）、ExceptionTime（整數 0–9999）、Description（最多 255）。
- Add、Copy 由使用者選新 ShiftNo；Edit 不允許更換 ShiftNo。管理者、班別與 Area/Department 欄位來源要由 API 選項提供。
- 確定寫入並關閉；套用寫入後留在表單；關閉不寫入。Audit 欄位唯讀。

## Oracle 結構與 PostgreSQL 建表

Oracle DDL 由 Windows PowerShell 5.1 + Oracle.ManagedDataAccess 直接唯讀查 MESTEST 資料字典取得，沒有查業務資料或執行 DDL。

- TBLSMDAREASHIFT：PK (AreaNo, DepartmentNo, ShiftNo)；DataStamp DEFAULT 0 可為 NULL。
- TBLSMDAREAOPERATOR：PK (AreaNo, DepartmentNo, ShiftNo, UserNo)；沒有 DataStamp。
- 兩表沒有 FK 或 PK 以外索引。Oracle DATE 對應 PostgreSQL timestamp without time zone。
- 完整欄位與空表 PostgreSQL CREATE SQL：database/reference/mestest_smd_area_shift_source_ddl.sql、mestest_smd_area_shift_create.sql。

## DEV 假資料

僅 import.meta.env.DEV 且 developmentPreview=true 時用獨立 localStorage。可切換 Base Area、繪製五種節點、縮放/網格、右鍵/雙擊區域、班別 CRUD/複製/多選刪除、人員加入/移除、目前狀態與歷史預覽。Production 僅呼叫 API；不得回退 localStorage。

## Production API handoff（家用電腦）

所有 SMD/WIP API 驗證登入者與對應權限；使用參數化 SQL。先檢查 YMES 現況，依 Oracle reference 建 forward migration，只建立空結構，不匯入 MES 資料。

| 方法 | 路徑 | 規則 |
|---|---|---|
| GET | /api/smd/areas?issueState=2&areaClass=1 | Base Area 選擇器；僅列已核准的基底區域。 |
| GET | /api/smd/areas/{areaNo}/layout | 回傳 relations 與 backgroundImageDataUrl；沿用 SD104 layout DTO。 |
| GET | /api/smd/areas/{areaNo}/shift-context | 回傳 areaNo、areaName、departmentNo，供區域節點班別設定使用。 |
| GET | /api/smd/areas/{areaNo}/shifts?departmentNo= | 列該區域/部門班別，排序 ShiftNo。 |
| GET | /api/smd/areas/{areaNo}/shifts/options?departmentNo= | 回傳該部門可選 ShiftNo、已核准管理者與可加入人員。人員限 IssueState=2 及相同 DepartmentNo。 |
| POST | /api/smd/areas/{areaNo}/shifts | 新增班別；驗證 Area/Department、班別、人員，伺服器產生 Creator/CreateDate/DataStamp=0。 |
| PUT | /api/smd/areas/{areaNo}/shifts/{departmentNo}/{shiftNo}?dataStamp= | 修改 ManagerNo、ExceptionTime、Description；先執行登入人員檢查，CAS 更新並遞增 DataStamp。DataStamp 為 NULL 時以 `dataStamp=0&dataStampIsNull=true` 傳送並以 `IS NULL` 比對；否則依實際數值比對。 |
| POST | /api/smd/areas/{areaNo}/shifts/{departmentNo}/{shiftNo}/copy | 新 ShiftNo 建主檔並複製來源班別全部 Operator；transaction 內做唯一鍵/登入狀態檢查。 |
| DELETE | /api/smd/areas/{areaNo}/shifts/{departmentNo}/{shiftNo}?dataStamp= | 驗證未登入，transaction 先刪 operator 再刪 shift；DataStamp 為 NULL 時以 `dataStamp=0&dataStampIsNull=true` 傳送並以 `IS NULL` 比對；衝突回 409。 |
| GET | /api/smd/areas/{areaNo}/shifts/{departmentNo}/{shiftNo}/operators | 回 assigned 與 available，人員需含 UserNo/姓名。 |
| PUT | /api/smd/areas/{areaNo}/shifts/{departmentNo}/{shiftNo}/operators?dataStamp= | 以一個 transaction 驗證完整集合、CAS 班別 DataStamp（NULL 版本以 `dataStampIsNull=true` 表示並用 `IS NULL` 比對）、阻止在站人員被移除，再同步 operator rows 並遞增主檔 DataStamp。 |
| GET | /api/wip/areas/{areaNo}/operator-state | 現場即時作業人員，依舊 WP_AreaOperatorState。 |
| GET | /api/wip/areas/{areaNo}/operator-log | 現場歷史，依舊 WP_AreaOperatorLog。 |

特別注意：SD104 layout API 目前仍待家用端完成；SD108 的配置圖要等該 API 可用。狀態/歷史屬 WIP 查詢功能，可沿用既有 WIP API，禁止把開發假資料當正式狀態。
