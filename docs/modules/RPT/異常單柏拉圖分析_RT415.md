## WinForms 查詢條件與互動

- 預設 `From HoldTime` 為本月 1 日 00:00，`To HoldTime` 為目前時間；只檢查起始時間不得晚於結束時間。查詢條件另有 CustomerNo、OPNo、ProductNo、MONo、EquipmentNo 五種可選多筆條件，使用標準多選查找窗；未指定傳 `*`。
- 查詢呼叫 `wsRPT.LoadERFParetoHoldReason`，Service 接受 `CreateDateFrom`、`CreateDateTo`、`CustomerNo`、`OPNo`、`ProductNo`、`MONo`、`EquipmentNo`。
- Core 合併兩類 `ERFSource=0` 資料：一般單 `ERFType<>6`，批次單 `ERFType=6`。兩支查詢均連接 HoldReason 與 QC HoldItem 取得名稱；一般單由 LotBasis 取得工單／產品、由 `TBLWIPCONT_EQUIPMENT` 取得設備。批次單由 `TBLWIPERFBATCHLOT` 與 LotBasis 彙整批號／工單／產品，並依 `LogGroupSerial` 彙整設備。
- 日期起點使用 `CreateDate >= from`；若結束值正好是日期午夜，Core 轉成 `< 次日 00:00`，否則用 `<= 指定時間`。Customer／Product／MO／Equipment 的批次查詢改由關聯批號篩選；OP 依 Core 的 `A.OPNo` 條件處理。批次設備條件透過批次單的 `LogGroupSerial` 連設備歷程。
- 結果依 HoldItemNo 加總 Qty；每原因的 LotNum 依回傳 LotNoList 項數計算，來源刻意保留重複批號。總覽顯示全部結果總 HoldQty／LotNum。圖表按 HoldQty 遞減，Bar Number 為空或 0 顯示全部；輸入前 N 時，個別百分比及累積 Pareto 線的分母是目前顯示的 Top N HoldQty 總和。
- 點擊圖表 Bar 可多選原因並顯示 HoldItemNo／名稱／Qty／LotNum／批號清單。魚骨圖按 CustomerNo、OPNo、ProductNo、MONo、EquipmentNo 五個要因分類，每一要因列出 Qty 前五名；沒有選取原因時分析全部原因。結果頁另有重繪、儲存圖檔及重新查詢條件操作。

## Service／Core 與資料表 references

- 查詢唯讀使用 `TBLWIPERFBASIS`、`TBLWIPERFHOLDREASON`、`TBLWIPERFBATCHLOT`、`TBLWIPLOTBASIS`、`TBLQCHOLDITEMBASIS`、`TBLWIPCONT_EQUIPMENT`。原 Core 以字串串接日期及多選值，Oracle 分支使用 `IMES_WM_CONCAT` 彙整欄位；正式 API 必須改用型別化日期與參數化清單，並設定期間及回傳量上限。
- Oracle source DDL 與 PostgreSQL CREATE-only references 均已在 repo，可沿用，不需新查 Oracle或另造 DDL：

## 公司端 Vue DEV 與家用端 API handoff

- DEV 查詢頁以本機假資料示範日期範圍、五種可搜尋多選、一般／批次異常資料、無條件萬用、起訖驗證及空結果。結果頁提供 HoldQty Pareto 長條、累積線、Top-N 重繪、單／多原因選取、批號明細與五因子 Top-5 魚骨摘要。
- Web 以單頁查詢與結果區取代 WinForms 的三個視窗；多選使用瀏覽器 modal。圖表改用 SVG，Save Graph 輸出 SVG 檔；未復刻舊畫面的列印與 JPG／BMP／GIF 截圖格式。DEV fishbone 用五類要因卡片表示分支及 Top-5 值，未重做 Lassalle Flow 的節點拖曳佈局。
- 建議家用端提供登入／RPT FunctionKey 權限保護的唯讀 `GET /api/reports/erf-pareto`，參數含 `createDateFrom`、`createDateTo`、`customerNos[]`、`opNos[]`、`productNos[]`、`moNos[]`、`equipmentNos[]` 及 `top`。伺服器須沿用 `ERFSource=0`、一般／批次單分支及來源 join 語意；批次多選不得以單一前端字串拼 SQL。
- API 回傳異常原因識別／名稱、HoldQty、LotNum、LotNoList、五個要因值與查詢條件。依來源口徑保留重複 LotNo 計數，並明確界定 Top-N 百分比分母。連結資料庫前，家用端仍需核對 live schema、索引及權限；不得在公司端連 PostgreSQL 或產生業務資料。
- 本桌機已核對 Form／Service／Core，使用 repo DDL references；未新查 Oracle、未讀業務資料、未連 YMES PostgreSQL、未實作正式 API/schema、未 build／test／browser。
