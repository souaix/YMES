# RT605 工單耗用資源檢視

## 功能與入口

- Menu FunctionNo `MO RESOURCE QUERY`、FunctionKey `RT605`、Form `frmResourceQuery_byMO`，模組 RPT「報表管理」。Vue DEV 入口：`/YMES/RPT/MoResourceQuery`。
- 依 Customer、Product＋Version、RO 或 MO 篩選批次，檢視勞務、設備、外包及物料的耗用、標準值、投入量與單位。四組條件可 AND 組合；至少勾一組且必須有有效值，避免無條件全查。
- DEV 假資料含 Customer／Product lookup、RO／MO 輸入、四條件組合、排序與依 MO／OrgLotNo／LotNo 顯示分組。資料僅在本機記憶體處理。

## WinForms、Service、Core

- Form 與 Designer 內嵌於 `D:\iMES\CSiMES\STD\MESWin\RPT\RT_ResourceQuery_byMO\frmResourceQuery_byMO.vb`。Customer、Product 由查詢窗選取且唯讀；RO／MO 可輸入、離開欄位轉大寫。MO 選取按鈕在 Designer 隱藏。取消條件會清空對應值；文字輸入會自動勾選 RO／MO。查詢需至少一個核取條件，空條件值會再被拒絕。
- Customer lookup 呼叫 `wsENT.LoadCustomerBasis`，要求 `IssueState=2`；Product lookup 呼叫 `wsPRD.LoadProduct`，要求 `IssueState=2` 與 `CurVersion=defInteger`；MO lookup資料呼叫 `wsWIP.LoadMOBasis` 並限 `MOState=3`，但 UI picker 隱藏。查詢 Service 為 `wsWIP.LoadSumOfResource_Valid_ByMO`，參數 `CustomerNo`、`ProductNo`、`ProductVersion`、`RONo`、`MONo` 及 `ReportMode=True`。
- Core 為 `D:\iMES\CSiMES\STD\MESkc\kcWIP\clsLot.cs` 的 `SHR_CalculateResource_Valid_MO`，ReportMode 使用 report connection。先由 `TBLWIPLotBasis` JOIN `TBLWIPLotState`，限定 `Status <> 99`，再將五個非空條件以等號 AND 套用。舊 Core 將條件直接串接 SQL；沒有分頁或期間上限。
- Core 遞迴展開 Split／Merge 批次歷程，計算 `TBLWIPCONT_RESOURCE` 與 `TBLWIPLOTLOG_REPORT`／`TBLWIPCONT_MATERIAL`／`TBLWIPCONT_MATERIALLOT` 耗用，並合併 `TBLWIPSUM_RESOURCE`／`TBLWIPSUM_MATERIAL` 已結批摘要。結果依 `(MONo, OrgLotNo, LotNo, RESClass, RESType, UnitNo)` 合併；`RESClass` 0/1/2/3 對應 Core 的 labor/equipment/outsourcing/material，Form value list 顯示 EMP/EQP/OS/MTL。來源在物料列建立結果時未設定 `InputQty`，因此其 DataTable 預設值為 0；DEV 假資料照此呈現。
- Grid 僅顯示 9 欄：`MONo`、`OrgLotNo`、`LotNo`、`RESClass`、`RESType`、`RESValue`、`StdValue`、`InputQty`、`UnitNo`。初始依 MONo／OrgLotNo／LotNo 分組並全部展開；數量欄靠右，最多顯示 8 位小數。DEV 保留排序及分組列。
