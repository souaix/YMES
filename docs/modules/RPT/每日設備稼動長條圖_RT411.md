# RT411 每日設備稼動長條圖

## 功能與入口

- 清冊項目：`EQP DAILY UTILIZATION CHART`，顯示名稱「每日設備稼動長條圖」，分類 RPT／在製品，Function No `RT411`。
- Vue DEV 入口：`/YMES/RPT/EqpDailyUtilizationChart`。固定設備、狀態片段與原因只用於 UI／查詢流程模擬，不呼叫正式 API、Oracle 或 PostgreSQL。
- 唯讀報表；主設備查詢與子設備查詢分別使用 `LoadEQPRealTimeReport`、`LoadEQPRealTimeReport_Chamber`。

## WinForms、Service、Core

- 主 Form：`D:\iMES\CSiMES\STD\MESWin\RPT\RT_EQPDailyUtilizationChart\frmEQPDailyUtilizationChart.vb`，Designer 為同資料夾 `frmEQPDailyUtilizationChart.Designer.vb`。載入設備狀態、主設備、ChamberManage 系統參數與狀態色彩圖例。當 ChamberManage=1 顯示 Chamber 按鈕。起訖預設昨天 08:00 至今天 08:00；若現在早於今天 08:00，EndTime 改為 Now。
- 主篩選為 AreaNo、EquipmentType、EquipmentNo 三個可勾選多選條件，選取後以逗號分隔傳入；EquipmentNo 查詢選項由 `wsEQP.LoadEquipmentBasis(IssueState=2, ChamberFlag=0)` 載入，EquipmentType 用 `wsEQP.LoadEquipmentType(IssueState=2)`，Area 用 `wsSMD.LoadAreaBasis(AreaClass=0)`。取消勾選會清空該欄。
- Query 檢查 StartTime／EndTime 不可晚於現在、StartTime 必須早於 EndTime、`DateDiff(Hour)>24` 不允許。主查詢以 `AdditionalXml` 傳送 `EquipmentType IN (...)`、`AreaNo IN (...)`，另直接傳 EquipmentNo、StartTime、EndTime、ReportMode=True。
- Service：`D:\iMES\CSiMES\STD\MESws_STD\wsSTD\wsRPT\wsRPT.cs` 的 `LoadEQPRealTimeReport`，解析 EquipmentState、EquipmentNo、StartTime、EndTime、AdditionalXml 與 ReportMode，呼叫 `kcRPT.clsReport.LoadEQPRealTimeReport`。本 Form 未傳 EquipmentState。
- Core：`D:\iMES\CSiMES\STD\MESkc\kcRPT\clsReport.cs` 的 `LoadEQPRealTimeReport`。Report Mode 查 `tblEMSEquipmentStateLog UNION ALL tblEMSEquipmentState`，join `tblSMDSMTAreaEQPMAP` 與 `tblEQPStateBasis`，只取與查詢區間重疊的狀態並將 Start／End 截到查詢界線。回傳 AreaNo、EquipmentType、EquipmentNo、EquipmentState、StateName（Form 欄名 Status）、StartTime、TotalTime、EndTime、Description（Form 欄名 Reason）；`TotalTime` 以分鐘進位，但 Gantt 使用 StartTime／EndTime 繪製。
- Gantt 每列顯示 EquipmentNo、EquipmentType 與 Utilization Rate；X 軸每小時一格，Y 軸依 AreaNo／EquipmentType／EquipmentNo／StartTime 排序。區段顏色與名稱來自 `tblEQPStateBasis.StateColor`／StateName。滑過區段的提示含狀態、Reason、開始／結束與總分鐘。Utilization Rate 的 Form 公式為：`(查詢總分鐘 − UtilizationType=0 狀態的分鐘總和) / 查詢總分鐘`，格式百分比；`UtilizationType` 由狀態主檔提供。
- Chart 支援 Y 軸捲動（滑鼠滾輪）、粗體切換、字型大小、Ctrl+C 複製圖表。點 Chamber 按鈕會另外開 `frmEQPDailyUtilizationChart_Chamber`，提供 Area／EquipmentType／Chamber Equipment／Main Equipment 多選條件與同樣的 24 小時 Gantt。
- 子設備 Form：`frmEQPDailyUtilizationChart_Chamber.vb`／Designer；狀態／設備資料透過 `wsEQP.LoadEQPStateBasis`、`wsEQP.LoadEquipmentBasis`（主設備 `IssueState=2, ChamberFlag=0`）、`wsEQP.LoadEquipmentChamberBasis(IssueState=2)`（子設備）等 lookup。Query 呼叫 `wsRPT.LoadEQPRealTimeReport_Chamber`，可傳 `BelongEquipmentNo`。其 Service 將此參數傳至 `clsReport.LoadEQPRealTimeReport_Chamber`；Core 另回傳 ChamberFlag／BelongEquipmentNo，從 `tblSMDAreaRelation` 組合主設備與 Chamber 的 AreaNo，並以 EquipmentBasis 的 BelongEquipmentNo／ChamberFlag=1 限制指定主設備的子設備。子設備狀態區間用 `A.StartTime <= 查詢 EndTime` 且 `A.EndTime >= 查詢 StartTime` 的 overlap 條件。
- Core 將日期、EquipmentNo 清單及 AdditionalXml 條件串接 SQL，沒有分頁；Form 以小時邊界檢查最多 24 小時。家用端應採參數化查詢、參數化設備清單、允許欄位 allowlist、授權檢查與固定的最大區間／回傳筆數，不能直接接受前端 SQL。

## Vue DEV 行為

- 起始頁仿主 Form：Area、EquipmentType、EquipmentNo 多選窗，StartTime／EndTime、Query／Close；起訖預設及未來／順序／24 小時檢查沿用原表單規則。查詢前不自動載入 Gantt。
- 查詢後以設備列呈現狀態時間軸，各區段有狀態色彩、名稱與原始假 Reason；滑過顯示時間 tooltip，點選固定明細。設備標籤計算 Utilization Rate；Area、Type、Equipment 多選與取消條件互動可操作。Chart 提供垂直捲動、粗體、字型大小及複製提示。
- DEV 用開關模擬 ChamberManage；啟用後顯示 Chamber 子設備入口。子設備模式沿用 Area、Type、Chamber Equipment 多選，另提供 Main Equipment 多選以模擬 BelongEquipmentNo 篩選。以返回按鈕在同頁切換兩個 Form；這是單頁呈現的簡化，Legacy 實際另開視窗。Ctrl+C／複製按鈕僅顯示提示，不存取作業系統剪貼簿。
- 狀態 ID、色彩、區間及 Reason 都是合成假資料，不能代表實際設備狀態／UtilizationType。DEV 只用樣本區段演算標籤 Rate，不呼叫報表資料庫。

## MESTEST DDL 與家用端 API handoff

- Repo 有本 Core 查詢表的 Oracle MESTEST 參照：`database/reference/mestest_wip_wp305_source_ddl.sql`（`tblEMSEquipmentStateLog`、`tblEMSEquipmentState`）；`database/reference/mestest_equipment_group_smd_source_ddl.sql`（`tblSMDSMTAreaEQPMAP`、`tblSMDAreaRelation`）；`database/reference/mestest_wip_wp201_unresolved_source_ddl.sql`（`tblEQPEquipmentBasis`）；`database/reference/mestest_equipment_state_create.sql`（檔頭註明依 `MESTEST.TBLEQPSTATEBASIS` DBMS_METADATA DDL 轉出）。
- 桌機沒有可用的受保護 Oracle profile，本項未另查 MESTEST／indexes；只引用 repo 已有參照。這是唯讀報表，不新增 CREATE／migration。家用端仍要比對 YMES live schema、欄位／索引與執行計畫。
- 建議唯讀 API：`GET /api/reports/equipment-utilization-timeline`，輸入 startTime、endTime、areaNos[]、equipmentTypes[]、equipmentNos[]；子設備使用 `chamber=true` 與 belongEquipmentNos[]。服務端驗證不含未來時間、StartTime<EndTime、Legacy 時數邊界規則，並限制區間／筆數；依授權範圍 parameterize 查詢，使用狀態 master 的 UtilizationType／StateColor 產生每個設備狀態段與 Utilization Rate。
- 回傳每個設備的 areaNo、equipmentNo、equipmentType、belongEquipmentNo、utilizationRate，以及狀態段的 equipmentState、status、reason、startTime、endTime。固定 EquipmentNo／StartTime 穩定排序；不要將前端 AdditionalXml／任意 SQL 傳給資料庫。
- 公司端未連 PostgreSQL、未實作或驗收正式 API／schema，未 build／test／browser。
