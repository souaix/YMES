## WinForms 畫面與互動

- 最大化 Form，上方顯示標題、BelongDate、Setup、Close；下方黑底可捲動圖表區。每個設定 OP 一張複合圖，按設定順序排列，每列最多四張。
- Load 先依 HostName 與 `SetupType=5` 取 RefreshTime、FontSize、OPNo／OPOrder；有設定才建立圖表、載入摘要並啟動 Timer。Setup 停 Timer，呼叫共用設定視窗，重載設定與摘要後依秒數恢復 Timer。
- 圖表標題是 OPNo，OPName 於游標移至圖表上方時顯示。右鍵選單有 Copy To Clipboard 與 Lot Detail。雙擊以接近螢幕大小開啟 Type 5 圖表；Lot Detail 開啟 Type 7 子視窗。
- X 軸按時段順序建立 T01…Tn；Legacy 隱藏軸標籤，游標 tooltip 顯示實際時段起訖與數值。WinForms composite chart 將 GoodQty、ScrapQty、DefectQty 畫成群組柱；`YieldContainDefect=0` 時包含 DefectQty。Yield 為藍色帶菱形標記折線，使用右側 0–100% 軸。
- 數量軸是跨全部 OP／時段共用的最大數量，左軸為數值；每張圖都套相同 `RangeMax`。`YieldContainDefect != 0` 時隱藏 DefectQty 柱，但仍顯示 Core 的 Yield。
- Timer 每 RefreshTime 秒停止、重新取摘要、更新圖表後重啟。Core 對未開始時段不填值；Form 將非數字的 Good／Scrap／Defect／Yield 資料點轉成 0，因此圖上未開始時段仍是零值。
- `CopyToClipboard` 是圖表原生剪貼簿操作。DEV 右鍵選單以 toast 模擬複製回饋，不觸碰系統剪貼簿；Lot Detail 以假批次列模擬。

## 資料表與計算

- `LoadBillBoardOPOutputSummary(OPNo)` 使用 `tblRPTTimeStepBasis` 的 `IssueState=2` 設定依 TimeStepNo 建立各時段，並按 OP 從 `tblWIPLotLog_Report` 讀 `Status=1` 的 EndTime、GoodQty、FailQty、DefectQty，取得 OPName。Core 以 `YieldContainDefect` 計算各時段 Yield。
- 輸出資料集對每個 OP 有 GoodQty、ScrapQty、DefectQty、Accumulate GoodQty、Yield 五列；RT207 只取前三個數量列與 Yield 列繪圖，未呈現累計 GoodQty。
- `LoadBillBoardOPOutputLotDetail(OPNo)` 依同一歸屬日、時段、OP 與 Status=1 取 LotLog，並附 TimeStep 顯示名稱。Core 的時段日期歸屬及邊界沿用 RT205 規格所列疑點；家用端須以同版資料和 MESTEST 複核閉區間重疊、班別及時區。
- `tblWIPLotLog_Report` 的 MESTEST CREATE reference 存於 `database/reference/mestest_wip_wp201_dependency_source_ddl.sql`；`tblRPTTimeStepBasis` 與看板設定表的可信 CREATE／完整鍵索引未在 repo 找到。本次沒有 Oracle profile metadata 可用證據，未查詢 Oracle、未推測 CREATE SQL。

## 家用端 API／schema handoff

- RT207 可沿用 RT205 的唯讀摘要 API：建議 `GET /api/reports/op-output-summary?opNos=...&belongDate=...`，一次批次回傳每個 OP 的 OPName 與時段起訖、GoodQty、ScrapQty、DefectQty、Yield、BelongDate、NowTimeStep。前端將四列摘要格式展開為群組柱與折線；跨 OP 數量最大值用於各圖共用左軸，Yield 軸固定 0–100%。實際切段與 Yield 規則沿 RT205 handoff 核對。
- RT207 設定沿用 Legacy `SetupType=5` 的 OP 清單、OPOrder、RefreshTime、FontSize。YMES 若需持久化，建議提供受登入使用者／已授權裝置範圍保護的設定讀寫 API；先確認設定歸屬與 live schema，再提供可信 PostgreSQL CREATE-only SQL。不要把 Legacy HostName／PCNo 直接當授權依據。
- Lot Detail 可沿用唯讀 `/api/reports/op-output-lot-detail?opNo=...&belongDate=...`，只回傳目前使用者可讀、限制日期與筆數的 Status=1 生產批欄位及時段標籤。DB 索引、欄位和時間區間需先比對同版 MESTEST DDL 與 PostgreSQL schema。
- 現有可信 LotLog reference 可作欄位核對起點；`tblRPTTimeStepBasis`、`tblRPTBillBoardOPStateConfig`、`tblRPTBillBoardOPStateContent` 目前沒有可信 CREATE／完整 PK、索引定義。公司端未產生推測性 CREATE SQL。
