# RT608 生產批資源檢視(分攤)

## 選單與來源

- 選單：RPT → 資源 →「生產批資源檢視(分攤)」，FunctionNo `LOT RESOURCE SHARE`、FunctionKey `RT608`，Form `frmRPTLotResource_Share`，執行檔 `RT_LotResource_Share.dll`。
- Form／Designer：`STD/MESWin/RPT/RT_LotResource_Share/frmRPTLotResource_Share.vb`。控制項版面與程式碼在同一檔，沒有獨立 `.Designer.vb`。CSiMES、THEIL、DEV_SILVA 三份 Form 的 SHA256 相同：`AEA15BB51734BB907268004B36F91C8043FA55E86D3F4871446E3A584E5262CE`。
- Service/Core：`wsRPT.LoadCont_Resource_Share` → `kcRPT.clsReport.LoadCont_Resource_Share`。
- 其他 lookup：`wsOP.LoadOPBasis` 與 `wsEQP.LoadEquipmentBasis`；兩者皆傳 `IssueState=defInteger`，Form 的單選視窗未另加狀態限制。

## Form 條件與操作

- 條件為 YearMonth、OPNo、MONo、LotNo、ResClass、ResItem、Production Time 起迄與 Summary Time 起迄。各條件需勾選或輸入才會送出；Query 至少要求一個有效條件。
- YearMonth 日期欄初值為當月，但 checkbox 初始未勾。Production Time 與 Summary Time 的起迄初值分別為今天 00:00:00 至 23:59:59，四個 DateTimePicker 初始皆未勾，可只指定單一端點。
- OPNo lookup 是單選 `frmCOMSearch`，使用 `LoadOPBasis`。MO／Lot 文字輸入會自動勾選條件，取消 checkbox 會清除值。ResClass 候選為 EMP、EQP；選值會自動勾選。
- ResItem 可直接輸入；`...` lookup 固定呼叫 `LoadEquipmentBasis`，以 EquipmentNo 單選回填，即使 ResClass 選 EMP 仍顯示設備清單。來源沒有 EMP／UserNo 對應 lookup，DEV 保留此限制並允許手動輸入。
- DateTimePicker 各自可獨立勾選，Form 沒有起迄順序驗證。YearMonth 與 Production Time 同時使用時，條件會相交。

## Service／Core 查詢

- Service 解析 YearMonth、OPNo、MONo、LotNo、ResClass、ResItem、EventTimeFrom／To、CreateDateFrom／To 後呼叫 Core。
- Core 只查 `TBLWIPCONT_RESOURCE_SHARE`，並明確不取 CLOB 欄位；欄位為 LotNo、MONo、LogGroupSerial、OPNo、ResClass、ResItem、ResValue、StdValue、InputQty、OutputQty、UserNo、EventTime（別名 ProductionTime）、CreateDate（別名 SummaryTime）、ItemNo。此方法以標準 `strConnectionString` 開連線。
- YearMonth 依 EventTime 使用月初含、次月月初不含的半開區間。OPNo、MONo、LotNo、ResClass、ResItem 為精確條件；Production Time 篩 EventTime，Summary Time 篩 CreateDate，各端點獨立且含等號。
- Core 將條件串成 SQL，沒有分頁、條件上限或日期跨度限制。Form 收到資料後依 ProductionTime 升冪排序。Grid 隱藏全部欄再顯示 12 欄：LotNo、MONo、OPNo、ResClass、ResItem、ResValue、StdValue、InputQty、OutputQty、UserNo、ProductionTime、SummaryTime；LogGroupSerial、ItemNo 保持隱藏。ResValue／StdValue 顯示最多兩位小數，InputQty／OutputQty 最多四位。
- Core 無法參數化地直接移植為正式 API。家用端需使用參數化條件、登入與 RT608 Function ACL，且設分頁／回傳上限；保留 YearMonth 的半開區間及各時間端點可單獨指定的口徑。
