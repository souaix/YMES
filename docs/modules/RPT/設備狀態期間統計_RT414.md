# RT414 設備狀態期間統計

## 選單與來源

- 選單識別：Module `RPT`、FunctionNo `EQP STATE STATISTICS`、FunctionKey `RT414`、Form `frmEQPStateStatistics`、ExecutionFile `RT_EQPStateStatistics.dll`，分類為「在製品」。此 Form／DLL 也由 EMS 的 ES409「設備狀態期間統計查詢」使用；兩個 FunctionKey 保持獨立。
- 公司端 Vue DEV 路徑：`/YMES/RPT/EquipmentStateStatistics`。此入口只增加 RT414 專屬選單鍵及路徑，重用 ES409 的 `EmsEquipmentStateStatistics.vue` 和 DEV preview，不另造重複查詢畫面。
- 原 Form 與 Designer 同在 `D:\iMES\CSiMES\STD\MESWin\RPT\RT_EQPStateStatistics\frmEQPStateStatistics.vb`；Service 為 `STD/MESws_STD/wsSTD/wsRPT/wsRPT.cs` 的 `LoadEQPRealTimeReport`、`LoadEQPRealTimeReport_Chamber`；Core 為 `STD/MESkc/kcRPT/clsReport.cs` 同名方法。WinForms 篩選、欄位投影、ChamberManage 與計算規則均見 [ES409 共用規格](../EMS/設備狀態期間統計查詢.md)。
- 來源沿用 ES409 已核實的唯讀 Oracle DDL／metadata references；本項無新表、無新 Oracle 查詢，也不查業務資料。

## RT414 入口與 DEV 行為

- `web/src/App.vue` 將 RT414 登記為 `function:RPT:EQP STATE STATISTICS`，獨立路徑為 `/YMES/RPT/EquipmentStateStatistics`，並與 ES409 的 `function:EMS:EQP STATE STATISTICS_EMS` 分開判斷。
- 兩入口共用相同 DEV 畫面：起訖日期、狀態多選、設備多選、區間驗證、標準／Chamber 切換、排序、空結果與查詢結果欄位。DEV 依假資料模擬區間裁切、分鐘向上取整和 Chamber 母子設備投影，不呼叫正式 API、不持久化資料。
- 功能為唯讀統計，沒有新增、修改或刪除操作。共用畫面的細節和舊 Core 風險以 ES409 規格為準，避免兩份規格發散。

## 家用端 API handoff

- 可由家用端評估讓 RT414 與 ES409 共用參數化唯讀查詢實作；API 必須依實際 FunctionKey／權限守門，不因 Vue 共用元件而合併兩個選單授權。
- 延用 ES409 建議參數 `startTime`、`endTime`、`equipmentNos[]`、`stateCodes[]`、`showChambers`，以及設備可見範圍、期間上限、時間區間裁切、`CEIL` 分鐘與穩定排序要求。詳細 API、來源表及欄位規則見 [ES409 共用規格](../EMS/設備狀態期間統計查詢.md)。
- 不需 RT414 專屬 schema／migration。公司端未連 YMES PostgreSQL、未實作或驗收正式 API/schema、未部署。
