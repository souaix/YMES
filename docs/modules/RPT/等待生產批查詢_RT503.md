# RT503 等待生產批查詢

## 選單與來源

- 選單：RPT → 生產批 →「等待生產批查詢」，FunctionNo `WAIT LOT`、FunctionKey `RT503`、Form `frmLotState_Wait`、執行檔 `RT_LotState_Wait.dll`。
- Form／Designer：`STD/MESWin/RPT/RT_LotState_Wait/frmLotState_Wait.vb`；Designer 內嵌在同一檔，沒有獨立 Designer 檔。CSiMES、THEIL、DEV_SILVA 三份檔案雜湊一致。
- Service：`STD/MESws_STD/wsSTD/wsWIP/wsWIP.cs` 的 `LoadLotBasisJoinState`。
- Core：`STD/MESkc/kcWIP/clsLot.cs` 的 `LoadLotBasisJoinState`。
- RT503 與 RT501／RT502 共用查詢 Service／Core；本 Form 傳入固定 `Status=2`，不能套成 RT501 的 `LotState=1` 或 RT502 的 `Status=3`。

## Form 條件與操作

- 查詢固定傳 `Status=2`、`ReportMode=True`；不傳 `LotState`，也沒有額外條件必填檢查。空條件仍會呼叫查詢。來源 Form 的註解將 2 標為「Hold」，但同檔 StatusShow 對 2 顯示 `Wait`，查詢值才是實際篩選依據。
- 八個可勾選條件：RO No、MO No、Product No（同時傳 ProductVersion）、Customer No、Lot No、OP No、Org Lot No、PS No。RO／MO／Lot／Org Lot 輸入非空時自動勾選；清空會取消勾選。取消 checkbox 會清除該欄值。
- Customer、Product、PS、OP 欄位唯讀並提供可見 lookup。Lookup 分別呼叫 `wsENT.LoadCustomerBasis(IssueState=defInteger)`、`wsPRD.LoadProduct(IssueState=defInteger, CurVersion=defInteger)`、`wsPRS.LoadProductionSegment(IssueState=2)`、`wsOP.LoadOPBasis(IssueState=defInteger)`；選取視窗只顯示 IssueState=2，Product 會回填 ProductNo、ProductVersion、ProductName。
- MO 與 Lot 的選取 helper 仍留在程式碼，但 Designer 將 `btnGet`／`btnGet1` 設為 `Visible=False`。隱藏 Lot helper 以 `wsWIP.LoadLotState(Status=2)` 載入待批清單。
- Query 沒有額外欄位驗證；Form 沒有日期、狀態下拉、明細視窗或寫入操作。Close 關閉表單。

## Service／Core 查詢

- Service 解析 Status 與 RO／MO／Product／ProductVersion／Customer／Lot／OP／OrgLot／PS 等共用參數後呼叫 Core；`ReportMode=True` 會使用 report connection。
- Core 主查詢從 `tblWIPLotState A` join `tblWIPLotBasis B`（BaseLotNo），left join `tblOPBasis C`（OPNo）、`tblPRSProcessBasis D`（ProcessNo／ProcessVersion）、`tblENTCustomerBasis F`（CustomerNo），並 inner join `tblPRDProductBasis E`（ProductNo／ProductVersion）。固定另有 `A.LotNo IS NOT NULL`；此 Form 的狀態條件為 `A.Status=2`。
- 不加 `B.LotState` 條件。RONo、MONo、ProductNo、OrgLotNo 使用 `LIKE`；ProductVersion 使用 `IN`；CustomerNo、OPNo、PSNo 使用等值；LotNo 以 `|` 分隔後使用 `IN`。Core 直接串接 SQL，沒有分頁、筆數上限或排序。
- Form 保留 ProductNo、ProductName、ProductVersion、LotNo、OPNo、BRNo、Status、CurQty、CurUnitNo，再新增 StatusShow。Grid 隱藏數字 Status，StatusShow 對 2 顯示 `Wait`；CurQty 格式 `0.####` 靠右；LotNo、OPNo 升冪排序。ProductName 與 ProductNo 的來源 Layout 都設 visible position 0，DEV 以易讀的九欄順序呈現。
- 結果唯讀，沒有自訂列選取後的操作或 Detail 呼叫。

## DDL 與家用端交接

- 主查詢 `TBLWIPLOTBASIS`、`TBLWIPLOTSTATE` 的 MESTEST source DDL 沿用 `database/reference/mestest_wip_wp101_source_ddl.sql`；Product、Customer、Process 的 references 沿用 RT502 對應 DDL。沒有新增 CREATE-only 表。
- `TBLOPBASIS` 的原生 source DDL／metadata 未找到；桌機沒有受保護 Oracle profile，本次沒有查 Oracle，也不以推測 DDL 建表。家用端先核 live PostgreSQL catalog、同步來源與 OP lookup 欄位。
- 家用端建議提供登入與 RPT FunctionNo `WAIT LOT` 授權保護的唯讀 `GET /api/reports/wait-lots`。伺服器固定套 `A.Status=2`，不加 RT501 的 LotState 條件；可接受 roNo、moNo、productNo、productVersion、customerNo、lotNo（支援多值）、opNo、orgLotNo、psNo。查詢需參數化、穩定排序、分頁及筆數上限；不可接受前端 SQL／AdditionalXml，也不可照搬空條件全量查詢。
