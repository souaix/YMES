# 作業站參數群組設定（OPB01）

## 功能識別

| 項目 | 內容 |
| --- | --- |
| FunctionNo / FunctionKey | `B_OP GROUP ATTRIB` / `OPB01` |
| 三層選單 | 作業站資料 → 行業包 → 作業站參數群組設定 |
| WinForms | `frmOPGroupAttrib`、`frmOPGroupAttribDef` |
| Service / Core | `Industry_Base.wsOP.LoadOPGroupAttrib`、`LoadOPGroupAttribJoinElementBasis`、`SaveOPGroupAttrib`、`DelOPGroupAttrib`；`MEStc_Industry_Base.clsOpBasis`；`MEStc_B_Basis_UPD.clsB_Basis_UPD` |

## 證據及資料庫結構

OPB01 主表 DDL 由公司電腦使用 Windows PowerShell 5.1、Oracle.ManagedDataAccess，從本機受保護的 `DatabaseConfigs.CS.Test.Mes` 連線唯讀執行 `DBMS_METADATA.GET_DDL`，並比對 `ALL_TAB_COLUMNS`、`ALL_CONSTRAINTS`、`ALL_INDEXES`、`ALL_IND_COLUMNS`。只查 metadata，沒有讀業務資料列，沒有在 Oracle 執行 DDL/DML，也沒有將連線秘密放入 repo。

- Oracle source：`database/reference/mestest_opb01_operation_group_attribute_source_ddl.sql`
- PostgreSQL CREATE-only 參考：`database/reference/mestest_opb01_operation_group_attribute_create.sql`
- YMES 共用 `tblsyselementbasis` 已列於 first-phase schema；本功能不另建同義表。部署前仍須由家用電腦比對 YMES live schema/migrations。

`TBLOPGROUPATTRIB` 的複合 PK 為 `(CUSTOMERNO, OPGROUPNO, ELEMENTNO)`。來源只有此 PK unique index 和各 NOT NULL 欄位 constraint，沒有 FK 或其他 index。`BYSECONDCLASS`、`DATASTAMP` 都 nullable；兩者 default 為 0。DataStamp 是更新時比對版本的值，更新成功遞增；新增時 Oracle 使用 default。

此表沒有 `ISSUESTATE`，OPB01 本身沒有狀態篩選或簽核流程。

## 主畫面

WinForms 主視窗是單一清單 Grid。上方有三個可獨立勾選的查詢條件：CustomerNo、OPGroupNo、ElementNo；每項有文字輸入及 `...` 查找按鈕，另有「查詢」。輸入後按 Enter 會勾選對應條件並執行查詢；離開欄位時 trim 並轉大寫。Core 對有傳入的三個條件使用 `=` 精確比對；`%` 字樣不是 SQL wildcard。

Grid 依 CustomerNo、OPGroupNo、ElementNo 排序，顯示：

1. CustomerNo、OPGroupNo、ElementNo、ElementName
2. DefaultValue、DataType、AllowNull、Sequence、`BYEQUIPMENT_TYPE`
3. Reviser、ReviseDate、Creator、CreateDate

DB 欄位名是 `BYSECONDCLASS`；WinForms 載入後改名 `BYEQUIPMENT_TYPE` 顯示。此欄是布林式設定，新增時預設 0。其餘未列入 Grid 的欄位隱藏。

右側按鈕：

- **ADD**：開啟空白編輯視窗。
- **EDIT**：依選取列的 CustomerNo + OPGroupNo 載入整組屬性；CustomerNo、OPGroupNo 鎖定。
- **DEL**：可多選屬性列；確認後逐筆呼叫刪除 Service。若系統參數 `InputAbortLog=1`，必須先取得作廢原因；舊畫面逐筆刪除，後續筆失敗時先前成功的刪除不會回復。
- **COPY**：載入選取列所在組別的整組屬性，允許選目標 CustomerNo、OPGroupNo，再批次複製/編輯。
- **CLOSE**：離開主畫面。

清單無 IssueState 欄，也沒有核准按鈕。

## 新增／修改／複製視窗

視窗頂部為 OPGroupNo 和 CustomerNo，兩欄透過 `...` 查找選取。編輯模式兩欄唯讀；新增及複製模式可選。群組選項是 `TBLOPECNGROUPBASIS.ISSUESTATE=2` 的 ECN 群組；客戶選項是 `TBLENTCUSTOMERBASIS.ISSUESTATE=2`。空白 CustomerNo 在儲存時代表共用客戶 `*`。新增預設值在 Web DEV 畫面設為 `*`，亦可從客戶選擇器選其他客戶。

下方是可一次編輯多個 Element 的 Grid：CustomerNo、ElementNo、ElementName、DefaultValue、DataType、AllowNull、Sequence、BYEQUIPMENT_TYPE。新增 Element 使用多選查找視窗；查詢來源為已核准的 `TBLSYSELEMENTBASIS` Product Element（`ISSUESTATE=2 AND ELEMENTTYPE=5`），不加入共用 Element (`ELEMENTTYPE=0`)，也不重複加入目前已選 Element。WinForms 查找 Grid 顯示 ElementNo、ElementName、ElementType、DataType、TransferType、ValueType、ValidList、DefaultValue、Description、Controlled、InputType、AllowNull；Web 選擇器保留這些來源欄位。這些代碼欄位在 WinForms 由 `ValueListProvider.GetValueList("TBLSYSELEMENTBASIS",欄位)` 取得依語系轉換的顯示文字；正式 API 應隨 Element lookup DTO 提供各代碼的顯示文字（例如 `dataTypeText`、`transferTypeText`、`valueTypeText`），不要把 DEV 頁的 fallback 名稱表當成正式 ValueList。ElementName/DataType 從 Element 主檔帶入且唯讀；`InputType` 決定 DefaultValue 編輯方式：

- `0 Key In`：文字輸入。更新既有值時 WinForms 呼叫 `wsSYS.ChkElementValueValid(ElementNo, CheckValue)`，並使用系統 Element 的 ValueType/有效值/參照參數檢核；Web API 應重用同一套 SYS 驗證規則，不能只信任前端。
- `1 Select List`：使用 `wsSYS.LoadElementValue(ElementNo)` 回傳的值清單作下拉選單。

可編輯欄位只有 DefaultValue、AllowNull、Sequence、BYEQUIPMENT_TYPE。AllowNull 選項為 `0 Not Null`、`1 Null`。Sequence 必須是整數 0–99（Oracle `NUMBER(2,0)`）。DefaultValue 不得超過 255 字元。新列的 DefaultValue、DataType、AllowNull、Sequence 取自 Element 主檔；BySecondClass 預設 0。

明細刪除只先標為待刪；新加入但尚未儲存的列直接從編輯資料移除。**套用**儲存後留在視窗，**確定**儲存後關閉，**關閉**不儲存目前尚未套用的修改。儲存必須有選取的 ECN 群組與至少一個 DataTable row；刪除所有列時需保留待刪旗標列才能送出。

### Copy 與批次 DataFlag

WinForms 以 `DataFlag` 表示每列：`0 新增`、`1 修改`、`2 刪除`、`-1 無異動/複製來源列`。Update Core 將同批 SQL 送入 `ExecuteSQLNoneQuery_ChkRowCount`；新增預期 1 列，修改需 DataStamp 條件命中 1 列，刪除預期命中既有列。`CopyOPGroupAttrib` 會先查目標複合鍵，已存在時略過，不存在才新增。

Web 的 Copy 以完整 PK `(CustomerNo, OPGroupNo, ElementNo)` 判斷是否換目標。目標鍵改變時，存活列視為目標組的新增；待刪來源列不複製，來源組不受影響。此處採用完整複合鍵保留 Copy 的使用者意圖，避免舊 WinForms 只以 OPGroupNo 判斷 DataFlag、CustomerNo 單獨變更時把修改送到錯誤主鍵的行為。

### 查找表 `MESTEST.TBLSYSELEMENTBASIS`

本功能只查已核准 Product Element。欄位 DDL 已收錄於 Oracle source reference；PostgreSQL 初始 CREATE 已在 `mestest_first_phase_create_tables.sql` 建立，本功能不再產生第二份 CREATE。查找至少需要 `ELEMENTNO`、`ELEMENTNAME`、`ELEMENTTYPE`、`DATATYPE`、`INPUTTYPE`、`ALLOWNULL`、`DEFAULTVALUE`、`ELEMENTSEQUENCE`、`VALIDLIST`、`VALUETYPE`、`ISSUESTATE`。

## YMES API handoff

所有路由要求登入並授權 FunctionNo=`B_OP GROUP ATTRIB` / FunctionKey=`OPB01`。SQL 必須參數化；Creator/CreateDate/Reviser/ReviseDate 從伺服器登入主體/伺服器時間產生，忽略 body 內稽核值。

| Method / path | 用途 |
| --- | --- |
| `GET /api/operation-group-attributes?customerNo=&opGroupNo=&elementNo=` | 主 Grid；僅套用有值且前端勾選的精確查詢條件；排序依複合鍵 |
| `GET /api/operation-group-attributes/editor?customerNo=&opGroupNo=` | 編輯視窗資料，join Element Basis 帶回 InputType/有效值 metadata，依 ElementNo 排序 |
| `POST /api/operation-group-attributes/batch-save` | 一次儲存該組的新增/修改/刪除；body 包含 customerNo、opGroupNo、entries 與 changeType/DataStamp |
| `DELETE /api/operation-group-attributes?customerNo=&opGroupNo=&elementNo=&abortLog=` | 刪除單一主鍵資料；多筆刪除由 UI 逐筆呼叫，API 每筆回報結果 |
| `GET /api/customers?issueState=2` | Customer picker；重用客戶基本資料 API，加上共用客戶 `*` 選項 |
| `GET /api/ecn-operation-groups?issueState=2` | ECN 作業站群組 picker；重用 OPB02 API |
| `GET /api/system-elements?issueState=2&elementType=5` | Element 多選/查找清單；只回可加入的 Product Element，回傳上述查找欄位及各代碼的語系顯示文字 |
| `GET /api/system-elements/{elementNo}/values` | Select List 的 Element 有效值，對應 `wsSYS.LoadElementValue` |
| `POST /api/system-elements/{elementNo}/validate-value` | Key In 驗證，重用 `wsSYS.ChkElementValueValid`/SYS Core |
| `GET /api/system/parameters/InputAbortLog` | 回傳 `{ "parameterName": "InputAbortLog", "value": "0" | "1" }`；UI 啟動時讀取，值為 1 時刪除必填作廢原因；讀取失敗時停止刪除並提示錯誤 |

### 寫入及一致性要求

- Batch Save 必須使用單一資料庫交易，逐筆依 DataFlag 執行，任一新增/修改/刪除失敗時整批 rollback；回傳失敗的複合鍵與可讀訊息。
- 修改使用 DataStamp CAS。來源欄可 NULL 且 DEFAULT 0：SQL 需對 null 舊值使用 `IS NULL`，對非 null 用等值比對；成功後遞增 DataStamp。CAS 未命中回 HTTP 409。不能把 NULL 舊值默認當 0 後允許覆蓋。
- 新增維持 Oracle 的 nullable/default 語義：`BYSECONDCLASS`、`DATASTAMP` nullable、default 0；不要加 FK 或額外索引。`TBLSYSELEMENTBASIS` 已是共用表，不建新表、不另加重複關聯表。
- 新增/修改均在伺服器端確認 ECN 群組 IssueState=2、Element IssueState=2 且 ElementType=5；修改 ElementNo 不可更換。
- 依同一套 SYS ValueType、ValidList/ElementValue、Reference Parameter 規則驗 DefaultValue；前端下拉選單不構成安全驗證。
- CustomerNo/OPGroupNo/ElementNo 長度及必填照來源 DDL；Sequence 0–99。主表批次刪除不是軟停用。
- Production API 不可連 Oracle；YMES 使用 PostgreSQL。DEV 假資料只存瀏覽器 localStorage，不寫入正式 DB。
