## 正式站操作

- Root 使用 app-browser 自行 Demo 登入；正式預設、KD 標誌、原生 21 個主選單、三層分支、深連結重載與還原中操作鎖均有實際操作記錄。
- 三個新 EMS 頁面均由原生選單開啟；正式 guard、頁名、Close、桌面／窄版自適應及文件沒有橫向溢出均通過。Close 能返回主選單。
- ET202 由「客戶資料→外包商資料設定→外包項目設定」原生三層選單開啟。只執行唯讀空條件與合法兩字元 no-match 查詢；開啟並關閉空白新增表單；開啟流程查找、等待資料載入、驗證輸入焦點，按 Escape 關閉子視窗並把焦點還給查找按鈕。沒有送出新增或其他業務寫入。
- WP109 從原生選單開啟並執行唯讀 Query；查詢完成、沒有 alert／載入殘留，新增仍依目前頁面狀態停用。沒有建立或修改 SWR。
- 側欄展開／收合、72px icon-only 模式、21 個頂層項目各 1 個 icon、半透明 scrollbar、選單長度與自適應均已實測。1280×900 時 nav 963px 高／可視 698px，會捲動；1280×1400 時 nav 1185px／內容 1185px，沒有多餘捲動。836×891、1280×900 與 1280×1400 文件均無水平溢出。最後回到主選單：所有頂層分支折疊、選單在最上方、主內容空白；Root 已目視檢查截圖。
- 全程沒有業務資料寫入；最後 app-browser warn/error 記錄為空。
